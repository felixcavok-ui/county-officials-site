徐长元 （1955年11月—），男，汉族，辽宁庄河人。1974年11月参加工作，1974年3月加入 中国共产党 ，大学文化。曾任 辽宁省 大连市 副市级干部（正厅局级），大连市 金州区 委书记、 金州新区 党工委书记、管委会主任 [ 1 ] 。2018年因涉嫌家族式黑社会组织犯罪等问题接受组织调查，被称为辽宁省纪检监察部门所查办的涉案金额最大、涉案人员最多、涉案时间最长、涉案类型极其复杂的一起“官商一体、官黑一炉、商黑交织”典型案件 [ 2 ] 。
生平 [ 编辑 ]
1972年，徐长元的母亲去世，因家境贫困，徐长元作为家中长子，主动放弃了学业，在 公社 生产队 工作养家。1974年，因表现优秀，加入中国共产党。1974年至1982年，任庄河县英烈士公社（今 庄河市 吴炉镇 英烈士村）党委副书记、革委会副主任。1982年，入读大连管理干部学院（今 大连职业技术学院 ）农业企业经营管理专业。1984年毕业后历任庄河县包装制品厂厂长，庄河县宏大企业公司经理，庄河市人民政府市长助理兼计经委主任，庄河市委常委、副市长，市委副书记、市长， 瓦房店市 委副书记，市长、 长兴岛 临港工业区（长兴岛经济技术开发区）管委会主任、党工委书记（正局级），金州区委书记，金州新区党工委书记、管委会主任。2015年5月，到龄退休，任大连长波集团决策委员会主任 [ 3 ] 。
落马 [ 编辑 ]
2018年4月， 辽宁省纪委 监委 第十纪检监察室根据收到的群众举报，对徐长元有关问题进行初核 [ 2 ] 。7月6日， 中央纪委国家监委网站 转发辽宁省纪委监委消息：徐长元涉嫌严重违纪违法，正接受纪律审查和监察调查 [ 3 ] 。辽宁省纪委监委为此案成立了专案组，对徐长元等人采取了 留置 措施 [ 2 ] 。2019年1月15日，经辽宁省纪委常委会会议研究并报 省委 批准，决定给予徐长元开除党籍处分、取消其退休待遇；将其涉嫌职务犯罪问题移送检察机关依法审查起诉，所涉财物随案移送。通报称，徐长元除了政治问题和涉嫌经济犯罪以外，还“涉及 黑恶性质组织 问题” [ 1 ] 。
2020年9月27日， 辽宁省大连市中级人民法院 对徐长元等24人涉黑案公开宣判，以组织、领导黑社会性质组织罪、诈骗罪等十余项罪名数罪并罚，判处被告人徐长元无期徒刑，剥夺政治权利终身，并处没收个人全部财产。其他同案犯（包括徐长元的二弟徐长发、妹妹徐秀敏、三弟徐长波、四弟徐长威、五弟徐长宝）中，徐长威被判处无期徒刑，剥夺政治权利终身，并处没收个人全部财产；徐长宝被判处有期徒刑二十五年，并处没收个人全部财产、剥夺政治权利五年；其他人分别被判处有期徒刑十二年至二年二个月不等，并处剥夺政治权利、没收财产及罚金等。被告单位大连长波物流有限公司因犯骗取贷款罪被判处罚金。判决书指出，自徐长元1996年担任庄河市副市长以来，其三弟、四弟以及五弟先后成立大连长波物流有限公司以及几十个子公司和相关联经济实体，在徐长元的领导、指点和纵容下，依靠徐长元的政治地位，网罗社会闲散人员，以暴力、威胁等手段大肆攫取非法利益，政商勾结、以商养黑、以黑护商，逐渐形成了家族式的具有黑社会性质的犯罪组织。该黑社会性质组织盘踞大连地区十余年，以暴力、威胁或者其他手段，先后实施了诈骗、骗取贷款、高利转贷、贪污、受贿、单位行贿、赌博、非法拘禁、非法侵入住宅、聚众斗殴、聚众扰乱社会秩序、寻衅滋事、故意伤害、窝藏等犯罪行为二十余起；实施寻衅滋事、非法拘禁、非法经营、非法讨债、强迫交易、故意伤害等违法行为三十余起，在庄河市、普兰店市（今 普兰店区 ）乃至整个大连地区形成了重大影响，在金融、房地产开发等多个领域形成了强大的非法控制，严重地危害了社会生活秩序和经济发展秩序。该组织还向政治领域持续渗透，除徐长元本人长期担任领导职务外，还有多名家族成员担任过各级人大代表、政协委员 [ 4 ] 。部分被告人不服一审判决，提起上诉。同年12月， 辽宁省高级人民法院 终审裁定，驳回上诉，维持原判 [ 2 ] 。
2021年3月27日，全国 扫黑除恶专项斗争 协调小组办公室和 中央廣播電視總台 共同制作的政论专题片《 扫黑除恶——为了国泰民安 》第二集《依法重击》在 中国中央电视台综合频道 播出，露了徐长元及“庄河徐家”黑恶势力“政商黑三通”的犯罪历程。他们暴力讨债，开设赌场，干预司法，挪用公款。徐长元对外以清廉形象示人，但单是在干部选拔任用、企业经营等方面收受的财物就达到9400多万元。他生活奢靡，每年春节都大摆宴席，邀请政商两界要人。在调查的过程中，很多受害人慑于徐家多年淫威，不敢讲出实情。纪委监委共计查获徐家资产上百亿元，房产2714套（总面积43.3万平方米），土地43宗（总面积35万平方米），注册企业46家，车辆142台，其中单是2700多套房产的总面积就几乎相当于 梵蒂冈 的面积，全部房产证的总重量达到了54公斤 [ 2 ] [ 5 ] [ 6 ] [ 7 ] 。
