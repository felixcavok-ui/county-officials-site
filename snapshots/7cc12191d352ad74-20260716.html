德阳市第五届人民代表大会第二次会议审议了市长方小方代表市人民政府所作的《政府工作报告》。会议认为，《报告》实事求是地总结了2 0 0 3 年政府工作，对2 0 0 4 年政府工作的总体安排切实可行。会议决定批准这个《报告》。 会议认为，2 0 0 3 年是全市经济社会发展取得可喜成绩的一年。在中共德阳市委的领导下，市政府高举邓小平理论伟大旗帜，认真贯彻党的十六大精神，努力实践“三个代表”重要思想，加快推进“三个转变”，团结和带领全市人民，艰苦奋斗，开拓进取，圆满完成了市五届人大一次会议确定的年度目标和各项工作任务。抗击“非典”取得阶段性重大胜利，国民经济发展创十年新高，“三个转变”成效显著，社会事业全面进步，人民生活不断改善，社会形势保持稳定，实现了新一届政府工作的良好开局，迈出了全面建设小康社会的坚实一步。 会议指出，2 0 0 4 年是实现"十五"计划的关键一年。当前我市经济社会发展态势很好，我们要抓住机遇，加快发展。要深入贯彻党的十六大、十六届三中全会精神，坚持以人为本，树立科学的发展观，切实把工作重点转移到调整经济结构、转变增长方式、提高增长质量和效益上来，深化改革，扩大开放，加快"三个转变"，努力实现国民经济持续快速协调健康发展和社会全面进步。 会议强调，要把解决好农业、农村和农民问题作为政府工作的重中之重，认真贯彻落实中共中央、国务院一号文件关于增加农民收入、减轻农民负担的各项政策措施，深化农村改革，调整优化农业结构，大力发展农业产业化经营，加快农村基础设施建设，促进农村经济发展。要坚持走新型工业化道路，充分发挥工业比较优势，进一步增强支柱产业和重点企业带动力，增强技术改造和技术进步推动力，抓好重装基地建设，深化国有企业改革，提高工业经济效益和整体竞争力。要高度重视第三产业，加快旅游业和服务业发展，积极培育消费热点，进一步繁荣城乡市场。要加大经营城市力度，抓好重点项目建设，推进城镇化进程。要加快民营经济发展，进一步增强县域经济活力。要搞好人才资源开发，积极培养和引进优秀人才。要加强招商引资工作，积极发展外向型经济，提高对外开放水平。要做好财税金融工作，坚持科学理财，搞好银政、银企合作，加强社会信用体系建设。要努力扩大社会就业，加强社会保障体系建设，完善特困群体的救助机制，帮助下岗职工、失地失业农民和因灾因病致贫等困难群体安排好生产生活，不断提高人民群众生活水平。要坚持统筹兼顾、协调发展，认真实施科教兴市和可持续发展战略，促进科技、教育、文化、卫生、体育等各项社会事业全面进步，促进人与自然和谐发展。要加强精神文明和民主法制建设，抓好社会治安综合治理，维护社会稳定。要按照"为民、务实、清廉"的要求，切实加强政府自身建设，进一步转变政府职能，坚持依法行政和科学民主决策，大兴求真务实之风，抓好廉政建设，提高行政能力和管理水平，努力建设高效服务型政府。 会议号召，全市人民要高举邓小平理论伟大旗帜，认真实践"三个代表"重要思想，团结一致、振奋精神，坚定信心，抢抓机遇，奋发图强，为推进德阳发展新跨越而努力奋斗。 责任编辑：否 扫一扫在手机打开当前页 $(function(){ var qrcode = new QRCode(document.getElementById("qr_code"), { width : 132, height : 132 }); qrcode.makeCode(window.location.href); });
