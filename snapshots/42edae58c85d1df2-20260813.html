 区委常委会会议召开

 来源:秀屿新闻网

 时间：2026-08-05 16:40

 | 
 
 |

 | 
 
 |

 　 8月4日，区委书记朱建阳主持召开区委常委会会议，传达学习习近平总书记近期重要指示精神，全国扫黑除恶专项斗争视频会议精神，省委常委、宣传部部长张彦来秀调研精神，研究我区贯彻落实意见。会议审议了重点项目挂钩领导调整方案，听取了全面从严治党、生态环境突出问题整改、信访有关事项等工作情况汇报，并安排部署下一步工作。区领导孙云峰、林峰等参加。 
   会议强调，要守底线护稳定。始终保持高压态势，深化扫黑除恶专项斗争，紧盯新型涉黑涉恶违法犯罪，健全长效常治机制，建设更高水平的平安秀屿。深入践行“四下基层”优良传统，加大信访积案攻坚力度，完善矛盾纠纷多元化解体系，用心用情解决群众合理诉求，确保社会大局和谐稳定。 要压责任促进度。健全重点项目全生命周期保障机制，挂钩领导要下沉一线、靠前协调，强化资金、土地、用能等要素保障，全力打通堵点、破解难点，力促项目提速增效、早日投产。   要优生态补短板。清醒认识当前生态环境面临的形势，狠抓突出生态环境问题整改，坚持长短结合、系统施治、标本兼治，持续改善生态环境质量，让秀屿的天更蓝、海更清、岸更绿。   要强作风促发展。坚决扛起管党治党政治责任，持续深化正风肃纪反腐，激励干部担当作为、真抓实干，营造风清气正的政治生态，为秀屿“产港城人”融合高质量发展提供坚强政治保障。（黄德鑫）
