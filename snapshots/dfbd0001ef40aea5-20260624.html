&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;据中央纪委监察部网站3月3日20时消息，河北省委常委、秘书长景春华涉嫌严重违纪违法，目前正接受组织调查。 &nbsp; &nbsp; &nbsp; &nbsp; 澎湃新闻（www.thepaper.cn）了解到，早在2014年，河北当地早就有了景春华即将落马的传言。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;就在其落马的4天前，景春华还曾在会议上强调锲而不舍地推进作风建设。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;据河北新闻网消息，（河北）全省党委秘书长、办公室主任会议2月28日在石家庄召开。河北省委书记周本顺出席会议并讲话。河北省委副书记赵勇主持会议。河北省委常委、秘书长景春华在会上讲话。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;景春华在讲话中还强调，要深刻认识党委办公厅（室）特殊重要的地位作用，切实增强担当使命的自觉性、坚定性，要始终把学习贯彻总书记系列重要讲话作为头等重大的政治任务。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;景春华说，始终把抓落实作为党委办公厅（室）的最基本职能、最根本任务，扭住重点抓落实，整合力量抓落实，开拓创新抓落实，一钉到底抓落实，全力确保中央和省委决策落地生根。 &nbsp; &nbsp; &nbsp; &nbsp;&nbsp;人民日报不久前曝光了2014年12月26日召开的的河北省委常委民主生活会。会上，各位常委之间开展了严肃坦诚、辣味十足的相互批评。 &nbsp; &nbsp; &nbsp; &nbsp; 对景春华，河北省委常委们提出，在整治文山会海上，成绩很大，但与中央要求相比，差距还很大；在执行民主集中制方面存在一定差距，常委会发言少；老好人思想有所滋长，或多或少有船到码头车到站的思想；有时不拘小节，防微更要杜渐。 &nbsp; &nbsp; &nbsp; &nbsp; 景春华说，自己尽心尽力、如履薄冰，生怕工作出现疏漏，思想上更多把自己的角色定位在服从服务省委和书记省长上，主动谋划、积极建言不够。在工作作风方面，主要问题是小节细节把得不严。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;公开资料显示，景春华生于1956年2月，山东广饶人。1973年，景春华在开滦矿务局唐山矿四采区参加工作，开始了自己在河北40多年的工作经历。景春华从最基层的工人开始干起，还曾担任该矿区的青年突击队长。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;出色的表现让景春华开始步入领导岗位。1978年4月，景春华进入唐山矿党委组织部担任干事，并在5年之后升任组织部副部长。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1987年，景春华从开滦矿务局团委副书记的岗位上调任共青团唐山市委书记。在之后的十年间，景春华先后升任共青团河北省委副书记、书记。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1997年，景春华离开共青团系统，转任承德市委副书记（正厅级），开始了自己在承德的9年工作经历。从2001年到2006年，景春华担任承德市委副书记、市长。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2006年7月，景春华转任衡水市委书记。2年后，景春华来到河北省委工作，担任省委秘书长，并在2011年进入河北省委常委行列。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;景春华也成为十八大以来河北省第二名落马的省委常委。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2014年11月20日，中央纪委网站公布消息称，河北省委常委、组织部部长梁滨涉嫌严重违纪违法，目前正接受组织调查。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2015年01月27日，最高人民检察院经审查决定，依法对河北省委原常委、组织部原部长梁滨以涉嫌受贿罪立案侦查并采取强制措施。 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;盘点党的十八大以来落马的省部级高官，在景春华之前，在任或曾任省委秘书长的高达8人，他们分别是四川的李崇禧、郭永祥，江西的赵智勇，山西的聂春玉、杜善学，江苏的赵少麟，山东的王敏。而作为中央书记处原书记、中央办公厅原主任的令计划，更是被视为其中最大的一只“老虎”。 景春华简历
