&nbsp; &nbsp; &nbsp; &nbsp;
&nbsp; &nbsp; 11月14日,市委、市政府召开全市安全生产大会。市委书记、市人大常委会主任王浩主持会议并讲话,市委副书记、市长周连华讲话；市委常委、市纪委书记初炳玉,市委常委、政法委书记韩国祥分别就纪检监察机关加大安全生产执纪问责力度和政法机关加大“刑责治安”力度讲了意见,市委常委、市政府党组副书记杨洪涛通报全市安全生产情况；市人大常委会第一副主任王顶岐、市政协主席郭利民、市委副书记于海田,市委、市政府领导班子成员出席会议。
&nbsp; &nbsp; &nbsp; &nbsp;王浩指出,安全生产是人命关天的大事,是不可触碰的高压线、生命线和底线。各级务必牢固树立底线思维和红线意识,真正把安全生产作为“天字号”任务来抓,以铁的手腕和决心切实提高安全生产水平。要以最严肃的态度、最严格的标准、最严厉的措施,彻查彻改安全隐患。要抓住重点,突出重点领域、重点地区、重点企业,确保纵到底、横到边,不留任何死角和盲点。要抓排查、抓整改,狠抓具体细节和隐患排查整改,彻底消除安全漏洞。要抓标本兼治,用好安全生产和生态环保两个倒逼机制,强化政策引导,搞好产业统筹和园区规划,加快淘汰落后产能,推动产业、企业向中高端发展,从根本上提升企业安全生产水平。要抓执纪执法,持续加大“打非治违”力度,突出打击非法违法生产和严重违规违章企业,对拿职工群众生命当儿戏、践踏安全法律法规的,重拳出击、快侦快办、严惩不贷。
&nbsp; &nbsp; &nbsp; &nbsp;王浩强调,抓好安全生产,关键要落实最严格的安全生产责任制和责任追究制。各级党委、政府要扛起属地管理责任,切实做到守土有责、守土尽责。安监部门和行业主管部门要扛起监管责任,对违法违规行为严格依法按最高格查处,强力推动企业抓好安全生产。企业要扛起安全生产主体责任,严格按规定要求做好安全生产投入、专业人员配备、职工安全培训、隐患排查整改等方面的工作,确保各项安全防范措施不折不扣地落实。在责任追究上,要坚持顶格处罚、从严从重,全面推行“刑责治安”,典型事故实行挂牌督办、提级调查,处理结果公开曝光,坚决打赢安全生产这场硬仗,为加快转型发展、实现走在前列的目标创造良好环境。
&nbsp; &nbsp; &nbsp; &nbsp;周连华在讲话中指出,要更加牢固树立安全发展观念,坚持以问题为导向,重心下移、标本兼治,把安全生产各项工作抓紧、抓细、抓实。一要全面推进安全生产依法治理,强化刑责治安,严格安全生产目标责任考核,把安全生产依法治理各项要求落到实处。二要扎实开展安全生产隐患大排查、快整治、严执法集中行动,强化隐患排查,狠抓隐患整治,加强社会监督,确保取得实实在在的成效。三要深入开展危险化学品安全生产治本攻坚行动,抓紧出台全市化工产业结构调整和规范发展相关政策措施,严把项目准入关口,深度推进化工产业布局调整,推动化工行业凤凰涅槃、浴火重生。四要着力夯实企业安全生产主体责任,推行企业内部网格化安全管理,推动企业建立健全并严格遵守各项安全规章制度和标准规程,加强对企业安全生产管理能力评价,确保企业主体责任落实到位。五要着力提高本质安全水平,深入实施科技强安,夯实基层基础工作,筑牢高危行业的基础安全防线。六要统筹抓好油气输送管道、煤矿、非煤矿山、劳动密集型企业、建筑工地、民爆器材、公共消防、烟花爆竹、森林防火等重点行业领域的专项整治。
&nbsp; &nbsp; &nbsp; 会上,桓台县、张店区、临淄区、周村区作了表态发言。市直有关部门、单位主要负责人,市政府安委会成员单位主要负责人、分管负责人,各区县委书记、区县长及有关负责人,中央驻淄企业、省管企业及市属部分重点企业主要负责人,各区县化工、煤矿、非煤矿山、烟花爆竹、民爆物品、道路运输等行业领域重点企业主要负责人参加会议。
