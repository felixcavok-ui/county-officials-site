'''王祥喜'''（{{bd|1962年|8月||catIdx=Wang王}}），男性，[[汉族]]，[[湖北省|湖北]][[仙桃市|仙桃]]人，1983年7月参加工作，1987年4月加入[[中国共产党]]。大学学历，工程硕士，高级工程师。[[第十一届全国人民代表大会]]湖北地区代表<ref>{{cite web|title=第十一届全国人大代表|url=http://news.xinhuanet.com/ziliao/2008-03/03/content_7708230.htm?node=36628|publisher=新华网|accessdate=2014-01-07|archive-date=2014-01-10|archive-url=https://web.archive.org/web/20140110211415/http://news.xinhuanet.com/ziliao/2008-03/03/content_7708230.htm?node=36628|dead-url=no}}</ref>。[[中华人民共和国]]政治人物，第二十届中央委员<ref>{{Cite web|title=中国共产党第二十届中央委员会委员名单_滚动新闻_中国政府网|url=https://www.gov.cn/xinwen/2022-10/22/content_5720882.htm|website=www.gov.cn|access-date=2026-01-31|archive-date=2023-12-14|archive-url=https://web.archive.org/web/20231214002604/https://www.gov.cn/xinwen/2022-10/22/content_5720882.htm|dead-url=no}}</ref>。曾任[[中共湖北省委]]常委、政法委书记，[[国家能源投资集团]]董事长，[[中华人民共和国应急管理部|应急管理部]]党委书记、部长、[[国家消防救援局]]第一政治委员。

2026年1月31日，因涉嫌严重违纪违法，接受中央纪委国家监委纪律审查和监察调查。<ref>{{cite web |title=应急管理部党委书记、部长王祥喜被查 |url=https://content-static.cctvnews.cctv.com/snow-book/index.html?item_id=6403115846905537944&source=50001&sub_source=50001_006 |website=央视新闻|date=2026-01-31 |accessdate=2026-01-31 }}</ref>

==生平==

王祥喜在1983年从[[焦作矿业学院]]采煤系采煤工程专业毕业后，被分配到湖北省松宜矿务局工作，他历任猴子洞煤矿技术员、生产技术科副科长、科长、副矿长、矿长，松宜矿务局副局长、第一副局长。

1996年6月，任[[湖北省煤炭工业厅]]副厅长、党组成员。2000年2月，任[[湖北省煤炭行业管理办公室]]主任、党组书记；同年8月转任[[湖北省经济贸易委员会]]副主任、党组成员。2003年4月，调任[[湖北省质量技术监督局]]局长、党组书记。

2006年6月，出任中共[[荆州市]]委副书记、副市长、代理市长，次年3月任市长。2008年起担任全国人大代表<ref>{{cite news|title=全国人大代表信息-王祥喜|url=http://210.82.31.1:8084/delegate/viewDelegate.action?dbid=111558|accessdate=2013-04-05|newspaper=全国人大网}}{{Dead link}}</ref>。2010年5月，任中共[[随州市]]委书记、市人大常委会党组书记，次年1月任市人大常委会主任。2012年7月，任[[湖北省人民政府]]秘书长、党组成员，[[湖北省人民政府办公厅|省政府办公厅]]党组书记、主任<ref>{{cite web|accessdate=2014-06-09|url=http://district.ce.cn/newarea/sddy/201207/29/t20120729_23535476.shtml|title=王祥喜接替傅德辉任湖北省政府秘书长、办公厅主任|publisher=中国经济网|archive-date=2014-05-12|archive-url=https://web.archive.org/web/20140512221632/http://district.ce.cn/newarea/sddy/201207/29/t20120729_23535476.shtml|dead-url=no}}</ref>。

2017年6月，升任[[中共湖北省委]]常委，7月兼任省委政法委书记<ref>{{cite web |url=http://district.ce.cn/newarea/sddy/201707/18/t20170718_24274487.shtml |language= |title=王祥喜任湖北省委政法委书记 王晓东不再兼任(简历) |publisher=中国经济网 |date=2017年7月18日 |accessdate= |archive-date=2017年7月21日 |archive-url=https://web.archive.org/web/20170721003324/http://district.ce.cn/newarea/sddy/201707/18/t20170718_24274487.shtml |dead-url=no }}</ref>。

2019年3月，接替到龄退休的[[乔保平]]，出任[[国家能源投资集团]]董事长、党组书记。同时自2019年6月至2020年5月兼任[[中国神华能源]]董事长<ref>{{Cite web |title=中国神华(601088) 高管 |url=https://vip.stock.finance.sina.com.cn/corp/view/vCI_CorpManagerInfo.php?stockid=601088&Pcode=30594168&Name=%CD%F5%CF%E9%CF%B2 |website=新浪财经}}</ref>。

2022年7月，升任[[中华人民共和国应急管理部|应急管理部]]党委书记<ref>{{cite web |title=王祥喜同志任应急管理部党委书记 |url=https://www.mem.gov.cn/xw/yjyw/202207/t20220729_419340.shtml |website=中华人民共和国应急管理部 |accessdate=2022-07-29 |date=2022-07-29 |archive-date=2022-08-03 |archive-url=https://web.archive.org/web/20220803202412/https://www.mem.gov.cn/xw/yjyw/202207/t20220729_419340.shtml |dead-url=no }}</ref>。同年8月，兼任[[国务院安全生产委员会]]副主任、办公室主任<ref>{{Cite web|title=应急管理部党委书记王祥喜任国务院安委会副主任|url=https://www.thepaper.cn/newsDetail_forward_19410260|publisher=澎湃新闻|accessdate=2022-08-12|archive-date=2022-08-12|archive-url=https://web.archive.org/web/20220812192104/https://www.thepaper.cn/newsDetail_forward_19410260|dead-url=no}}</ref>。同年9月，任应急管理部部长<ref>{{Cite web|title=全国人民代表大会常务委员会决定任免的名单（2022年9月2日第十三届全国人民代表大会常务委员会第三十六次会议通过）|url=http://www.npc.gov.cn/npc/c30834/202209/c522812e660c48e1a228f8c3509295d3.shtml|work=中国人大网|date=2022-09-02|accessdate=2022-09-03|archive-date=2022-10-20|archive-url=https://web.archive.org/web/20221020162757/http://www.npc.gov.cn/npc/c30834/202209/c522812e660c48e1a228f8c3509295d3.shtml|dead-url=no}}</ref><ref>{{Cite web|title=中华人民共和国主席令（第一二一号）|url=http://www.npc.gov.cn/npc/c30834/202209/9ba27b7a6623418da4c3854866757f2f.shtml|work=中国人大网|date=2022-09-02|accessdate=2022-09-03|archive-date=2022-10-20|archive-url=https://web.archive.org/web/20221020162657/http://www.npc.gov.cn/npc/c30834/202209/9ba27b7a6623418da4c3854866757f2f.shtml|dead-url=no}}</ref>。2023年1月6日，兼任[[国家消防救援局]]第一政治委员<ref name="报道0106A">{{cite web |author1=人事司 |title=国务院任免国家工作人员（2023年1月6日） |url=http://www.mohrss.gov.cn/SYrlzyhshbzb/sydqjdxs/SYguowuyuanrenmian/202301/t20230106_492900.html |website=中华人民共和国人力资源和社会保障部 |accessdate=2023-01-06 |location=北京 |language=zh-hans |archive-date=2023-02-23 |archive-url=https://web.archive.org/web/20230223170738/http://www.mohrss.gov.cn/SYrlzyhshbzb/sydqjdxs/SYguowuyuanrenmian/202301/t20230106_492900.html |dead-url=no }}</ref>。

2026年1月，因涉嫌严重违纪违法，正接受中央纪委国家监委纪律审查和监察调查。<ref>{{cite web |title=应急管理部党委书记、部长王祥喜被查 |url=https://content-static.cctvnews.cctv.com/snow-book/index.html?item_id=6403115846905537944&source=50001&sub_source=50001_006 |website=央视新闻|date=2026-01-31 |accessdate=2026-01-31 }}</ref>

2026年2月26日，国家主席习近平签署主席令免去王祥喜的应急管理部部长职务。<ref>{{cite news |title=受权发布丨中华人民共和国主席令（第六十九号） |url=http://www.news.cn/20260226/7008f4e3c9fc4d8280568205ae7837b2/c.html |accessdate=2026-02-26 |work=新华网 |date=2026-02-26 |archive-date=2026-02-26 |archive-url=https://web.archive.org/web/20260226123751/https://www.news.cn/20260226/7008f4e3c9fc4d8280568205ae7837b2/c.html |dead-url=no }}</ref>翌日，[[中华人民共和国国务院]]决定免去其国家消防救援局第一政治委员职务。<ref>{{Cite web |title=国务院任免国家工作人员（2026年2月27日） |url=https://www.mohrss.gov.cn/SYrlzyhshbzb/sydqjdxs/SYguowuyuanrenmian/202602/t20260227_567638.html |website=中华人民共和国人力资源和社会保障部 |access-date=2026-02-28}}</ref>
