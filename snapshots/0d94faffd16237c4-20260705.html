# 张德江
# 来源: https://zh.wikipedia.org/wiki/%E5%BC%A0%E5%BE%B7%E6%B1%9F
# 抓取: 2026-07-05 维基百科 API (explaintext)

张德江（1946年11月4日— ），辽宁台安人，中国共产党、中华人民共和国政治人物，原正国级领导人。曾任中共第十六、十七、十八届中央政治局委员，中共十八届中央政治局常务委员会委员（排名第三），第十二届全国人大常委会委员长，中共中央港澳工作协调小组组长，中央国家安全委员会副主席。


== 经历 ==


=== 早年生涯 ===
张德江在1946年11月4日（农历丙戌年十月十一日）生于中国大陆辽宁省台安县，他在1968年11月，张德江响应中共中央关于“知识青年上山下乡”的号召，在吉林省汪清县罗子沟公社太平大队插队劳动；两年后，调汪清县革委会工作，任宣传组干事、机关团支部书记；并于1971年1月，加入中国共产党。1972年5月，张德江受推荐进入延边大学朝文系学习，成为工农兵学员，后担任过班级党支部书记；1975年毕业后，留校工作；历任延边大学朝鲜语系党总支副书记，校党委常委、革委会副主任。
1978年8月，张德江被派赴朝鲜民主主义人民共和国留学，就读金日成综合大学经济系，并任留学生党支部书记。1980年8月回国后，出任延边大学党委常委、副校长。1983年8月，张德江37岁才离开校园，出任中共延吉市（县级市）市委副书记，开启从政之路。


=== 主政地方 ===
1985年，升任吉林省延边州委副书记；于1986年8月调中央工作，出任民政部副部长、党组副书记；1990年10月，回到吉林任省委副书记、兼延边州委书记；1995年6月，升任中共吉林省委书记；1998年1月起，还兼任吉林省人大常委会主任。
1998年9月，中共中央宣布，调张德江接任中共浙江省委书记。四年后，2002年11月的中共十六届一中全会上，张德江当选中共中央政治局委员，跻身党和国家领导人。会后不久，即接替李长春出任中共广东省委书记，其中共浙江省委书记一职由时任浙江省长习近平接任。
在任中共广东省委书记期间，张德江提出泛珠三角构想。同时，广东省也曾发生不少重大事件；包括，2003年爆发的SARS事件、孙志刚事件，2005年的太石村罢免事件、东洲事件，以及后来的南方都市报案。张德江在对这些事件上的处理手法，受到《多维新闻》撰稿人刘逸明的质疑。《苹果日报》认为，在2003年春，张德江涉隐瞒非典型肺炎疫情，令疫症在港扩散。这次疫情造成1,755人染病、299人死亡，包括8名医护人员殉职。


=== 国务院副总理 ===
2007年10月的中共十七届一中全会，张德江连任中共中央政治局委员，并于2008年3月，进入温家宝政府出任国务院副总理（排名第三），兼任国务院安全生产委员会主任。任职期间，曾于2009年负责指挥造成108人死亡的黑龙江鹤岗新兴煤矿爆炸事故事故抢救、善后处理及调查工作；2010年8月，负责指挥河南航空8387号班机空难事故抢救、善后处理及调查工作；2011年在处理温州动车追尾事故中，安监局的官员称张德江下令制止残骸掩埋。
王立军事件发生后，2012年3月15日，中共中央免去薄熙来的中共重庆市委书记职务后，宣布由张德江兼任。这是张德江第四次出任中共省级行政区的一把手。张德江在重庆就任市委书记后随即改变了薄熙来主政重庆时的部分政策，比如重新允许重庆电视台播放商业广告和停止唱红打黑。


=== 全国人大常委会委员长 ===
2012年11月15日，66岁的张德江在中共十八届一中全会上当选中共中央政治局常委（排名第三），跻身最高领导层。2013年3月14日，在第十二届全国人民代表大会上接替吴邦国当选全国人大常委会委员长。2014年1月25日，出任中共中央国家安全委员会副主席。张德江任期内，全国人大废除了实行近50年的劳动教养制度，并通过《立法法》修正案，将立法公开原则写入法律。


=== 主管港澳工作 ===
2012年11月，中共十八届一中全会后，张德江接任因习近平成为中央政治局常委当选总书记而空缺的中央港澳工作协调小组组长职务，开始成为中国共产党和中央政府在香港和澳门的代表。
2017年2月，张德江和中共中央政治局委员、中共中央统战部部长孙春兰等中央港澳工作协调小组领导人，在深圳市与五大商会及多个建制派政党负责人会面，传达林郑月娥为政治局“唯一”支持的下届特首候选人。
2017年5月，张德江视察澳门，称赞澳门准确贯彻一国两制，严守《基本法》，维护中央主权安全与发展利益，又特别值得肯定的是澳门率先完成基本法第23条立法，将维护国家安全放在前列。


=== 卸任 ===
2017年10月25日，70岁的张德江在中共十九届一中全会后卸下中共中央政治局常委的职务，并在2018年3月举行的十三届全国人大一次会议后卸下全国人大委员长和中共中央港澳工作协调小组组长的职务退休，由栗战书和韩正分别接任全国人大委员长和中共中央港澳工作协调小组组长。


== 争议 ==


=== 行为争议 ===
2016年9月29日，一向立场亲中共兼有中资背景的《成报》，发表评论文章点名批评张德江，文章说主管港澳事务的中共中央港澳工作协调小组组长张德江，治港路线偏执强硬，搞敌我矛盾，造成社会严重撕裂，文章指出张德江主导的香港路线失误，错判形势及民情，全国人大“8.31决定”，导致“占中”爆发。
文章又指从2003年下令隐瞒非典型肺炎疫情，病毒从广东扩散至香港，造成近300名港人染病死亡，可算是“香港世仇”，又形容张是香港“灾星”，而张德江隐瞒疫情酿成大祸，广东省卫生厅厅长黄庆道等官员被罢免，但张获江泽民撑腰下不用问责。


=== 访问香港争议 ===
早于2016年5月17日至5月19日，张德江到访香港出席一带一路论坛，香港警方封闭多条道路，让张的车队更不止一次逆线行驶，导致交通出现挤塞和混乱，不守香港本地交通规则引人咎病。有香港众志成员拦截张德江车队。


=== 言论争议 ===
2017年5月27日，张德江出席纪念香港特别行政区基本法实施20周年座谈会，称“坚定不移推动‘一国两制’伟大事业继续前进。面对风险和挑战，要继续坚定不移贯彻落实基本法”、“要加强基本法宣传教育，在香港社会普遍树立起国家意识和法治意识，使广大香港同胞自觉尊重基本法、遵守基本法、捍卫基本法”、“树立国家和法治意识”。惟香港大律师公会前主席石永泰质疑有关说法：“中国法治排名比香港低这么多，为何还可以对香港法治指指点点？是不是很讽刺呢？”

== 家庭 ==
张德江出身于农民家庭，父亲因为会理发，上世纪70年代被延揽到吉林省委后勤做杂工，成为省委大院理发的师傅。

妻子辛树森。山东海阳人，1949年出生，本科就读于长春冶金建筑学院，研究生就读于东北财经大学，曾任中国建设银行副行长。
有一女儿
