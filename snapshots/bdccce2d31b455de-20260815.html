靳磊（1970年2月—），男，汉族，河南济源人，中华人民共和国政治人物，经济师。1992年7月参加工作，1999年10月加入中国共产党。曾任安阳市人民政府市长，中共德阳市委书记，中共四川省委常委、政法委书记、社会工作部部长、组织部部长等职务。现任中共广东省委常委、深圳市委书记。
== 生平 ==
== 早年及河南省 ==
1992年，毕业于武汉大学政治学系行政管理专业，7月进入河南省计经委经济研究所工作。
1996年7月，任河南省计划委员会财金处干部。
1996年9月，进入厦门大学财金系金融学专业学习，2002年6月获经济学硕士学位。
2004年8月，任河南省发展和改革委员会办公室副主任。
2009年2月，任河南省委、省政府机关事务管理局副局长。
2011年12月，任河南省发展和改革委员会副主任。
2015年4月，任中共周口市委常委、组织部部长。
2016年9月，任中共郑州市委副书记、秘书长，市委党校校长。
2018年9月，任中共安阳市委副书记、市人民政府市长。
== 四川省 ==
2019年12月，调任中共德阳市委书记。
2022年5月，当选中共四川省委常委，晋升副部级。同年7月，兼任省委政法委书记。
2024年1月，兼任省委社会工作部部长，至2025年6月。
2025年1月，不再担任省委政法委书记，转任省委组织部部长。
== 广东省 ==
2026年3月，调任中共广东省委常委、深圳市委书记。
