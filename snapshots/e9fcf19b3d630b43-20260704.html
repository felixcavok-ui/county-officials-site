山东厅级人事调整继续：日照、临沂市长换人
澎湃新闻
02-11 15:34
刘维寅（左）、刘星泰
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;山东省厅级人事调整仍在继续进行。
&nbsp; &nbsp; &nbsp; &nbsp;&nbsp;山东省商务厅门户网站发布消息称，“2月11日，佘春明厅长在济南会见韩国驻青岛总领事馆黄胜炫总领事一行”。而该网站“厅领导分工”一栏则显示佘春明现任商务厅党组书记一职，“领导商务厅全面工作”。
&nbsp; &nbsp; &nbsp; &nbsp; 这意味这佘春明（1963.03）已正式履新山东省商务厅。
&nbsp; &nbsp; &nbsp; &nbsp; 佘春明原任济宁市委常委、济宁高新技术产业开发区党工委书记，1月24日被确定为提拔交流担任省直经济部门正厅级领导职务的干部人选考察对象。
&nbsp; &nbsp; &nbsp; &nbsp; 据中国经济网消息，此前山东省商务厅党组书记、厅长职务是由王华出任。
&nbsp; &nbsp; &nbsp; &nbsp; 此外，山东省编办领导职务也发生变更。
&nbsp; &nbsp; &nbsp; &nbsp; 据山东省机构编制委员会办公室网站消息，2月9日，该省编办召开全办干部会议。山东省委组织部副部长马晓磊出席会议，宣布省委关于省编办主要负责同志调整决定，刘维寅由省编办副主任升为主任，刘星泰（1963.01）任日照市委副书记，提名为日照市市长候选人，不再担任省编办主任职务。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;《人民日报》1月27日头版文章《从先进中找落后 从成功中找隐患 山东改革坚持问题导向》中提到，“‘把省政府的3亿美元审批权全部下放到设区市’。这个力度，让省编办副主任刘维寅直呼’没想到’。”
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;2月10日上午，日照市十七届人大常委会举行第二十一次会议，决定任命刘星泰为日照市副市长、代市长。会议并接受了李同道（1964.04）市长、钱焕涛（1963.08）副市长及有关市人大常委会组成人员的辞职请求。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;李同道早前接任了陈伟的枣庄市委委员、常委、书记职务。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;此前，澎湃新闻独家从枣庄市委获悉，陈伟一月份已被免职，去向不明。2月8日，齐鲁网报道称，陈伟被免去枣庄市委书记、常委、委员职务。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;另据山东省经济和信息化委员会官方网站“领导分工”栏目，钱焕涛的描述具体显示为“党组书记，主持全面工作”。中国经济网称，原任山东省经信委党组书记、主任的是郭述禹。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1月24日，山东省组织部曾公示干部考察预告，“根据《党政领导干部选拔任用工作条例》规定，在民主推荐的基础上，经研究，确定李同道同志为交流担任市委书记人选考察对象，钱焕涛同志为提拔交流担任省直经济部门正厅级领导职务的干部人选考察对象”。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;此外，据山东临沂琅琊新闻网消息，2月10日上午，临沂市十八届人大常委会第二次全体会议决定任命张术平（1964.01）为临沂市副市长；表决并通过了市人大常委会主任会议关于提请接受陈先运（1962.09）辞去临沂市市长职务的议案，接受陈先运辞去临沂市市长职务的请求。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;同日，上述会议第三次全体会议表决并通过了市人大常委会主任会议关于提请决定张术平为临沂市代市长的议案，决定张术平为代市长。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;张术平调任临沂代市长前曾任枣庄市市委副书记、市长。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;据2月8日晚《枣庄新闻》节目报道，2月7日下午5点，枣庄市领导干部会议召开，山东省委组织部副部长、省国资委党委副书记时培伟宣布省委决定：张术平不再担任枣庄市委副书记、常委、委员职务，李峰（1961.01）任枣庄市委委员、常委、副书记。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;李峰在调任枣庄市委副书记前任临沂市委副书记。《临沂日报》1月26日曾发布干部考察预告，山东官方确定李峰为提拔交流担任地级市市长人选考察对象。
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;经过此番调整，目前山东省各地级市领导岗位中尚有济南市委书记、枣庄市市长职务空缺。
