 if (str2 == "s") {
 return str1 * 1000;

 } else if (str2 == "d") {
 return str1 * 24 * 60 * 60 * 1000;
 }
}

                     2004年1月3日在浦城县第十四届 人民代表大会第一次会议上 
 各位代表：
 现在，我代表浦城县人民政府向大会作工作报告，请予审议，并请县政协委员和列席会议的同志提出宝贵意见。
 一、过去五年工作的回顾
 县十三届人大一次会议以来的五年，是我县改革、建设、发展史上不平凡的五年；是县域经济实力迈上一个新台阶，支柱产业不断壮大，城乡面貌日新月异，人民群众安居乐业，社会事业焕发勃勃生机，三个文明建设协调发展的五年。五年来，我们在县委的正确领导下，在县人大、政协的监督支持下，高举邓小平理论伟大旗帜，认真实践“三个代表”重要思想，紧紧围绕富民强县的目标，突出发展第一要务，团结带领全县人民，解放思想，与时俱进，真抓实干，胜利完成
“九五”计划，实施“十五”计划取得重大进展，开创了经济和社会发展的崭新局面。
 --过去的五年，是县域经济快速发展，综合实力明显增强的五年。面对经济转轨的新形势，全县上下坚持加快发展不动摇，奋力推动国民经济步入快速健康发展的新阶段。预计2003年，全县国内生产总值继续高位攀升，完成19.19亿元，比增12.1%，比98年增长45.72%，年均递增7.8%，其中，一、二、三产业增加值分别为8.04亿元、5.21亿元、5.94亿元，分别年均递增4.3%、10.9%和10.5%。财政收入持续快速增长，实力逐年增强，财政总收入完成1.32亿元，其中，地方级财政收入7781万元，（同口径计算）分别比增18.61%和25.85%，比98年分别增长45.05%和30.3%，分别年均递增7.72%和5.45%，确保增资政策和工资按时足额兑现；全县税性收入占地方一般预算收入比重达78.26%，比98年提高15.2个百分点。全社会固定资产投资大幅增长，完成9.3亿元，比增50%，比98年增长144.74%，年均递增19.6%。社会消费品零售总额完成7.6亿元，比增15%，比98年增长55.1%，年均递增9.2%。金融各项存款余额20.1亿元，年均递增11.86%。
 --过去的五年，是产业调整不断加快，经济结构明显优化的五年。具有浦城特色的县域经济结构初步形成。工业发展后劲和主导作用显著增强，以精细化工为龙头的林产、矿产、食品四大支柱产业，对工业增长贡献率大幅提高，一批规模工业企业不断成长壮大。预计2003年，四大支柱产业预计实现产值11.5亿元，占全县工业总产值的比重由98年48%提高到78%；规模工业企业从98年17家发展到41家，完成工业产值8.7亿元，比增40%，比98年增长105.25%，年均递增15.5%，工业经济效益指数连续五年位居全市前列；南浦生态工业园区势头迅猛，完成一期开发建设2200亩，基本实现“六通一平”，先期入园企业17家，其中7家企业建成投产，成为工业经济快速增长最大的新“亮点”；非国有工业发展迅速，比重占全县工业总产值的86.3%，第二产业对国民经济贡献率达42.7%。农业产业化进程明显加快。优质米、笋竹、乳牛、菌菜、烤烟等“八大产业”成为农村经济的重要支柱。预计2003年，农林牧渔业总产值12.0亿元，比增8.6%，其中“八大产业”产值9.22亿元，占农林牧渔业总产值的比重由1998年的54%提高到77%；粮经产值比例由98年的70.2:29.8调整为59:41，农产品优质品率上升到60%。龙头企业加速发展壮大，年销售收入500万元以上龙头企业达到42家，比98年增加38家，其中省市级龙头企业12家，农民从产业化中实现人均增收220元；农村劳动力转移力度加大，农村二、三产业正成为农民增收的主渠道，农民人均非农收入2071元，年均递增12.42%。商贸流通、旅游、金融等第三产业繁荣活跃。完成新建、扩建专业市场5.07万平方米，发展超市、连锁经营16家；旅游业取得重大突破，编制完成《浦城县旅游发展总体规划》，总投资1亿元的浮盖山风景区及配套服务区开发建设正式启动；房地产、中介、社区服务等新兴服务业发展迅速。第一、第三产业对国民经济贡献率分别达到28.89%和28.41%。
 --过去的五年，是体制改革纵深推进，对外开放明显扩大的五年。围绕建立健全社会主义市场经济体制，以“产权制度和职工身份两置换”为切入点，以加快企业重组盘活为目标，基本完成工业、林业、粮食、商业、供销、二轻等国有、集体企业改革重组，置换职工身份6996人，重新就业5300多人，发展了华瑞化工、绿康生化、丽浦中纤板等一批骨干企业，极大地推进了企业民营化进程。农村经济体制和工作机制创新不断突破，集体林权制度改革稳步推进，统分结合的双层经营体制进一步完善，金融信贷支农机制成效显著，发放信贷支农资金3.1亿元，并率先在全市创建九牧信用镇。新一轮县乡财政管理体制改革进展顺利，农村税费改革基本完成，较好实现村村减负、户户受益的目标。县乡党政机构改革基本完成，行政审批制度改革完成削减行政审批事项148项。全面推行土地有偿使用制度改革，所有经营性用地项目和矿业开采权一律纳入招标拍卖，土地出让项目性收入居全市前列。教育改革逐步深化和完善，建立新的中心小学管理体制，创办民办清华中学，民办教育取得了新的突破。文化、卫生、科技、广电等改革明显加快。大力实施“南接北连”的对外开放战略，积极融入长三角发达地区，全方位扩大对外开放，外经贸工作位居全市前列。五年共新增“三资”企业21家，完成实际利用外资6734万美元，外贸出口总额1.16亿美元，年均分别递增11.7%、18.3%；引进山海协作资金6.5亿元，年均递增78.6%。
 --过去的五年，是固定资产投资强劲增长，城乡面貌明显变化的五年。坚持实施项目带动战略，深入开展“项目开发年”和大竞赛活动，累计完成全社会固定资产投资27.19亿元，为前五年投资总额近两倍。全县共落实生产性项目382个，完成项目投资8.03亿元，培育了一大批经济增长点，极大增强了经济发展后劲。与此同时，一批重大基础设施项目相继竣工，花古两条入闽战备通道全线建成通车，花城线获全省重点项目建设优胜奖，完成5个乡镇、33个村公路硬化改造，浦南高速公路即将动工，县乡公路等级明显提高。城区防洪工程建设基本实现全线闭合，并顺利通过省级验收，防灾减灾能力得到加强。农村电网改造工程基本完成，并获全省第一名，城网改造开始启动，全社会投资小水电开发势头强劲，新增装机容量1.41万千瓦时，为缓解电力紧缺和抗旱蓄水发挥了重要作用。城镇建设步伐加快，全面完成县城和5个建制乡镇总体规划编制，积极探索城市资产经营，实现以地聚财、以城养城。累计投入7.16亿元资金，先后高标准完成滨江一期、浦林、安华广场、怡源小区及道路、供水、交通、绿化、防洪、排污、夜景灯改造等一批建设项目；河滨二期旧改拆迁和怡源大酒店建设进入实质性阶段。城区规划面积扩大到26平方公里，新增城区人口3.34万人、公共绿地4.8万平方米。仙阳、石陂、临江等集镇建设取得明显成效，带动功能进一步发挥，城镇化水平逐年提高。
 --过去的五年，是社会各项事业全面进步，群众生活水平明显提高的五年。精神文明建设创建活动深入开展，公民道德水准和文明素质进一步提升，先后荣获省级卫生县城，第七届、第八届省级文明县城称号。认真实施“科教兴县”和可持续发展战略。科技创新能力和技术成果承接转化、推广能力不断增强，科技进步对经济增长的贡献率达45%。教育“两基”成果连续五年以较高标准通过省、市跟踪督查验收，城乡中小学布局调整、教育资源优化整合及危房改造步伐加快，累计投入资金3925万元，新建、改建校舍10万平方米。加快实施人才战略，在财政困难情况下，对本科人才全部予以分配，并公开招聘一批大中专毕业生，其中教育系统43人，卫生系统25人，为经济社会发展提供了智力支持。文体、广播电视事业健康发展，以《丹桂情》、《梦笔江郎》为代表的一批优秀剧目，获得了国家和省级大奖，全面完成赣剧院改造，全民体育健身活动蓬勃发展；广电事业基本完成“网台分营”，广电信号人口覆盖率达98.7%，城乡电视光缆实现联网。计生工作连续多年保持全国、全省先进水平，先后荣获全国计生协会先进单位、全省计生“三为主”先进县和计生一类县称号。卫生初级保健通过省、市达标验收，农村公共卫生建设力度加大，县医院门诊综合大楼建成投入使用，群众健康水平普遍提高，防治“非典”取得阶段性胜利，为全省、全市做出贡献。土地执法管理和城乡环境综合整治工作走上法治化、规范化轨道，分别荣获“全国土地执法模范县”和
“全国环境综合整治优秀县”称号。城乡居民收入不断增加。预计2003年，预计城镇居民人均可支配收入7015元，比增7.2%，农民人均纯收入3420元，比增9.0%，两项收入分别比98年增加1808元和806元，年均递增6.1%和5.5%；城乡居民储蓄余额达16.8亿元，比98年增长78.8%，年均递增12.23%。群众消费结构和生活质量不断提高，住房、旅游、医疗保健、文教娱乐等支出的比重逐年增加，尤其是住房条件明显改善，城镇和农村人均居住面积分别达35.14平方米和36.01平方米。城镇养老、失业保险及城市低保实现基本覆盖，累计发放低保资金436万元、失业保险金1765万元，困难群众的基本生活得到了有效保障。五年来，共筹集下岗职工基本生活费181.7万元，基本养老金全面实现社会化发放，医疗保险参保人数扩大到1.6万多人。就业和再就业工作成效明显，新开发公益性岗位256个，新增城镇就业6300 人，城镇登记失业率控制在5.6%。扶贫开发、防灾救灾和经常性社会救助工作力度加大，实施“造福工程”35个村2313人。

 二、今后五年奋斗目标和主要任务
 今后五年，是我县在新世纪初加快发展，深入推进全面建成小康社会，开创大开放、大改革、大发展新局面的重要战略机遇期。根据县第十次党代会确定的奋斗目标和任务，政府工作的指导思想是：高举邓小平理论伟大旗帜，全面贯彻“三个代表”重要思想，认真落实党的十六大和十六届三中全会精神，按照全面建成小康社会和建设“南接北连的生态经济走廊”的总体要求，以加快发展为主题，以结构调整为主线，以改革开放和科技进步为动力，以发展民营经济为重点，以提高人民生活水平为根本目的，认真实施项目带动战略，全方位融入长三角经济格局，大力推进工业化、农业产业化和城镇化的进程，努力实现三次产业、城市与农村、经济社会与生态环境、物质文明与政治文明、精神文明的快速协调发展。
 根据上述指导思想，今后五年，浦城经济社会发展预期目标是：经济实力显著壮大。到2008年，国内生产总值达到33.82亿元，年均增长12%，圆满完成“十五”计划，制定并实施“十一·五”计划；地方财政收入达1.22亿元，年均增长10%；全社会固定资产投资15亿元，年均增长10%。产业结构显著优化。三次产业的比例调整为28:39:33，第二、三产业的主导作用更加凸显。对外开放水平显著提高。完成外贸出口总值4606万美元，实际利用外资3339万美元，年均增长均为10%。人民生活显著改善。城镇居民人均可支配收入和农民人均纯收入年均递增均为6%，分别达9388元和4577元；城镇登记失业率控制在6%以内。可持续发展能力显著增强。人口自然增长率控制在8‰以内。城乡群众思想道德、科学文化和健康素质显著提高。
 围绕实现上述预期目标，今后五年的主要任务是：

 三、2004年工作建议
 2004年是新一届政府施政的开局之年，也是实现五年奋斗目标极为重要的起步之年。全县经济发展的主要预期目标是：国内生产总值增长12%；全社会固定资产投资增长16%；社会消费品零售总额增长13%；地方级财政收入增长10%；合同利用外资增长10%；实际利用外资增长10%；外贸出口增长10%；城镇居民人均可支配收入增长7%，农民人均纯收入增长7%，城镇登记失业率控制在6%以内；人口自然增长率控制在7‰ 以内。为全面完成2004年各项任务，要始终按照中央“五个统筹”、“五个坚持”的要求，大力实施“六大工程”，扎实抓好“十大项目”，认真做好“九项工作”。
 （一）实施“六大工程”。着力抓好事关长远发展的基础性项目和与群众生活密切相关的重大公益性项目建设，统筹城乡经济社会事业发展，有效改善经济发展和人民生产生活环境。一是推进总投资32亿元浦南高速公路浦城段控制性工程2004年底动工建设。二是用三至五年时间全面改善农村道路，2004年要完成“百公里”农村公路硬化改造，解决制约农民增收和出行难的问题。三是加强农村公共卫生和饮水工程建设，合理布局、优化配置城区卫生资源，扩建县传染病房，建设县疾病预防控制中心。四是建设县教育信息网络中心，推进成人和职业技术教育，实施浦二中的扩建和三中的完善，改造农村校舍危房面积1万平方米以上。五是全面改造城区电视网络，扩大乡村电视网络联网面达60%以上；建成县体育健身中心。六是拓宽改造上青岭至千里马路面工程，建设城市垃圾处理场，推进江滨二期改造和怡园新区建设，完成江滨三期城防工程的全线闭合，打通江滨大道。
 （二）狠抓“十大项目”。2004年要全面落实好以下十大新经济增长点项目：①推进总投资1.5亿元的南浦生态工业园区二期扩建；②推进总投资1.5亿元华瑞化工新上项目的扩建；③推进总投资5000万元绿康生化系列项目扩建；④推进总投资8000万元正大生化新区项目的建设；⑤推进总投资500万美元红豆杉种植及紫杉醇提取加工项目的建设；⑥推进总投资1亿元浮盖山旅游风景区的建设；⑦推进总投资5500万元怡源大酒店的建设；⑧全面动工兴建总投资1.5亿元蒋溪口、观前两大电站；⑨着手实施总投资1.6亿元南浦生态工业园区商贸中心区的建设；⑩积极推进总投资1亿元绿波湖工程的建设。
 （三）做好“九项工作”：
 1、走工业兴县强县之路，调优结构突出民营突破工业，进一步扩张经济总量。一要大力发展民营经济。以“提升地位、提升比重、提升水平”为目标，全面落实扶持发展民营经济的政策措施，充分调动和支持民营经济进入农业、旅游、文化、教育等领域，特别是引导、保护和服务好民营工业发展，大上快上一批高新技术或劳动密集型企业，壮大民营工业队伍，培育工业经济主力军。选择确定一批投资300万元以上具有广阔市场前景、良好信誉度的民营企业，实行县领导、部门和金融机构“三挂钩”，帮助企业加快技术、制度、经营和管理创新，向外向型、股份制、规模化转变，争取培植1-2家民营工业集团。与此同时，放手发展“四个一批”，形成民营工业“百花齐放”，即积极开展招商引资，利用县外资金兴办一批，加快国有集体企业改制重组一批，引导民营企业加速积累自我扩张一批，鼓励干部职工领办创办一批，促进民营经济蓬勃发展。二要做大做强规模工业。着力发展5个以上产值上亿元或利税上千万的工业“龙头”。突出抓好正大生化、华瑞化工、绿康生化、丽浦中纤板等重点企业的扩张，在资金、电力、土地、技术等生产要素上实行重点倾斜，迅速壮大一批骨干规模工业企业。鼓励企业加强技改创新，不断开发新产品、新技术、新项目，全年完成技改投资9600万元，实施“五新”项目10项以上，创立1-2个国家、省级名牌，促进产业、产品结构的优化升级。大力发展乡镇企业，加快企业机制转换和资产重组，全年各乡镇至少新增1家投资300万以上的工业企业。三要强力打造工业平台。在现有开发2200亩基础上，继续完善园区配套基础设施建设，完成园区二期两条次干道硬化、自来水管道铺设及11万伏变电所建设，扩张园区面积5000亩以上。严格落实项目入园的责任制，以园区为平台，大引项目、引大项目入园，尽快使园区布满项目，争取园区全年新增项目8个以上，投资超亿元，实现年产值2亿多元，创利税3000万元。在抓好奔马工艺品、金辉木业、永芳香料等7家已投产企业全面达产达效的同时，重点加快萨迦体育用品、闽城光学眼镜、华星农机、旭禾米业、阳光木业等10家入园企业建成投产，促成意向入园项目落地生成。做到引进一个新项目，建成一个新企业，开发一片新土地，形成一个新增点，培育一个新产业。通过2-3年努力，实现园区工业产值10亿元，利税1亿元。四要加快企业重组盘活。认真总结我县近年来国有集体企业实现重组盘活的成功经验和做法，坚持盘活存量，吸引增量，扩大总量的原则，思想再解放一些，政策再优惠一些，进一步加大未改制企业闲置土地、厂房、设备等资产的盘活力度，积极引进国内外企业和集团，采取引资嫁接、产权转让、收购兼并等多种手段，不求所有，只求所在，加速国有资产从竞争性领域退出，实现企业产权大重组、资产大整合、市场大拓展、活力大增强，促进工业经济的运行质量进一步提高。
 2、加快推进农业产业化，重抓龙头培育特色提高效益，进一步增加农民收入。一要培育壮大龙头企业。以市场为导向，以产业化为重点，按照“引外、扶强、兴小、育新”的要求，突出发展加工、流通和专业市场型的龙头企业，加速推进农业产业化经营。对目前已具备一定规模的华美乳业、仙楼竹制品、仙泉啤酒、望丰米业、绿洲、盛龙食品等龙头企业，要在系列产品研制开发、市场开拓上下功夫，千方百计做强做大，力争有1-2家产值超亿元，实现创利税上千万元，形成支撑农村经济的“台柱子”。进一步加强全县龙头企业建设，组建专门的领导机构，落实扶持龙头企业的各项优惠政策，培育和催生新兴龙头企业，重点抓好白鹅、水产品和山茶油等规模龙头企业的新建，使全县各类龙头企业发展到100家以上，其中争取进入国家和省市级15家。全年实现经营产值5亿元，创利税3500万元，带动农户8万户，发展各类基地50万亩，农民从产业化中实现人均增收280元。二要大力发展特色产业。围绕区域化布局、标准化生产、产业化经营，在继续抓好“八大产业”的同时，大力发展绿色、特色、生态、优高农业，着力培育2-3个支柱产业。重点发展优质稻28万亩，优高经济作物22万亩以上，其中突出抓好烟叶产业面积落实和技术服务指导，力争完成5万担目标，实现增产增收。加快发展以乳牛为重点的畜禽业，千方百计扩张乳牛养殖规模，力争发展乳牛4000头，带动发展白鹅220万只、稻田鱼等特色水产养殖6.5万亩，使畜牧水产产值占农业总产值的比例上升到32%。加大山地经济开发，加强100万亩生态公益林管护，发展珍稀树种、工业原料林、毛竹丰产高效、大径材四大基地3.9万亩，抓好银杏、锥栗、花卉、中药材等特色经济林的规模种植，提高林业经济效益。加强农业科技示范园区建设，建成示范面积1000亩，带动相关产业发展。三要狠抓基地规模建设。坚持示范带动，典型引路，着力抓好一批高标准、高要求、高技术含量连片基地20万亩以上，其中优质稻示范基地7.5万亩、优高经济作物2万亩、毛竹示范基地7.5万亩和优高水产养殖基地1万亩。着手建立农产品质量标准和检测检验体系，积极发展绿色食品和名牌农产品，建立龙头企业的农产品无公害基地30万亩以上，新培育省市优质农产品品牌2个、绿色农产品品牌1个以上。通过基地建设，为龙头企业提供充足的加工原料，农民从基地上获得更多收益。四要健全完善农村服务体系。充分发挥科技特派员工作站、县农副产品流通信息中心及乡镇流通信息站的作用，进一步整合、改造、新建农村经济中介组织，有效提高农村生产和流通组织化程度，推动农业优良品种引进、先进实用技术推广和大宗农副产品的流通经营。深化城镇户籍、教育制度改革，加快农村富余劳动力向二、三产业转移，争取全年转移农村劳动力新增1-2万人，实现人均非农收入2155元。加强以农田水利为重点的农业基础设施建设，抓好570米城区防洪工程和8座病险水库除险加固，继续实施中低产田改造和万亩土地二期整理，深入开展山地水利建设，全县新建2000个以上山地蓄水池，扩大旱涝保收和高产稳产农田面积5万亩，增强农业可持续发展能力。
 3、着力提升第三产业水平，发展旅游搞活流通拓展城区，进一步拉动经济快速增长。一要进一步完善城镇规划和建设。坚持大手笔规划，高起点建设，全面完成县域城镇体系规划、控制性详规、近期规划以及城市燃气、公共交通规划的编制。加强城市基础设施建设，集中力量抓好河滨二期、怡源小区等一批新建、续建项目，着手实施兴浦路延伸205国道路段建设，进一步完善城区路网构架。加强城市无形资产的经营，组建城市资产运营中心和城市出租车公司，规范城市主街道空间广告、液化气经营点、出租车、公厕等城市特许经营权，加大土地收储和使用权招标拍卖力度，盘活土地存量，增加城市建设投入。整顿规范小区物业管理，加强市容市貌、街区卫生、交通秩序综合治理，努力提高城市管理水平，改善人居环境。二要推动旅游经济快速发展。在全县旅游总体规划框架内，完成浮盖山、匡山、九石渡“二山一水”三大景区详规的专家论证评审工作，积极抓好浮盖山景区升级国家4A级景区或国家级地质公园，匡山省级风景名胜区或国家级森林公园的申报工作。全力支持浮盖山景区和服务区内水、路、电、讯等配套设施建设，力争在2005年元旦前正式对外接待游客。与此同时，注重开发具有浦城特色的旅游土特产品和工艺品，加大旅游宣传和促销力度，实现旅游产业相关收入3000万元以上。三要推进流通现代化。立足我县三省七县（市）边界优势，引导社会资金参与流通设施建设，加快专业市场建设和改造步伐，不断完善城区现有爱民、跃进、新华、城西等市场功能，完成城区牲畜屠宰场搬迁建设，年内形成3万头猪牛羊屠宰规模。加快县蔬菜批发市场升级改造，完善农药检测中心、净菜加工、物流配送等建设。积极发展连锁经营、现代物流业和网上购物等现代经营方式，创造条件把县购物中心发展成城区大型超市，并鼓励引导城区超市向主要集镇延伸，形成连锁经营网络。鼓励企业通过自由连锁、集中配送等形式，构建企业自我完善的商贸流通服务体系，促进传统商业向现代商业转变。
