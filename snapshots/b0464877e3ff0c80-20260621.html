'''张剑飞'''（{{bd|1962年|11月|catIdx=Z张}}），男，汉族，[[湖南省]][[邵东市]]人。中华人民共和国政治人物。1983年8月参加工作，1994年10月加入[[中国共产党]]。[[同济大学]]道路与交通工程系道路工程专业毕业，[[加利福尼亚大学伯克利分校]]运输工程专业博士研究生学历<ref name="sifh" >{{cite web |url=http://www.chinadaily.com.cn/hqcj/zxqxb/2012-06-11/content_6152140.html |title=资料：长沙市市长张剑飞简历 |accessdate=2012-06-11 |publisher=中国日报网 |work= |language=zh-cn |archive-url=https://web.archive.org/web/20150924122749/http://www.chinadaily.com.cn/hqcj/zxqxb/2012-06-11/content_6152140.html |archive-date=2015-09-24 |dead-url=yes }}</ref>。曾任[[长沙市人民政府]]市长，[[湖南省人民政府]]副省长，[[中国共产党湖南省委员会|中共湖南省委]]常委、秘书长，[[湖南省人大常委会]]副主任等职。

== 生平 ==
1979年9月至1983年8月，张剑飞在[[同济大学]]道路与交通工程系道路工程专业学习<ref name="sifh" />。1983年8月至1987年7月任[[中华人民共和国交通部]]公路规划设计院助理工程师。1987年7至1991年5月在美国[[加利福尼亚大学伯克利分校]]土木工程系运输工程专业学习，先后获工学[[硕士]]和[[博士]]学位。1991年5月至1992年8月任[[世界银行]]中国蒙古局交通运输处交通运输规划师。

1992年8月至1995年1月任交通部公路规划设计院副总工程师。1995年1月至1995年8月任交通部公路规划设计院院长助理。1995年8月至1998年3月任[[中华人民共和国交通部|交通部]]公路规划设计院副院长。1998年3月至2001年9月任交通部规划研究院副院长。2001年9月至2003年6月任交通部规划研究院院长。2003年6月至2007年11月任交通部公路司司长，其间于2006年9月至2007年1月在[[中共中央党校]]进修班学习。

2007年11月，张剑飞回到家乡湖南，任[[中国共产党长沙市委员会|中共长沙市委]]副书记、[[长沙市人民政府]]代理市长。2008年1月至2013年11月任中共长沙市委副书记、长沙市人民政府市长<ref name="sifh" />。

2013年11月任[[湖南省人民政府]]副省长<ref>{{cite web|url=http://www.hunan.gov.cn/zw/zfld/zjf/grjl_55060/201312/t20131202_1379227.html|title=副省长张剑飞简历|accessdate=2015年9月13日|publisher=湖南省人民政府门户网站|work=|language=zh-cn|deadurl=yes|archiveurl=https://web.archive.org/web/20151225052332/http://www.hunan.gov.cn/zw/zfld/zjf/grjl_55060/201312/t20131202_1379227.html|archivedate=2015年12月25日|df=}}</ref>，晋升副部级。2013年12月不再担任长沙市长职务<ref>{{cite web|accessdate=2014-06-09|url=http://district.ce.cn/newarea/sddy/201312/20/t20131220_1965754.shtml|title=张剑飞不再担任长沙市委副书记 将卸任市长|publisher=中国经济网|archive-date=2020-11-21|archive-url=https://web.archive.org/web/20201121183951/http://district.ce.cn/newarea/sddy/201312/20/t20131220_1965754.shtml|dead-url=no}}</ref>。2017年7月兼任湖南省人民政府国有资产监督管理委员会党委书记，2017年12月升任中共湖南省委常委。2018年1月28日，不再担任湖南省副省长职务。

2019年5月，任[[中国共产党湖南省委员会|中共湖南省委]]秘书长。2021年11月，不再担任中共湖南省委常委。

2022年1月，当选为[[湖南省人大常委会]]副主任<ref>{{cite web|accessdate=2022-01-19|url=http://district.ce.cn/newarea/sddy/202201/19/t20220119_37271526.shtml|title=张庆伟当选湖南省人大常委会主任 谢建辉、张剑飞、陈文浩当选副主任|publisher=中国经济网|archive-date=2022-01-21|archive-url=https://web.archive.org/web/20220121071709/http://district.ce.cn/newarea/sddy/202201/19/t20220119_37271526.shtml|dead-url=no}}</ref><ref>{{cite web |title=湖南新一届省人大常委会主任、副主任简历(主任张庆伟) |url=http://district.ce.cn/newarea/sddy/202301/18/t20230118_38354447.shtml |website=中国经济网 |publisher=[[湖南日报]] |accessdate=2023-10-30 |date=2013-01-18 |archive-date=2023-08-06 |archive-url=https://web.archive.org/web/20230806173054/http://district.ce.cn/newarea/sddy/202301/18/t20230118_38354447.shtml |dead-url=no }}</ref>。2026年2月，到龄辞任<ref>{{Cite web |title=湖南省第十四届人民代表大会第四次会议关于接受张剑飞辞去湖南省第十四届人民代表大会常务委员会副主任职务请求的决定 |url=https://m.hnrd.gov.cn/content/646046/99/15685164.html |website=m.hnrd.gov.cn |access-date=2026-05-09}}</ref>。

== 荣誉与违纪 ==
张剑飞是交通部1985年度新长征突击手，北京申办2008年奥运会交通问题陈述人，2004年主持了国家高速公路网的规划。

2015年12月，因为[[中央八项规定|组织、参加用公款支付的旅游、宴请等]]，受到党内严重警告处分，责令退赔相关费用，所收礼金予以收缴<ref>{{cite news|accessdate=2015-12-21|url=http://district.ce.cn/newarea/sddy/201512/21/t20151221_7723627.shtml|title=中央纪委通报七起违反中央八项规定精神问题|publisher=中国经济网|archive-date=2020-11-21|archive-url=https://web.archive.org/web/20201121184923/http://district.ce.cn/newarea/sddy/201512/21/t20151221_7723627.shtml|dead-url=no}}</ref>。
