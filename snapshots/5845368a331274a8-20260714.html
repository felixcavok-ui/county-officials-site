 董保同 （1967年1月—）， 河北 深县 人， 汉族 ， 中国共产党 党员。 中华人民共和国 政治人物、 第十三届全国人民代表大会 云南省 代表 [ 1 ] 。现任 中华人民共和国生态环境部 副部长、党组成员， 国家核安全局 局长。
 生平 [ 编辑 ] 
 早年教育 [ 编辑 ] 
 1981年，时年14岁的董保同从河北省深县第一中学（现河北深州市中学）参加高考，以 深县 第一名考入 北京大学 技术物理系原子核物理学专业 [ 2 ] 。
 国防科工系统 [ 编辑 ] 
 1985年本科毕业后，18岁的董保同进入 核工业部 核科学技术情报研究所工作。1988年，核工业部撤销并组建 中国核工业总公司 后，董保同继续在该公司工作 [ 2 ] 。
 1998年7月，董保同赴任 国防科学技术工业委员会 工作，先后担任政策法规司副司长、办公厅副主任、办公厅巡视员兼副主任等职务，期间曾挂职任 北京奥组委 场馆管理部副部长 [ 3 ] 。
 2008年7月， 国家国防科技工业局 组建后，董保同任国家国防科技工业局系统工程二司司长（正司局级） [ 3 ] 。
 空降云南 [ 编辑 ] 
 2010年10月，董保同赴 云南省 任职，出任 中共昆明市委 常委， 昆明高新技术产业开发区 管委会主任、党工委书记（正厅级） [ 3 ] 。
 2014年7月，董保同任 云南省人民政府 副秘书长（正厅级） [ 3 ] 。
 2015年6月，董保同出任中共 曲靖市 委副书记，曲靖市人民政府代市长、市长 [ 2 ] 。
 2018年10月，董保同任 云南省科学技术厅 副厅长、党组副书记（正厅级），于次年1月接任厅长 [ 2 ] 。2018年，董保同被选为云南省出席 第十三届全国人民代表大会 代表 [ 4 ] 。
 回京任职 [ 编辑 ] 
 2020年11月，董保同离开工作了10年的云南，重返国家国防科技工业局任副局长、党组成员，兼任 国家原子能机构 副主任 [ 3 ] 。
 2022年10月，董保同升任 生态环境部 副部长、党组成员， 国家核安全局 局长 [ 5 ] 。
