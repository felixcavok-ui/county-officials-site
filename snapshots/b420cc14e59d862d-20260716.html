锡山区三届人大一次会议胜利闭幕
时间： 2012-03-31    来源：       浏览量：
打印     字体：   放大   正常   缩小
锡山区第三届人民代表大会第一次会议在圆满完成大会预定的各项议程后，于 3 月 29 日上午胜利闭幕。
区委书记朱爱勋在闭幕大会上作重要讲话，他说，这次会议是一次集思广益、凝心聚力的大会，是一次民主团结、求真务实的大会，是一次开拓创新、催人奋进的大会，必将极大地鼓舞全区人民，以更加坚定的信心，更加饱满的热情，更加坚实的步伐，向着率先基本实现现代化的目标奋勇前进。
朱爱勋、吴富生、华炳泉、陆志坚、蒋群、陈琦伟、张黎平、郑永君、周挥、胡晓鹏、姚永新在主席台前排就座。在主席台上就座的还有大会主席团其他成员、区四套班子其他领导和区人民法院院长、区人民检察院检察长等。
大会应到代表 237 名，实到代表 234 名，符合法定人数。
大会首先进行选举，大会选举由朱爱勋主持。选举采用无记名投票方式进行。选举产生新一届区人大常委会主任、副主任、委员 ; 区人民政府区长、副区长 ; 区人民法院院长 ; 区人民检察院检察长。选举产生出席无锡市第十五届人民代表大会的代表。经过认真思考和选择，代表们郑重地填写选票，秩序井然地在票箱前投上自己神圣的一票。监票员当众打开票箱，清点选票张数。大会实发 8 种选票各 234 张，发出的选票与收回的选票相符，大会宣布选举有效。大会还进行了换届风气民主测评。大会主席团举行第五次会议，审核、确认选举结果。接着，第二次大会继续举行，宣布选举结果 : 华炳泉当选为锡山区第三届人大常委会主任，张黎平、郑永君、周挥、姚永新当选为副主任，丁伦元等 22 名同志当选为委员 ; 陆志坚当选为新一届锡山区人民政府区长，章红新、李江、张映雪、言国强、包鸣、陈奕当选为副区长 ; 王立新当选为锡山区人民法院院长 ; 黄懿斌当选为锡山区人民检察院检察长。王杰等 44 人当选为出席无锡市第十五届人民代表大会的代表。当新当选的新一届区人大常委会主任、副主任和区长、副区长等先后到台前与代表们见面时，全场响起了热烈的掌声。
大会还听取并通过了议案审查委员会主任委员郑永君所作的议案审查报告 ( 草案 ) ，通过了预算审查委员会的预算审查报告 ( 书面 ); 通过了关于《政府工作报告》的决议 ; 通过了关于《无锡市锡山区 2011 年国民经济和社会发展计划执行情况与 2012 年国民经济和社会发展计划》的决议 ; 通过了《无锡市锡山区 2011 年财政预算执行情况和 2012 年财政预算》的决议 ; 通过了关于无锡市锡山区人民代表大会常务委员会工作报告的决议 ; 通过了关于无锡市锡山区人民法院工作报告的决议 ; 通过了关于无锡市锡山区人民检察院工作报告的决议。
朱爱勋在简要回顾区二届人大一次会议以来全区经济社会发展所取得的成就后指出，这些成绩的取得，是全区人民团结拼搏、共同奋斗的结果，更凝聚着二届人大及其常委会的智慧和力量，饱含着广大人大代表的辛劳和汗水。朱爱勋高度评价了区二届人大及其常委会四年来的工作，他说，区二届人大常委会是一个富有凝聚力、战斗力的领导集体，是一个团结和谐、奋发有为的领导集体，区二届人大及其常委会任职的时期，是全区人大工作与时俱进、开拓创新、成绩显著的时期。
由于年龄关系和工作需要等因素，这次人大换届后，一些同志将不再担任新一届区人大常委会、区政府领导职务。朱爱勋说，这些同志在任期内勤勤恳恳、尽心尽责，为我区经济社会发展倾注了大量心血，洒下了辛勤汗水，贡献了智慧力量。尤其是吴富生同志，身体力行、率先垂范，团结带领区人大常委会和全体人大代表，卓有成效地开展新时期人大工作，为推动我区经济社会发展和民主法制建设作出了积极贡献。大会以热烈的掌声向他们表示诚挚的感谢和崇高的敬意。
朱爱勋指出，当前锡山的发展已进入了赶超发展、率先基本实现现代化的关键时期。去年召开的区第三次党代会科学谋划了今后一个时期锡山的发展蓝图，明确提出了以赶超发展为主题，以加快转变经济发展方式为主线，坚持“高点定位、高端合作、高品质环境打造”联动，大力实施“创新驱动”、“城市化和城乡一体”、“普惠民生”主战略，全面提升经济发展水平、区域功能地位和百姓幸福感受，率先基本实现现代化的总体要求。这次区人代会又进一步通过法定程序，把区委的决策部署变成了全区人民的共同意志。新的起点，蕴含着新的使命，开启了新的征程，朱爱勋希望新一届人大和人大代表要把思想和行动统一到区第三次党代会和本次人代会精神上来，坚定信心、振奋精神，凝心聚力、奋发有为，努力为推动锡山经济社会又好又快发展作出更大贡献。在具体工作中力求在以下三个方面实现新突破 :
一要始终围绕全区中心工作，在推进赶超发展上作出新贡献。区人大及其常委会要善于找准人大工作与经济社会发展的结合点，特别要紧紧围绕“十二五”时期发展的主题、主线、目标任务和重大举措，选择全局性、前瞻性、综合性的重大课题开展专题调研，提出具有建设性、针对性和可操作性的意见建议，使区委的决策更符合科学发展要求、更贴近锡山发展实际。
二要充分发挥桥梁纽带作用，在维护人民利益上实现新提升。人大代表代表人民参与国家事务的管理，是党和政府联系人民的桥梁和纽带。各位代表来自人民、根植人民，要始终保持“人民选我当代表、我当代表为人民”的高度荣誉感和神圣使命感，充分发挥好桥梁纽带作用，用卓有成效的工作实践，为人民群众用好权、履好职、尽好责。
三要不断加强人大自身建设，在提高履职水平上取得新进步。加强自身建设，是人大依法履行职责的重要条件。新形势、新任务对人大工作提出了新的更高要求，区人大及其常委会要始终把加强自身建设放在突出位置，努力提高人大工作科学化水平。自觉坚持党的领导，注重对人大工作规律和特点的研究，充分发挥代表作用，不断提升人大履职水平。
朱爱勋强调，人民代表大会制度是我国的根本政治制度，人大工作是党的工作的重要组成部分。全区各级党委要按照总揽全局、协调各方的要求，切实加强对人大工作的领导，把人大工作摆在突出位置，列入重要议事日程，及时研究解决人大工作中的重大问题，为人大常委会和人大代表履行职责、开展工作创造更好的条件。“一府两院”要自觉接受人大及其常委会的监督，认真贯彻执行人大及其常委会作出的决定、决议，及时办理人大代表提出的各项建议意见，进一步改进工作，提高依法行政和公正司法水平，全力助推锡山科学发展、赶超发展。
朱爱勋最后说，宏伟蓝图催人奋进，赶超征程任重道远。让我们牢记党和人民的重托，珍惜人民赋予的权利，以更加昂扬的斗志、更加饱满的精神、更加务实的作风，同心同德，开拓创新，扎实工作，为锡山加快赶超发展、率先基本实现现代化而努力奋斗，以优异成绩迎接党的十八大胜利召开 !
大会在雄壮的国歌声中闭幕。
