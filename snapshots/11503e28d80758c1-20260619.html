 Collection: Wikipedia Outlinks March 2016

 Crawl of outlinks from wikipedia.org started March, 2016. These files are currently not publicly accessible.

Properties of this collection.
It has been several years since the last time we did this.
For this collection, several things were done:
1. Turned off duplicate detection. This collection will be complete, as there is a
good chance we will share the data, and sharing data with pointers to random
other collections, is a complex problem.

2. For the first time, did all the different wikis. The original runs were just against the 
enwiki. This one, the seed list was built from all 865 collections.

       我的简历 
 
 陈安丽，女，1963年12月出生，汉族，湖北汉川人，武汉大学文学学士、中欧国际工商学院工商管理硕士。1985年4月加入中国共产党。     1984年7月任武汉大学图书情报学院分团委副书记；     1986年3月任武汉大学图书情报学院分团委书记；     1987年12月任省委科教部政研室、高校工委组织处正科级干事；     1991年6月任省高校妇工委副秘书长     (其间：1993年2月至1993年6月在高校党校培训班学习)；     1993年12月任省委高校工委组织处副处长；     1996年4月任省委高校工委组织处处长；     1998年2月任省委高校工委、省教委组织处处长     (其间：1998年5月至1998年7月在省委党校县处级女干部培训班学习)；     2000年6月任省委高校工委、省教育厅干部人事处处长；     2003年5月任省教育厅副厅长、党组成员，省委高校工委委员；     2008年12月任省委高校工委副书记、省教育厅副厅长、党组副书记、省政府教育督导室主任、主任督学；     2009年1月任省教育厅厅长、党组副书记、省委高校工委副书记、省政府教育督导室主任、主任督学     (其间：2010年3月至2012年6月在中欧国际工商学院工商管理硕士学位学习；2011年5月参加中组部组织赴耶鲁大学发展中的女性领导者高级研究班培训；2012年2月至2012年4月在中央党校厅局级干部培训班学习)；     2013年1月任省政协常委、省教育厅厅长、党组副书记、省委高校工委副书记、省政府教育督导室主任、主任督学；     2013年3月任黄冈市委副书记、黄冈市人民政府副市长、代市长、党组书记；     2013年4月任黄冈市委副书记、黄冈市人民政府市长、党组书记。     十届省委委员、十一届省政协常委。     （2015年6月获广州军区第七届“国防之星”荣誉称号）
