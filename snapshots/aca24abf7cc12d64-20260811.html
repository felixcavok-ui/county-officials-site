在这几天相继召开的县市“两会”上，泰州市海陵、姜堰两区人大代表选出新一任区长，刘剑波、孙靓靓分别全票当选。两位年轻区长的就职发言激情洋溢，也在与会代表及朋友圈中赢得好评如潮。 新当选的海陵区区长刘剑波在会上讲话 图片由通讯员提供 “我从去年6月20日踏入凤城河畔，至今已经210天。这些天来，‘三个不相信’精神，以及大格局、大视野、大担当、大情怀、大作为‘五大’信念，深深鼓舞着我……”刘剑波说，能够为52万海陵人民服务，对他来说既是一份殷切的重托，也是一种无限的信赖，更是一个全新的起点。刘剑波向全区人大代表及海陵人民庄严承诺：坚定“一枝一叶总关情”的赤诚情怀，甘做为民服务的孺子牛；坚持“不日新者必日退”的进取意识，甘做创新发展的拓荒牛；坚守“无须扬鞭自奋蹄”的实干之风，甘做艰苦奋斗的老黄牛。 图片由通讯员提供 会上，代表听的是表态；会后，群众看的是行动。刘剑波表示，将按照海陵区委全会的战略部署和本次大会决议，紧扣幸福海陵建设总命题，锚定“冲击全市第一方阵、争当区域高质量发展排头兵”目标，围绕创新引领、产业重塑、项目突破、改革开放、城市建设、乡村振兴、改善民生等7项重点任务，把心思都用在推动发展上，把精力都用在为民造福上，把智慧都用在干好工作上，苦干实干拼命干，以钉钉子精神全力落实好定下来的事情，兑现好向人民的承诺。 新当选的姜堰区区长孙靓靓在会上讲话 图片由通讯员提供 “我全程参与了3届溱潼会船节，每当看到会船上的篙手们，在高亢锣声中飞篙走桨、中流击水，都被他们身上的激情和力量所感染，这正是姜堰人民奋勇争先、一往无前的生动写照。”姜堰新任区长孙靓靓向代表们郑重表态：做思想洪流中的篙手，校准坐标、坚定航向；做发展浪潮中的篙手，扬篙激浪、勇争一流；做民生港湾中的篙手，支撑希望、摆渡幸福；做人生长河中的篙手，躬身向前、行稳致远。 图片由通讯员提供 任何脱离民生的发展，都注定无法远航。孙靓靓表示，她将始终把人民放在心中最高位置，全心全意、用情用力，坚持做到：增强脚力，更多地把足迹印在田间地头、生产车间、项目现场，倾听原汁原味的声音，回应群众的所呼所盼。用好财力，带头过“紧日子”，把更多的“真金白银”投入到民生事业上，努力把经济总量、财政增量，转化为老百姓实实在在的生活质量。倾注心力，毫不松懈抓好疫情防控，坚决守住安全生产防线，真情实意关心困难群体，带领百姓共同驶向幸福的港湾。 搜索两位新区长的工作履历，刘剑波1978年3月生，江苏泰兴人，1998年8月参加工作，曾任共青团泰兴市委副书记(主持工作)、共青团泰州市委副书记、泰州市商务局副局长、泰州市政府副秘书长等职，2020年6月起任海陵区委副书记、区政府代区长。孙靓靓，女，1984年2月生，江苏滨海人，2006年大学毕业后进入乡镇工作，曾任盐城市亭湖区团区委副书记、书记，共青团泰州市委副书记、书记，姜堰区委副书记、溱湖旅游度假区党工委书记、姜堰现代农业产业园区党工委书记，姜堰区政府代区长等职。 大道至简，实干为要。今年是“十四五”开局之年，也是全面建设社会主义现代化起步之年。刘剑波表示，将以时不我待、只争朝夕的进取精神，恪尽职守、夙夜在公的工作状态，全身心投入幸福海陵建设的火热实践。“十四五”的赛场鼓点铿锵，孙靓靓承诺，她一定将大家的信任化为前行的动力，与全区人民同舟共济、奋勇向前，为创造姜堰人民的幸福生活接续奋斗。 交汇点记者 顾介铸 1 "); else document.write(" 1 "); for(var i=1; i "+(i+1)+" "); else document.write(" "+(i+1)+" "); } } --> createPageHTML(1, 0, "t20210116_6949370", "shtml"); 标签： 责编：顾志铭
