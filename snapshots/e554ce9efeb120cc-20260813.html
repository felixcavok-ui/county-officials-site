 区长开展安全生产工作调研

 来源:荔城在线

 时间：2026-06-08 21:17

 | 
 
 |

 | 
 
 |

 　　6月8日，区委副书记、区长刘基棠带领相关部门负责人开展安全生产工作调研，副区长陈海防一同参加。 
 　　刘基棠一行来到镇海街道万象汇项目，听取项目负责人介绍工程推进情况，实地调研项目扫尾工作，认真排查安全隐患。刘基棠要求各级各部门要时刻绷紧安全生产这根弦，聚焦人员密集场所等重点领域，持续深化隐患排查整治，确保人民群众生命财产安全。 
 　　随后召开座谈会，刘基棠认真听取万象汇项目介绍及需要协调解决的问题，要求相关部门全力以赴，主动靠前，做好服务，确保项目顺利开业。刘基棠还对万象汇项目选择落户荔城表示感谢，希望在相关部门的共同努力下，将其打造成标杆项目，带动城市商圈繁荣发展。
