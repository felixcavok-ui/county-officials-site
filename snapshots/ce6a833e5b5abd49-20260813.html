城厢要闻 区委书记参加并指导龙桥街道领导班子党史学习教育专题民主生活会 来源:今日城厢 时间：2022-01-26 15:10 | | | | 【反向关联】 --> 1月24日，根据区委统一安排，区委书记王文才参加并指导龙桥街道领导班子党史学习教育专题民主生活会。区领导黄美光，区委党史学习教育第二巡回指导组、区纪委、区委组织部相关同志到会指导。 会上，龙桥街道主要负责同志代表领导班子作了对照检查、自我批评，班子成员逐一进行自我剖析，并开展严肃认真的批评和自我批评。还书面通报了龙桥街道领导班子党史学习教育专题民主生活会准备工作、整改措施落实、会前征求意见等情况。 在仔细审阅材料、认真听取大家发言后，王文才指出，这次党史学习教育专题民主生活会，是深化拓展党史学习教育成果的重要内容，也是推动全面从严治党、严肃党内政治生活的重要抓手。这次专题民主生活会会前准备扎实充分，查摆问题实事求是，剖析原因深入深刻，开展批评坦诚相见，整改措施具体可行，达到了统一思想、振奋精神、整改问题、促进工作、增强党性的预期目的。希望龙桥街道进一步压实责任，建立长效机制，认真抓好整改落实 “后半篇文章”，努力把民主生活会的成果转化为推动高质量发展的实效。 王文才强调 —— 要提升站位，旗帜鲜明讲政治。坚持把党的政治建设摆在首位，持续在学懂弄通做实习近平新时代中国特色社会主义思想上下更大功夫，与贯彻落实习近平总书记来闽考察重要讲话精神结合起来，与秉承弘扬习近平总书记治理木兰溪的重要理念结合起来，带头牢记 “两个确立”，坚决做到“两个维护”，推动党中央决策部署和上级工作要求落地落实落效。 王文才要求 —— 要俯下身子，干事创业勇担当。立足区位资源禀赋，聚焦产城联动，抓好产业提质，坚持存量提升和增量扩张并举，深入挖掘电商、楼宇总部等优势资源 ,突出业态提升、模式创新、招大引强,推动现代服务业集群集聚发展。抓好城市提级，加快项目谋划建设，推动城市居住、风貌、亮点区片、管理等功能品质提升，加快打造生态宜居区。 王文才强调 —— 要党建引领，夯基惠民提效能。深化拓展 “我为群众办实事”实践活动，民生短板要再补齐，加快解决一批群众最急最忧最盼最难的突出问题。基层治理要再精细，加快推动近邻党建、小区党建、“三长”落到最小单元，把基层治理“底座”夯实，实现从精细到精致到精品。发展底线要再守牢，统筹疫情防控和经济社会发展，统筹发展和安全，加快补齐疫情防控、安全生产、信访维稳等短板，确保社会大局和谐稳定。 王文才要求 —— 要从严治党，转变作风树形象。要落实责任，街道领导班子要切实担负起政治责任、主体责任，履行好 “一岗双责”，推动全面从严治党向纵深发展、向基层延伸。要转变作风，端正态度、主动作为，脚踏实地、苦干实干，营造干事创业的浓厚氛围。要严守纪律，发挥模范带头作用，牢固树立规矩意识，以更高的标准、更严的要求遵纪守法。 扫一扫在手机上查看当前页面 附件下载： 相关链接： {{ el._doctype }}：
