5月23日上午，通化市委召开领导干部会议，宣布吉林省委关于通化市政府主要领导同志调整的决定：乔恒同志任通化市委委员、常委、副书记。 同日，通化市七届人大常委会第十次会议决定任命乔恒为通化市副市长、代市长，决定接受田玉林辞去通化市市长的请求，并报市第七届人民代表大会第三次会议备案。 据人民网地方领导资料库显示，乔恒此前担任吉林省林业厅副厅长、党组成员，通化市原市长田玉林因违纪已被立案调查。 (唐嘉艺) 乔恒同志简历 乔恒 乔恒，男，1960年10月生，汉族，吉林省乾安人，中共党员，先后获理学硕士、区域经济学博士学位，高级经济师。 历任吉林省林业厅办公室副主任、主任，吉林省林业厅纪检组副组长、监察室主任，抚松县人民政府副县长，吉林省林业厅副厅长、党组成员。 2014.05 中共通化市委副书记，市政府副市长、代市长 (人民网资料 截至2014年5月) 【编辑:何敏】 参与互动( 0 ) window._bd_share_config = { "common": { "bdSnsKey": {}, "bdText": "", "bdMini": "2", "bdMiniList": false
