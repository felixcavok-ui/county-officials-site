'''陈润儿'''（{{bd|1957年|10月16日|catIdx=C陈}}），[[湖南省]][[株洲市]][[茶陵县]]人。1975年9月参加工作，1975年12月加入[[中国共产党]]。[[中共中央党校]][[在职研究生]]学历。[[中华人民共和国]]政治人物。[[中国共产党]]第十七届、十八届中央委员会候补委员，第十九届中央委员，第十三届全国人大代表。曾任[[河南省人民政府]]省长，[[中国共产党宁夏回族自治区委员会|中共宁夏回族自治区党委]]书记，[[宁夏回族自治区人民代表大会常务委员会|宁夏回族自治区人大常委会]]主任，第十三届全国人民代表大会农业与农村委员会副主任委员等职务。

==生平经历==
===基层历练===
陈润儿出生于湖南省茶陵县思聪公社（今茶陵县[[思聪街道]]）<ref name=cl>{{cite book |author1=茶陵县地方志编纂委员会 |title=《茶陵县志（1993-2010）》 |date=2016年 |publisher=方志出版社 |location=北京市 |isbn=978-7-5144-1857-6 }}</ref>{{rp|455}}，1975年9月，陈润儿在[[茶陵县第一中学]]高中毕业后，出任[[湖南省]][[茶陵县]]思聪公社秘书。1976年11月任茶陵县商业局职工、茶陵县委办公室干事，1981年1月任茶陵县马江公社（乡）党委书记。1983年9月在[[湖南农学院]]农业干部培训部农学专业学习，1985年7月任中共茶陵县委常委、副县长。1987年3月任中共茶陵县委副书记、县长<ref name=cl1 />{{rp|426}}，1988年，获评为“全国农村体育先进工作者”<ref name=cl1>{{cite book |author1=茶陵县地方志编纂委员会 |title=《茶陵县志》 |date=1994年 |publisher=[[中国文史出版社]] |location=北京市 |isbn=9787503406737}}</ref>{{rp|769}}，1990年9月升任中共茶陵县委书记。

1992年9月，陈润儿任中共郴州地委委员、中共[[北湖区|郴州市 (县级市)]]党委书记，其间于1993年9月至1994年7月在[[中央党校一年制中青年干部培训班]]学习<ref>{{cite book |author1=《郴州市北湖区志》编纂委员会|title=《郴州市北湖区志（1990—2004）》 |date=2011年4月 |publisher=方志出版社 |location=北京市 |isbn=9787514400441 |page=100 |edition=1}}</ref>。1994年9月任中共郴州地委副书记、中共[[郴州市]]（地级）委副书记，其间于1993年9月至1996年1月在中央党校研究生院在职研究生班经济管理专业学习<ref>[http://epaper.xxcb.cn/xxcba/html/2011-11/24/content_2554298.htm 陈润儿简历：1993.09－1994.07中央党校一年制中青年干部培训班学习。1993年9月至1996年1月在中央党校研究生院[[在职研究生]]班经济管理专业学习] {{Wayback|url=http://epaper.xxcb.cn/xxcba/html/2011-11/24/content_2554298.htm |date=20111223131838 }} 潇湘晨报数字报</ref>。

===湖南高层===
1997年8月，陈润儿调任中共[[娄底]]地委副书记<ref name="ld">{{cite book |author1=娄底地区地方志编纂委员会 |title=《娄底地区志》 |date=1997年 |publisher=湖南人民出版社 |url=https://books.google.com.sg/books?id=l7AvAAAAMAAJ |location=湖南省长沙市 |isbn=9787543816619 |access-date=2024-09-23 |archive-date=2024-12-01 |archive-url=https://web.archive.org/web/20241201003929/https://books.google.com.sg/books?id=l7AvAAAAMAAJ |dead-url=no }}</ref>{{rp|1674}}、行署副专员。1998年2月，任中共湖南省[[娄底]]地委副书记、行署专员<ref>{{cite book |author1=湖南年鉴社 编辑 |title=《湖南年鉴（1999年）》 |date=1999年 |publisher=湖南年鉴社 |location=湖南省长沙市 |oclc=952777350 |url=http://www.hnfzg.cn:8889/xboot/elasticsearch/openHtml?id=214534900798197761,%E9%99%88%E6%B6%A6%E5%84%BF |accessdate=2023-12-23 |chapter=娄底地区 |archive-date=2023-12-23 |archive-url=https://web.archive.org/web/20231223044331/http://www.hnfzg.cn:8889/xboot/elasticsearch/openHtml?id=214534900798197761,%E9%99%88%E6%B6%A6%E5%84%BF |dead-url=no }}</ref>。1999年2月，任湖南省地质矿产厅副厅长、党组副书记。2000年4月，任中共湖南省[[湘潭市]]委副书记、代市长，次年1月当选湘潭市人民政府市长。2003年2月，任中共[[湘潭市]]委书记。

2006年11月23日，陈润儿升任[[中共湖南省委]]常委，中共[[长沙市]]委书记<ref>[http://www.xinhuanet.com/chinanews/2006-11/24/content_8609746.htm 陈润儿担任长沙市委委员、常委、书记] {{Wayback|url=http://www.xinhuanet.com/chinanews/2006-11/24/content_8609746.htm |date=20140714154711 }} 新华网</ref>，晋升副部级。在长沙工作六年半的时间里，他通过率先发展目标的引领，增强了长沙的经济实力。通过跨江发展战略的实施，拓展了城市空间。通过基础设施建设的推进，完善了承载功能。通过文明城市的创建，提升了长沙的城市形象。

===从黑龙江到河南===
2013年4月16日，陈润儿离开工作多年的湖南，调任[[中共黑龙江省委]]副书记<ref>[http://www.chinanews.com/gn/2013/04-16/4735554.shtml 陈润儿任黑龙江省委副书记 不再兼任长沙书记] {{Wayback|url=http://www.chinanews.com/gn/2013/04-16/4735554.shtml |date=20130426153907 }} 中国新闻网</ref>。在交接大会上，他发表了饱含深情的讲话，情到浓时，几度哽咽落泪。

2016年3月26日，陈润儿在黑龙江工作三年之后，升任[[中共河南省委]]副书记，并提名为省长候选人<ref>{{cite web|url=http://hlj.people.com.cn/n2/2016/0326/c220027-28019100.html|title=陈润儿任河南省委副书记、提名为省长候选人|publisher=人民网|accessdate=2016-03-26}}{{dead link|date=十一月 2017 |bot=InternetArchiveBot }}</ref>。同年4月7日，當選為[[河南省人民政府]]省長。2017年10月24日，在[[中国共产党第十九次全国代表大会]]上当选为中共中央委员。2018年2月24日，当选为[[第十三届全国人大代表]]<ref>{{Cite web|title=（受权发布）中华人民共和国第十三届全国人民代表大会代表名单-中新网|url=http://www.chinanews.com/gn/2018/02-25/8453959.shtml|accessdate=2021-02-13|work=中新网|archive-date=2018-02-27|archive-url=https://web.archive.org/web/20180227031724/http://www.chinanews.com/gn/2018/02-25/8453959.shtml|dead-url=no}}</ref>。

===从河南到宁夏===
2019年10月25日，陈润儿升任[[中共宁夏回族自治区党委]]委员、常委、书记<ref>[http://www.xinhuanet.com/2019-10/25/c_1125153124.htm 宁夏回族自治区党委主要负责同志职务调整 陈润儿任宁夏回族自治区党委书记] {{Wayback|url=http://www.xinhuanet.com/2019-10/25/c_1125153124.htm |date=20191025133035 }} 新华网</ref>。12月6日，辞去河南省人民政府省长职务<ref>{{cite web |title=尹弘任河南省代理省长 陈润儿辞去河南省人民政府省长职务 |url=http://liuyan.people.com.cn/n1/2019/1206/c58278-31493960.html |website=人民网 |accessdate=2020-02-16 |date=2019-12-06 |archive-date=2020-02-16 |archive-url=https://web.archive.org/web/20200216032642/http://liuyan.people.com.cn/n1/2019/1206/c58278-31493960.html |dead-url=no }}</ref>。2020年1月15日，当选为[[宁夏回族自治区人大常委会]]主任<ref>{{Cite web |url=http://www.gov.cn/xinwen/2020-01/15/content_5469367.htm |title=陈润儿当选宁夏回族自治区人大常委会主任 艾俊涛当选宁夏回族自治区监察委员会主任 |accessdate=2020-01-18 |archive-date=2020-05-18 |archive-url=https://web.archive.org/web/20200518163052/http://www.gov.cn/xinwen/2020-01/15/content_5469367.htm |dead-url=no }}</ref>。

===退居二线===
2022年3月29日，陈润儿不再担任中共宁夏回族自治区党委书记、常委、委员职务<ref>{{cite web |title=宁夏回族自治区党委主要负责同志职务调整 梁言顺任宁夏回族自治区党委书记 |url=http://www.news.cn/politics/2022-03/29/c_1128513376.htm |website=新华网 |accessdate=2022-03-29 |archive-date=2022-03-30 |archive-url=https://web.archive.org/web/20220330085634/http://www.news.cn/politics/2022-03/29/c_1128513376.htm }}</ref>。2022年4月20日，任[[全国人民代表大会农业与农村委员会]]副主任委员<ref>{{cite web |title=全国人民代表大会常务委员会任命名单 |url=http://www.npc.gov.cn/npc/c30834/202204/035b083c2c21486fbd5a49a5f9550aa5.shtml |website=中国人大网 |accessdate=2022-04-20 |archive-date=2022-06-20 |archive-url=https://web.archive.org/web/20220620102222/http://www.npc.gov.cn/npc/c30834/202204/035b083c2c21486fbd5a49a5f9550aa5.shtml }}</ref>。2023年3月，当选[[中国人民政治协商会议第十四届全国委员会委员名单|第十四届全国政协常委]]、[[中国人民政治协商会议全国委员会文化文史和学习委员会|文化文史和学习委员会]]副主任<ref>{{Cite web |title=中国人民政治协商会议第十四届全国委员会各专门委员会主任、副主任名单 |url=http://www.cppcc.gov.cn/zxww/2023/03/14/ARTI1678757816150357.shtml |website=www.cppcc.gov.cn |access-date=2026-01-22 |archive-date=2023-03-30 |archive-url=https://web.archive.org/web/20230330101358/http://www.cppcc.gov.cn/zxww/2023/03/14/ARTI1678757816150357.shtml |dead-url=no }}</ref>。
