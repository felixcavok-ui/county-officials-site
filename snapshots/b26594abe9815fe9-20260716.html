当选新吴区人民政府区长
会后，区长章金伟
第一时间接受了专访
快来听听他怎么说
刚才，大会选举产生了新一届区政府领导班子，选举我担任新吴区区长。我深知，一张张选票的背后，承载着厚望重托，饱含着无限信任，凝结着殷切期盼；我深感责任重大、使命光荣。在此，我真诚地向各位代表、向全区人民，表示衷心的感谢，并致以崇高的敬意！
当前，新吴的发展已经站在新的起点上，作为区政府“班长”，我将在市委、市政府和区委的坚强领导下，在区人大、政协的监督支持下，团结带领区政府一班人，紧紧依靠全区广大干部群众，乘势而上、接续奋斗，奋力开创新吴更加灿烂美好的明天。
0  1
我将矢志不渝守初心
坚持用习近平新时代中国特色社会主义思想为指引，坚定捍卫“两个确立”，坚决做到“两个维护”，坚定不移把贯彻上级决策部署作为根本政治责任，深入贯彻、忠实执行、狠抓落实，确保政府工作始终沿着正确的方向笃定前进。
0  2
我将奋发有为担使命
我和政府一班人将永葆“争第一、创唯一”的精神，发扬“定了干、马上办、办到底”的作风，一以贯之实施产业强区主导战略、创新驱动核心战略，一往无前推进“双招双引”、太湖湾科创城建设、产业园区优化提升等中心工作，一着不让狠抓污染治理、加固安全底板、维护社会稳定，早日把“规划图”变成“实景图”。
0  3
我将用情用力惠民生
我将始终坚持以人民为中心的发展思想，着力解决好群众身边的烦心事、操心事，把新吴较强的经济实力、较多的财政增量，更多转化为群众实实在在的生活质量，让生活在新吴的人民更幸福、更自豪。
0  4
我将廉洁勤政做表率
我将倍加珍惜人民给予的荣誉和职责，堂堂正正做人，清清白白为官，踏踏实实干事，同时认真履行“一岗双责”，抓好班子，带好队伍，筑牢反腐倡廉的思想防线和制度防线。
征途漫漫，惟有奋斗。从此刻开始，我将时刻牢记自己作出的庄严承诺，始终保持“赶考”姿态，锐意进取、埋头苦干，向组织和人民交上一份满意答卷！
