政府工作报告 
     
 
   
    
 
  (2015年2月7日在黔西南州第七届人民代表大会第六次会议上通过) 
     
 
   
    
 
  州 长  杨永英 
     
 
   
    
 
  各位代表： 
     
 
  现在，我代表州人民政府，向大会作工作报告，请予审议,并请州政协委员和其他列席人员提出意见和建议。 
       
 
   
    
 
  一、2014年工作完成情况 
     
 
   
    
 
  2014年，在州委的正确领导下，在州人大、州政协的监督支持下，州人民政府紧紧依靠全州各族人民，认真贯彻落实党的十八大和十八届三中、四中全会以及习近平总书记系列重要讲话精神，坚守“两条底线”，坚持主基调主战略，主动适应新常态，着力稳增长、调结构、促改革、惠民生、防风险，完成了州七届人大五次会议确定的主要预期目标，为实现全面小康奠定了坚实基础。 
     
 
  —— 综合实力不断增强。地区生产总值完成670.96亿元，同比增长14.6%；固定资产投资（50万元以上口径）786.31亿元，增长31%；财政总收入143.66亿元，增长13.7%；社会消费品零售总额156.75亿元，增长12.7%；金融机构存款余额759.35亿元，增长16.8%，贷款余额540亿元，增长27%。在全省经济发展综合测评中，我州排第六位。 
       
 
  —— 经济结构不断优化。第一产业增加值完成113.41亿元，同比增长6.6%；第二产业增加值240.45亿元，增长16%，其中规模以上工业增加值（2000万元以上口径）224.65亿元，增长14.1%；第三产业增加值317.1亿元，增长15.6%。三次产业比重调整为16.9:35.8:47.3。 
           
 
  —— 经济效益明显提升。公共财政预算收入完成94.5亿元，同比增长16.1%；规模以上工业主营业务收入476.61亿元、增长12.1%，税金总额27.22亿元、增长15.8%；民营经济增加值315.23亿元，占GDP比重的47%，比去年提高7.6个百分点；旅游总收入112.01亿元，增长25.1%。 
       
 
  —— 人民生活持续改善。城镇居民人均可支配收入完成21290元，同比增长10.5%；农村居民人均可支配收入6343元，增长13.4%；安龙、普安2县和兴仁回龙等24个乡镇实现“减贫摘帽”，减少贫困人口17.36万人，连续2年获省扶贫工作特等奖。预计全面小康实现程度76.5%。 
       
 
  过去一年，经济社会发展稳中有序、稳中有进、稳中向好，既有量的扩大，又有质的提升，必将极大地鼓舞全州各族干部群众砥砺奋进，创造新的辉煌！ 
         
 
  一年来，我们重点抓了以下工作： 
     
 
  （一）深入推进改革开放。积极稳妥推进重点领域和关键环节的改革。推进行政区划调整，优化城镇空间布局，获批设立“贵州省城乡统筹发展综合改革义龙试验区”、“贵州万峰林现代服务业开发区”。开展矿产资源“圈而不探、占而不采”专项治理，注销探矿权44个；严格执行招拍挂出让制度，加快矿业权交易市场建设；金州能矿公司挂牌运营，全州煤矿兼并重组为12个煤矿企业集团；启动煤炭资源税从价计征工作。工商注册资本由实缴制改为认缴制，出台鼓励非公有制企业进入特许经营领域管理办法。完成州县乡三级食品药品监督管理体制改革。开展农村土地确权登记试点，启动乡镇农村土地承包经营权确权登记颁证工作。出台精准扶贫工作实施方案，对极贫人口实行“菜单式兜底”和“育婴式管理”。组建贵州黔西南喀斯特区域发展研究院。推行校长定期交流轮岗和职业院校“双证书”制度。启动县级公立医院综合改革试点，支持社会力量办医。认真执行《黔西南州殡葬管理条例》，殡葬改革加快推进。制定政府性债务管理办法，加强政府债务风险管控。完善州级投资公司考评办法，提高国有资产经营效益。在全省率先完成州县两级机构改革任务。兴义出入境检验检疫局获准设立。成功举办第二届“中国美丽乡村·万峰林峰会”。组建州招商引资中心，开展“百团招商”，积极参加酒博会、茶博会、农交会、香港贸易活动周等招商引资推介活动，引进省外资金（3000万元口径）535.8亿元，增长25.9%。积极培育外贸企业，超额完成省下达的进出口和实际利用外资任务。 
        
 
  （二）大力夯实发展基础。强力推进“百日攻坚”，精心组织现场观摩、集中开工活动，项目建设取得重大进展。争取上级专项资金109.73亿元，增长32%,占全省比重首次突破10%；全社会固定资产投资完成1300亿元，增长30％。望（谟）安（龙）、盘（县）兴（义）高速公路加快建设，紫（云）望（谟）、罗（甸）望（谟）高速公路前期工作进展顺利；开工建设通村油路（水泥路）3000公里、建成1500公里，完成县乡道改造136.5公里。启动贵阳至兴义、兴义至永州铁路和兴义至义龙现代有轨电车项目前期工作，沪昆客运专线黔西南段建设有序推进。光照库区航运工程建设进展顺利，20道乡（镇）渡口、4个便民码头建设加快。兴义万峰林机场改扩建工程扎实推进。兴仁打鱼凼水库竣工蓄水，“引马入兴”工程完工通水；开工建设安龙平桥、兴仁尖山等骨干水源工程；兴义马岭水利枢纽工程前期工作顺利推进；建成1602个小型农田水利项目，解决34.07万人饮水安全问题。完成2座220千伏变电站、111公里供电线路建设，普安雨雪、晴隆欲飞等输变电项目加快建设。 
      
 
  （三）着力加快平台建设。把“5个100工程”作为优化生产力空间布局的主要载体，加大投入力度，完成投资359.1亿元。加快产业园区基础设施建设，安龙工业园等8个园区核心区域实现“七通一平”；完善工业园区考核办法，严格执行入园优惠政策，新增入园项目149个，实现产值305.54亿元。启动义龙试验区望谟飞地工业园、兴仁泛亚薏仁生态产业园建设。推进现代高效农业示范园区建设，20个省级园区实现产值78.57亿元。着力抓好8个省级重点旅游景区建设，基础设施逐步完善，服务水平、接待能力明显提升。兴义商城（一期）、贞丰生态文化广场等13个城市综合体加快建设，富康国际会展中心竣工投用。兴义清水河、兴仁巴铃、贞丰者相等18个示范小城镇建设加快，建成“8+X”项目78个，完成投资52.5亿元。义龙试验区、万峰林现代服务业开发区建设有序推进。 
      
 
  （四）同步提升三次产业。坚持“优一产、强二产、扩三产”，以提高产业发展质量和效益为中心，切实转变发展方式。严守耕地红线，完成高标准农田整治24.6万亩，提高粮食单产，粮食总产量完成102万吨；大力优化农业种植结构，加快草地畜牧、烤烟、蔬菜、核桃、甘蔗、薏仁米、中药材等特色优势产业发展，粮经比为39.2:60.8；贵州薏仁集团等186家农业龙头企业实现销售收入58.2亿元；兴义市被列为全国现代农业示范县。扎实开展“双服务”、“百千万”工程，巩固提升传统产业，盘活工业存量，煤、金、电产量分别完成3111万吨、22.5吨、266.6亿度；“四个一体化”项目加快建设，鸿大垃圾发电厂、恒力新能源科技甲醇燃料调配库、清水河热电联产动力车间（一期）等项目基本建成；大力发展新兴产业，开工大健康医药产业项目21个，投资35.3亿元；淘汰落后产能74.3万吨，万元GDP能耗下降3.2%。加大景区、酒店等旅游基础设施建设力度，开展多形式旅游推介活动，旅游业蓬勃发展。兴义万峰林机场新增宁波、丽江航线，恢复深圳航线，旅客吞吐量突破17万人次。浙兴商贸城（一期）、金州·木贾物流园等商贸物流中心建成营运，流通体系不断完善。快递业加快发展。贵州银行、贵阳银行在州设立分支机构，州工投公司13亿元企业债券成功发行，融资规模突破500亿元。 
         
 
  （五）统筹推进城乡发展。以新型城镇和美丽乡村建设为抓手，推动城乡协调发展，城镇人口达105万，城镇化率达36%，提高2个百分点。强化规划引领，立足“一核一圈两翼”城镇空间布局，编制完成《黔西南州州域城镇体系规划》、《兴兴安贞城镇群空间发展战略规划》，完成兴义、兴仁、安龙、贞丰、望谟5个县域中心城市和册亨丫他等10个乡（镇）总规修编；开工城市棚户区改造15片，完成改造任务1.59万户；一批垃圾清运、污水处理、公园绿地等城镇设施建成投用，完成投资105亿元，城乡生活垃圾无害化处理率达58.8％。扎实推进小城镇建设，小城镇承载能力、辐射带动作用不断增强。大力实施“四在农家·美丽乡村”六项行动计划，完成投资31.56亿元，兴仁马家屯、贞丰对门山等一批小康示范村建设有序推进。 
           
 
  （六）大力加强生态建设。深入实施“三位一体”规划，出台加快生态文明建设的意见，启动生态文明示范州建设暨“石漠化山头绿起来”三年攻坚计划，完成石漠化综合治理85平方公里、水土流失治理314.45平方公里，建成和改良草地90.08万亩，完成营造林45.28万亩，森林覆盖率达48.7%。认真抓好“十二件环保实事”，完善环境质量监测机制，建成11个空气质量和3个水质自动监测站；加强对贵州宜化、贵州兴化跟踪监管监测，督促企业强化内部监管、合理调整生产负荷，污染得到有效控制。引进第三方参与兴义桔山、下五屯和安龙、册亨、望谟3县城区污水处理厂运营管理。加强与六盘水、百色、曲靖等周边地区的合作，共同推进马岭河、南北盘江等重点流域的污染治理和生态建设。 
      
 
  （七）不断保障改善民生。“十二件民生实事”基本完成，民生保障水平不断提升。深入实施精准扶贫、水库移民整村推进和扶贫生态移民工程。宁波对口帮扶力度不断加大。“星火计划、科技扶贫”扎实推进。新增城镇就业3.08万人，失业人员再就业5500人，完成乡村能人培训18959人，“3个15万元”政策带动就业6772人。城乡居民基本医疗保险政府补助标准提高到320元，人均基本公共卫生服务经费标准提高到35元。启动实施“四在学校·幸福校园”示范工程，建成普安、晴隆、册亨、望谟4县寄宿制学校学生宿舍19.6万平方米。完成城镇保障房6.06万套，改造农村危房3.6万户。城市低保月平均保障标准提高到364元，农村低保年平均保障标准提高到1988元；对80岁以上老人实行高龄补贴，开工建设13所农村敬老院；对28.3万受灾困难群众实施冬春口粮救助。在全省率先完成“卫计整合”，建成14所乡镇卫生院达标工程，完成州医院新院主体工程建设。建成“农民文化家园”21个、少年宫23所、全民健身路径工程20个、广播电视地面卫星接收站5.17万座。 
            
 
  （八）全面发展社会事业。始终以人民群众的期盼和需求为努力方向，统筹推进科教文卫各项事业发展。兴义民族师范学院、黔西南民族职业技术学院新校区和兴义一中改扩建工程、洒金教育城建设加快，新建“留守儿童之家”45个，新建、改扩建幼儿园73所。城镇职工基本养老保险、城乡居民养老保险、城乡居民医疗保险参保人数分别达9.44万人、149万人、289.67万人。强化计生服务管理，常住人口自然增长率控制在5.58‰，下降0.11个千分点。申请专利263件，获得授权158件。成功举办中国·黔西南万峰林国际持杖徒步大赛、中国自行车联赛（兴义万峰林站）等重大体育赛事，开展“美丽金州·欢乐乡村”等群众文化活动。安全事故起数和死亡人数分别下降14.3%和7.9%。加强信访维稳工作，扎实推进社会治安综合治理，群众满意度和安全感大幅提升。加强人民武装、民兵预备役工作。民族宗教、工青妇、残疾人、老龄、档案、史志等各项事业全面推进。 
          
 
  各位代表！一年来，我们扎实开展党的群众路线教育实践活动，严明政治纪律和政治规矩，严格执行八项规定，狠抓“四风”整治。认真落实“约法三章”，下放、合并行政审批和便民服务14项，为企业和个体工商户减税、免税15.54亿元，“三公”经费支出下降24%，压缩5%行政经费用于教育“9+3”计划。 
      
 
  一年来，我们自觉接受人大及其常委会的法律监督、工作监督和政协的民主监督，办复州人大代表建议107件、州政协委员提案202件。认真听取各民主党派、工商联、无党派人士、人民团体的意见和建议。办理“州长信箱”来信621件，开通“12345州长直通热线”，办好政府门户网站，大力促进政务公开。 
       
 
  一年来，我们坚持不懈推进依法行政，出台依法治州实施意见，进一步规范行政执法，有效化解行政争议，受理行政复议案件78件、审结72件，制定规范性文件19件、清理218件。州政府荣获第三届“中国法治政府奖”。 
       
 
  各位代表！过去一年的成绩来之不易。这是省委、省政府和州委正确领导的结果，是州人大、州政协监督支持的结果，是全州干部群众团结奋斗和各方大力支持的结果。在此，我代表州人民政府，向全州各族人民、各级干部表示崇高的敬意！向人大代表、政协委员、各民主党派，各人民团体和各界人士，向驻州人民解放军、武警官兵和人民警察，向中央和省驻州各部门表示衷心的感谢！ 
            
 
  在肯定成绩的同时，我们清醒地看到存在的困难和问题。主要是：结构性问题和深层次矛盾依然突出，产业层次不高，过多依赖资源消耗；发展缺乏大项目、大产业支撑，投资体量偏小，固定资产投资增长后劲不足；工业经济总量小，转型升级压力大；农业产业化程度不高，农特产品品牌培育效果不明显；中小企业融资难，实体经济运行难，财政增收放缓；扶贫攻坚任务艰巨，结构性就业矛盾突出，民生保障任务重；“四风”问题依然存在，个别部门工作不够主动、担当不够有力，发展环境亟待改善。对此，我们将高度重视，采取有效措施，不断加以解决。 
       
 
   
    
 
  二、2015年政府工作主要任务 
     
 
   
    
 
  2015年是全面深化改革的关键之年，是全面推进依法治州的开局之年，也是全面完成“十二五”规划的收官之年。当前，全国经济社会发展进入新常态，我州全面小康建设步入新阶段。新常态催生新动力，新阶段蕴含新机遇。我们一定要牢记使命、抢抓机遇，主动作为、奋勇争先，不辜负全州各族人民的重托和期望！ 
              
 
  今年政府工作的总体要求是：全面贯彻落实党的十八大和十八届三中、四中全会精神，以邓小平理论、“三个代表”重要思想、科学发展观为指导，深入贯彻习近平总书记系列重要讲话精神，按照中央、全省、全州经济工作会议的部署，坚守发展和生态两条底线，主动适应经济发展新常态，保持经济运行在合理区间，深入实施主基调主战略，大力实施开放带动、创新驱动，以“五个起来”为抓手，更加注重转方式调结构，更加注重深化改革开放，更加注重发挥投资关键作用，更加注重保护生态环境，更加注重防控债务风险，更加注重强化民生保障，把“天蓝、地绿、水清、人和、业兴”的美丽黔西南更好更快向前推进。 
      
 
  经济社会发展的主要预期目标是：地区生产总值确保增长14.5%，力争增长15%以上；粮食总产量102万吨，农业增加值增长6%；规模以上工业增加值增长14%以上；服务业增加值增长16%；固定资产投资增长32%以上；社会消费品零售总额增长13%以上；进出口总额、实际利用外资分别突破2亿美元；公共财政预算收入增长12%以上；城镇、农村居民人均可支配收入分别增长11%和14%以上；城镇新增就业5万人；减少贫困人口15.06万人；居民消费价格涨幅控制在3%左右；人口自然增长率控制在5.8‰以内；节能减排指标控制在省下达的计划范围内；全面小康实现程度达81%。 
          
 
  围绕实现全年目标，重点抓好以下工作： 
     
 
  （一）以增强活力为目标，着力深化改革开放。坚持改革推动、开放带动、创新驱动，不断为经济发展增动力、添活力。一是强化改革推动。认真贯彻落实中央、省委、州委的决策部署，按照既定的改革时间表、路线图，从解决经济社会发展面临的突出问题入手，严把改革方案质量关，聚焦、聚神、聚力抓落实，确保关键环节和重点领域的改革取得更大突破。扩大“多规融合”改革试点。推进农村土地承包经营权、宅基地和集体建设用地确权登记发证工作。实行工商登记前置审批事项目录化管理制度。制定破解民营经济发展“七难”的具体措施。建成数字黔西南地理信息平台。完成生态保护红线划定工作。制定林业生态保护和环境污染防治问责办法。推进农村敬老院管理体制和运行机制改革，探索建立社会化农村养老机制。全面推开县级公立医院综合改革。按照省的统一部署，积极稳妥推进其他改革。二是强化开放带动。坚持把扩大开放作为后发赶超的战略支撑。加快贵州万峰林现代服务业开发区建设；启动兴义万峰林机场航空口岸和空港物流区建设，大力发展进出口业务。鼓励州内企业参加国际国内会展，加大宣传和销售力度，做大对外贸易。积极参与和融入“一带一路”、泛珠三角、中国—东盟自贸区、珠江—西江经济带、左右江革命老区建设，加强与黔中、滇中和广西北部湾经济区的战略合作。继续办好“中国美丽乡村·万峰林”峰会。继续组织参加省大数据产业博览会、酒博会、茶博会。积极参加“贵州·北京大健康医药产业发展推介会”，确保签约资金80亿元、力争突破100亿元。聚焦珠三角、长三角、港澳台等区域，着力引进优强企业，招商引资到位资金增长20%以上，省外到位资金突破650亿元。三是强化创新驱动。大力推进科技创新，实施“五个科技行动”。支持华大基因建设华大科学村、华大西南数字化检测中心等项目。建成义龙试验区中国科学院华南经济作物育成中心。办好贵州黔西南喀斯特区域发展研究院，用好、用活、用足“星火计划、科技扶贫”试验区平台，在科技试验示范、重大项目等方面争取更大支持。 
             
 
  （二）以交通水利为重点，着力完善基础设施。深入实施基础设施建设大会战，不断破解发展瓶颈。一是加快综合交通体系建设。建成望（谟）安（龙）高速公路，实现县县通高速；加快建设盘（县）兴（义）高速公路，开工建设罗（甸）望（谟）高速公路，力争开工建设紫（云）望（谟）高速公路，加快纳（雍）晴（隆）高速公路前期工作；争取安（龙）贞（丰）、安（龙）兴（仁）高速公路纳入省的规划；开工国省道改造工程160公里，完成兴义客运东站和5个以上乡镇客运站建设，启动兴义客运西站建设。开工建设兴义至义龙赵庄马岭河公（路）铁（路）两用大桥引道工程；完成贵阳至兴义铁路前期工作，力争2016年开工建设；加快推进兴义至永州铁路前期工作，力争启动兴义至百色连接南百高速铁路、兴义至盘县连接沪昆客运专线铁路前期工作；搞好沪昆客运专线建设的协调服务。加快光照库区航运工程建设，新开工建设20道乡（镇）渡口和董箐航运工程。完成兴义万峰林机场改扩建主体工程。二是加快水利基础设施建设。完成兴义木浪河水库扩容工程。推进普安五嘎冲、晴隆西泌河、兴义小龙潭、贞丰七星、兴仁尖山、安龙平桥、册亨水库、望谟桑郎等骨干水源工程建设，加快兴仁鲁皂、普安甲金烟水工程和以盘江灌区为重点的灌溉工程建设。开工建设册亨丫他、望谟纳戎、安龙月亮田抗旱水源工程以及兴仁响水、贞丰超千烟水工程。力争开工建设马岭水利枢纽和“引黄入木”工程。三是加快电力和通讯基础设施建设。加快兴义、兴仁、贞丰、义龙热电联产动力车间项目和郑屯变电站至巴铃工业园输电线路建设；架设输电线路213公里、新增变电容量3.7万千伏安；建成兴义龙井等7个输变电项目；配合做好滇西北至广东±800千伏特高压直流输变电工程黔西南段建设。实施信息基础设施建设三年会战，实现各县（市）城区和主要景区Wi-Fi全覆盖，高速公路、城区和主要景区4G网络全覆盖；新增129个村通电话、通宽带，改造农村邮政危旧网点26个，新建村级邮件接收场所及快递网点32处。四是加快实施“四在农家·美丽乡村”六项行动计划。以县乡为实施主体，集中连片改造，整乡整村推进，完成投资16.95亿元。加强与金融机构合作，创新美丽乡村基础设施建设融资方式，扩大融资规模。建立建营管一体化机制，确保各项设施正常运转、永续使用。 
                    
 
  （三）以项目建设为抓手，着力增强投资拉动。扎实抓好重大工程和重点项目建设，充分发挥投资对稳增长的关键作用，确保限上固定资产投资突破1000亿元。一是精心编制“十三五”规划。深入贯彻落实国发2号文件，坚守“两条底线”，抓好以重大基础设施、产业发展、民生事业为重点的“十三五”规划编制，谋划一批重大工程和重点项目进入国家和省的“十三五”规划，为同步全面小康谋好篇、布好局。二是注重优化投资结构。注重引导投资方向，优化投资结构，扩大投资规模。完成工业（含电力）投资430亿元、交通（含机场）投资100亿元、城镇（含房地产）投资220亿元、水利投资30亿元、社会事业（含民生）投资50亿元、商贸流通投资45亿元、农业产业化投资30亿元、旅游文化产业投资25亿元、其它投资70亿元。三是着力加快项目进度。严格项目前期工作经费绩效管理，提高使用效益，做深做实前期工作。严格执行项目建设“五个一”机制，强化目标绩效考核，继续实行项目倒逼、观摩评比，加快重大工程和重点项目建设。不断优化招商引资环境，切实抓好招商引资项目落地，确保开工率60%以上。四是全力保障投资要素。加大向上争取资金力度，力争增长20%以上。在基础设施、公共服务等领域探索PPP模式。用好土地利用总体规划评估修编、生态移民搬迁、农村土地确权颁证等政策，清理批而未供、供而未用闲置土地，确保重大工程和重点项目用地需求。为企业发展、项目建设提供“一站式”、“保姆式”服务，帮助完善各项手续。建立健全用工需求信息系统，开展校企合作和订单培训，帮助企业解决用工难问题。 
                              
 
  （四）以转型升级为主线，着力壮大工业经济。坚定不移实施工业强州战略，着力改造提升传统产业、做优做强特色产业、培育壮大新兴产业，工业总产值增长15%以上，让“工业经济活起来”。一是优化存量。深入实施工业“百千万”工程，以深化改革盘活存量，以降本增效巩固存量，以帮扶脱困释放存量。对金宏化工等7户难以复产企业，通过资产重组、股份制改革、资源回收等方式，使其焕发新活力；对贞丰久盛能源等70家负增长企业，进行“一企一策一专班”帮扶，帮助企业稳定和拓展市场。继续改造提升煤炭、黄金、电力等传统产业，帮助煤矿企业扩大产销，完成原煤产量3200万吨、黄金产量23吨，力争满负荷发电。二是扩大增量。扎实推进产业项目建设，搞好协调、加强督促、做好服务，力争兴仁煤电铝、兴义泰龙铁合金、安龙金源铁合金以及新恒基矿业、泰瑞佳新材料等项目建成投产，新增入库企业50户以上。抓住国家启动第二轮电力体制改革机遇，加快中电普安电厂建设，力争开工建设大唐兴仁电厂，做强电力产业。三是做活园区。强化产业定位，分级分类推进工业园区建设，防止产业雷同。培育壮大工业龙头企业，带动产业链上下游企业入园集聚发展，确保清水河、威舍、郑鲁万、兴仁、安龙工业园分别新入园产业项目15个以上，贞丰、普安、晴隆工业园和义龙试验区红星工业园分别新入园产业项目10个以上，册亨、望谟工业园（含飞地工业园）分别新入园产业项目5个以上。全州工业园区完成投资250亿元，规模以上工业总产值突破350亿元。四是调优结构。大力发展大健康医药、新能源、新型建筑建材等新兴产业，促进产业转型升级。认真贯彻落实省大健康医药产业发展规划和实施意见，推动德良方药业达产和苗嗓子药业、贵和堂中药饮片、江西医疗器械等项目投产；建成金茂LED灯、甲醇汽油、玄武岩纤维等项目，加快建设晴隆苏家屯风电项目，开工建设兴义白龙山、普安横冲梁子风电项目。 
               
 
  （五）以农民增收为核心，着力发展高效农业。高度重视粮食生产，确保粮食安全。按照“立体化、专业化、标准化”的要求，推动“高效农业搞起来”，实现农业增加值120亿元，农村居民人均可支配收入7400元。一是做宽市场。充分发挥州农产品流通协会作用，开展“农超对接”、“农企对接”、“农校对接”、“农社对接”，加快农产品销售窗口和实体店建设，拓宽农产品销售渠道。以组建州供销集团公司为契机，壮大农产品销售力量。加快涉农电子商务平台建设，加强与淘宝网等电商平台合作，实现网上销售收入1.5亿元以上。二是做强园区。整合水电路讯、土地整治、高标准农田建设、农业综合开发等项目资金，加强园区基础设施建设。做大做强现代高效农业示范园区，建设30个州、县级示范园区，新增10个以上省级示范园区，争创2个以上省级重点和1个国家级示范园区，确保入园企业总产值突破70亿元。三是做优特色。按照“一品为主、多品共融，以短养长、长短结合”的生态农业发展模式，加快山地特色农业发展，力争实现羊存栏150万只、牛存栏84万头、绿壳蛋鸡养殖500万羽，核桃种植150万亩、蔬菜种植120万亩，茶叶、中草药、精品水果种植分别达到50万亩，薏仁种植40万亩，收购烟叶80万担。四是做大龙头。大力培育农业产业化龙头企业，支持晴隆海权肉羊公司申报国家级龙头企业，推动安龙金州出口蔬菜公司、普安宏鑫茶业公司等龙头企业发展壮大，新增州级以上龙头企业50家。大力发展农民专业合作社、种养大户和各类专业协会，确保农业市场主体增长25%以上。五是做响品牌。出台农产品品牌创建奖励办法，鼓励企业申报农产品“三品一标”。建成绿色食品、无公害农产品、有机食品产地认定基地24万亩以上，认证产品35个以上，力争注册2个以上农产品原产地地理标志，培育晴隆羊、兴仁薏仁米、册（亨）望（谟）油茶等一批农产品品牌。 
                    
 
  （六）以旅游业为引领，着力做大服务产业。积极发展以旅游业、现代服务业为重点的第三产业，实现增加值375亿元以上。一是推动旅游业蓬勃发展。按照“旅游产业旺起来”工作部署，围绕旅游产品开发、市场营销、综合服务，加快构建“快旅慢游”服务体系，做旺旅游业，实现旅游总收入、旅游人数分别增长25%以上。加强基础设施建设，突出景区个性，打造万峰林等重点景区升级版。推进旅游综合体制改革，增强政府对旅游资源的调控能力。以打造贞丰者相等9个特色旅游小镇和安龙打凼等50个民族文化村寨为引领，发展乡村旅游。做好世界文化景观遗产申报工作。支持办好“万峰林美丽乡村·好歌旅游节”、“三月三”、“六月六”、“八月八”等民族传统节庆活动。加大旅游营销力度，在重要客源地设立旅游推介馆。探索“航线+旅游”的联合促销模式，着力培育旅游航线，确保兴义万峰林机场旅客吞吐量突破20万人次。二是推进服务业集聚发展。坚持“一核多点”，努力将贵州万峰林现代服务业开发区建成全省现代服务业聚集发展的标杆。推动现代服务业与现代农业融合发展，培育一批集展示交易、仓储冷冻、配送运输为一体的现代物流企业，大力发展营销贸易、电子商务等生产性服务业。积极发展休闲、娱乐、家政等生活性服务业，建成一批社会化养老服务基地。三是提升商贸服务水平。开工建设兴仁薏仁系列综合市场，完成10个以上农贸市场规范化建设。规范发展批零住餐业，建成浙兴商贸城（二期）和州邮政（快递）分拣转运中心；大力培育电子产品、节能汽车等消费热点，实现社会消费品零售总额177亿元以上。

  三、加强政府自身建设 
     
 
   
    
 
  各位代表，做好今年各项工作，必须进一步加强政府自身建设。我们要认真落实“三严三实”要求，按照“法治年”、“开放年”、“落实年”的安排部署，围绕转变发展方式、转变政府职能、转变干部作风，全面提高政府的公信力、执行力和创造力。 
      
 
  （一）依法履行政府职能。在守纪律、讲规矩上做表率，进一步减政、减负、减支，以政府权力的“减法”，换取市场活力的“加法”，充分发挥市场在资源配置中的决定性作用。抓好政务服务、公共资源交易、电子政务平台的运用和管理，织牢社会保障网、公共安全网、生态保护网。推行政府权力清单制度，建立完善依法审核、发布和动态管理工作机制，依法公开权力运行流程，坚决消除权力设租寻租空间。制定并向社会公布保留的前置审批及中介服务目录，全面取消于法无据的行政事业性收费。推行政府向社会力量购买服务，创新政府履行职能的方式方法。

    function IsMobile() {
        var isMobile = {
            Android: function () {
                return navigator.userAgent.match(/Android/i) ? true : false;
            },
            BlackBerry: function () {
                return navigator.userAgent.match(/BlackBerry/i) ? true : false;
            },
            iOS: function () {
                return navigator.userAgent.match(/iPhone|iPad|iPod/i) ? true : false;
            },
            Windows: function () {
                return navigator.userAgent.match(/IEMobile/i) ? true : false;
            },
            any: function () {
                return (isMobile.Android() || isMobile.BlackBerry() || isMobile.iOS() || isMobile.Windows());
            }
        };

        return isMobile.any(); //是移动设备
    }
