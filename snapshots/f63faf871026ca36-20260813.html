聚焦党代会丨中国共产党莆田市城厢区第十一次代表大会闭幕 来源:今日城厢 时间：2026-07-31 15:15 | | | | 【反向关联】 --> 7月31日 中国共产党莆田市城厢区第十一次 代表大会圆满完成各项议程 胜利闭幕 大会执行主席王文晖、黄建恩、欧国民、陈美钗、王丽媛、吴国庆、葛富裕、许玉树、方宇、余赛智、余立锋、郑纪、陈海防、黄智光在主席台就座。王文晖致闭幕词，黄建恩主持。 大会应到代表224名，实到217名，符合规定人数。 大会通过了中国共产党莆田市城厢区第十届委员会报告的决议(草案)、中国共产党莆田市城厢区第十届纪律检查委员会工作报告的决议(草案)。 王文晖在闭幕式上指出 这次大会，是在全区上下深入学习贯彻党的二十大和二十届历次全会精神，全面贯彻落实习近平总书记对福建工作的重要讲话重要指示批示精神，奋力开启“十五五”新征程的关键时期召开的一次十分重要的会议。这次大会，全面总结了过去五年的奋斗历程和宝贵经验，科学擘画了未来五年城厢发展的宏伟蓝图，鲜明提出加快打造“和美莆田、共同富裕”首善之区的发展愿景，明确“七个跃升”的发展目标，系统部署实力城厢、品质城厢、美丽城厢、活力城厢、和谐城厢五个方面的具体实施路径。全区上下要迅速把思想和行动统一到大会精神上来，凝聚思想共识，汇聚奋进力量，把大会确定的目标任务转化为高质量发展的实际成效。 就贯彻好党代会精神，王文晖强调 01要坚定不移、旗帜鲜明讲政治 全区各级党组织和广大党员干部要坚持不懈用习近平新时代中国特色社会主义思想凝心铸魂，深入学习贯彻习近平总书记对福建工作的重要讲话重要指示批示精神，深学细悟习近平总书记治理木兰溪的重要理念，坚定拥护“两个确立”、坚决做到“两个维护”。要始终胸怀“两个大局”、牢记“国之大者”，主动把城厢工作置于全国、全省、全市战略全局中统筹谋划，不折不扣落实上级决策部署，确保上级有号令、城厢见行动。 02要携手奋进、开拓进取谱新篇 牢记市委赋予城厢的使命任务，以文明和谐、活力充盈筑牢“和美”之基，以产业兴旺、城乡共荣、民生优享、生态宜居走好“共富”之路，以率先发展、领先发展扛起“首善”之责。紧扣“七个跃升”发展目标，聚力打造实力城厢、品质城厢、美丽城厢、活力城厢、和谐城厢，把“五个城厢”的发展路径转化为“和美莆田、共同富裕”首善之区的生动图景。 03要敢为人先、勇立潮头攀高峰 全区上下要拿出中心城区的担当，对标一流、跳起摸高，努力在服务全市大局中勇挑重担、走在前列。以“闯”的精神破难题，以“创”的劲头增优势，以“干”的作风求实效，破除惯性思维、路径依赖和畏难情绪，以改革开路、创新赋能，把资源优势转化为发展胜势，把每一项工作都干出首善标准、干出城厢速度、干出一流业绩。 04要上下同心、一以贯之创佳绩 各级党组织要把学习宣传贯彻党代会精神作为重要任务，推动大会精神进基层、进一线、进群众；各级领导干部要树立和践行正确政绩观，干事创业，攻坚克难，把成效书写在城厢大地上；各位代表要当好大会精神的宣传者、贯彻者、推动者，团结带动全区人民同心同德、同向同行，推动党代会各项部署落到底、见实效。 王文晖号召 让我们更加紧密地团结在以习近平同志为核心的党中央周围，在省委、市委的坚强领导下，奋进新征程、建功新时代，为加快打造“和美莆田、共同富裕”首善之区，奋力谱写全面建设社会主义现代化城厢新篇章而团结奋斗！ 会议还进行了换届风气测评，王文晖、郑纪分别代表新一届区委委员、候补委员以及区纪委委员作履职尽责公开承诺。 大会在雄壮的《国际歌》声中闭幕。 扫一扫在手机上查看当前页面 附件下载： 相关链接： {{
