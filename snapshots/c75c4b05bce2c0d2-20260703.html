枣庄要闻
市十六届人大常委会第四十四次会议召开 陈平主持
来源：枣庄日报全媒体
2022-01-20
&nbsp; &nbsp; &nbsp; &nbsp;1月19日，市十六届人大常委会第四十四次会议在市人大机关召开。市委书记、市人大常委会主任陈平主持会议，市人大常委会副主任徐玲、宋淑启、于良、刘志才、程涛，市人大常委会秘书长赵士亮出席会议。市委常委、市纪委书记李妍，市政府副市长邵士官，市中级人民法院党组书记于锡涛，市人民检察院党组书记宋晓磊列席会议。
&nbsp; &nbsp; &nbsp; &nbsp;会议作出关于召开枣庄市第十七届人民代表大会第一次会议的决定，枣庄市第十七届人民代表大会第一次会议将于2022年2月下旬举行。
&nbsp; &nbsp; &nbsp; &nbsp;会议审议通过了市人大常委会工作报告（稿），决定提请市十七届人大一次会议审议。
&nbsp; &nbsp; &nbsp; &nbsp;会议根据市人大常委会主任会议的提请，经过无记名投票表决，补选葛慧君同志为山东省第十三届人民代表大会代表。
&nbsp; &nbsp; &nbsp; &nbsp;会议经无记名投票表决，决定任命张庆伟、刘宏涛、左文为市人民政府副市长，决定免去市人民政府副市长、市公安局局长宋丙干等人员职务。
&nbsp; &nbsp; &nbsp; &nbsp;会议经无记名投票表决，任命李妍为市监察委员会副主任，决定李妍为市监察委员会代理主任；任命于锡涛为市中级人民法院副院长、审判委员会委员、审判员，决定 于锡涛为市中级人民法院代理院长；任命宋晓磊为市人民检察院副检察长、检察委员会委员、检察员，决定宋晓磊为市人民检察院代理检察长。
&nbsp; &nbsp; &nbsp; &nbsp;会议经表决，决定接受王玉波辞去枣庄市监察委员会主任职务的请求，接受孙英辞去枣庄市中级人民法院院长职务的请求，接受张敬艳辞去枣庄市人民检察院检察长职务的请求。
&nbsp; &nbsp; &nbsp; &nbsp;会议还任免了其他有关人员职务，并为新任命人员颁发了任命书。
&nbsp; &nbsp; &nbsp; &nbsp;会后，举行了宪法宣誓仪式，市委书记、市人大常委会主任陈平主持并监誓。陈平要求，新任命人员要深入学习贯彻习近平新时代中国特色社会主义思想，增强“四个意识”，坚定“四个自信”，做到“两个维护”，&nbsp;捍卫“两个确立”，忠于宪法、遵守宪法、维护宪法，加强宪法实施，履行宪法使命，为“工业强市、产业兴市”作出积极贡献，以优异成绩迎接党的二十大胜利召开。
&nbsp; &nbsp; &nbsp; &nbsp;列席会议的还有：市监察委员会、市政府办公室负责人；市人大常委会副秘书长、市人大常委会各室（工委）主要负责人。
