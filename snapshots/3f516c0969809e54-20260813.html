 区委书记调研高考考前准备工作

 来源:荔城在线

 时间：2026-06-04 21:27

 | 
 
 |

 | 
 
 |

 　　2026年高考在即。6月4日，区委书记杨兴斌带队调研高考考前准备工作。区领导刘基棠、陈忠、翁林、李振海、唐荣堂、林错错一同或分别参加。 
 　　杨兴斌一行先后来到莆田第四中学和莆田第八中学，实地察看高考考点周边环境、考场设置、监控运行等考前准备工作情况，详细听取了考务组织、应急处置、安全保密等相关工作汇报情况，并结合现场实际提出针对性指导意见。 
 　　杨兴斌强调，高考事关万千考生人生前程，连着千家万户切身利益，是社会高度关注的民生大事。各级各部门要紧扣树立和践行正确政绩观学习教育要求，树牢以人民为中心的发展思想，统筹教育、公安、交警、卫健、市场监管、城管等多方职能部门力量，完善应急预案，压实联防联控责任，确保高考指挥体系高效畅通、响应迅速。要紧盯考场设备运行、试卷流转、应急处置等关键环节，全面开展隐患回头看，对发现的问题立行立改，做到不留盲区、不漏细节，全力守住考试安全红线。要立足考生实际需求，完善便民助考举措，细化考生帮扶、考点便民服务、天气应急保障等配套内容，用心用情为广大考生营造安静、舒心、安全的考试环境。
