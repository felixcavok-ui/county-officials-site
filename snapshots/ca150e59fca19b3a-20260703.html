# 魏树旺简历

**基本信息**
- 出生：1967年12月（现年58岁）
- 籍贯：河北清苑
- 民族：汉族
- 政党：中国共产党

**教育背景**
- "1992年毕业于北京师范大学思想政治专业"

**职务履历**

| 时间 | 职位 |
|------|------|
| 2010年 | 六盘水市委常委 |
| 2010年代 | 六盘水副市长、市委副书记 |
| 2010年代 | 遵义市委副书记、副市长 |
| 2015年5月-2019年10月 | "遵义市市长" |
| 2018年2月 | 贵州省人民政府秘书长（第一次） |
| 2018年3月 | 返回遵义继续担任市长 |
| 2019年8月-2022年6月 | 中共遵义市委书记 |
| 2022年6月至今 | 贵州省人民政府办公厅党组书记、主任 |
| 2022年7月至今 | 贵州省人民政府秘书长（第二次） |

**其他身份**
- 2018年被选为第十三届全国人民代表大会贵州省代表
