 关于县人民政府领导成员工作分工的通知 
 各乡（镇）人民政府、街道办事处，县政府各部门、各直属机构： 
 因人事变动，经研究，决定对县人民政府领导成员工作分工进行调整。现将调整后的县政府领导成员工作分工通知如下： 
 一、袁超洪县长：领导县政府全面工作，主管编制、人事、监察、财税、审计、武委会、金古管委会等工作。 
 二、吕永青常务副县长：负责县政府常务工作；县长外出时，主持县政府工作。协助分管国土资源、住房和城乡规划建设、城市管理、人民防空等工作。协助县长抓监察、人事、财税、审计具体工作。 
 分管部门：监察局、公务员局、财政局、国土资源局、住房和城乡规划建设局、审计局、人防办 ( 民防局 ) 、城监大队、城市建设投资有限责任公司。 
 联系县政协。 
 联系单位： 现代物流开发区管委会、 国税局、地税局、 邮政局、电信分公司、长线分局、移动分公司、联通分公司、铁通分局、 196 地质大队、南昌铁路局沙县采石车间。 
 三、邱华英副县长：协助分管教育、文化体育、广播电视、新闻出版、卫生、人口计生、民族与宗教事务、地方志和政府系统精神文明建设等工作。 
 分管部门：教育局、卫生局（爱卫办）、人口计生局、文体广电出版局、民族与宗教事务局、方志委。 
 联系单位：文明办、团县委、妇联、社科联、文联、老体协、计生协、关工委、档案局、食品药品监管局。 
 四、乐生龙副县长：协助分管交通运输、乡村公路、高速公路、铁路、机场建设、旅游等工作。 
 分管部门：交通运输局（交战办）、旅游局、公路建设指挥部、高速公路建设指挥部、铁路建设指挥部、机场办。 
 联系单位： 公路分局、南昌铁路局沙县车站、闽通长运分公司、官蟹航运公司。 
 五、陈剑生副县长：协助分管政府办 ( 驻外机构 ) 、发展和改革、工业、统计、物价、政务服务、效能、纠风等工作。 
 分管部门：县政府办（法制办、机关事务管理局、驻外机构）、发改局（物价局）、经贸局（工业方面）、统计局、行政服务中心管委会、效能办、纠风办。 
 联系单位： 石油分公司 、 盐业支公司 、供电有限公司 、 青山纸业股份有限公司 。 
 六、乐荣光副县长：协助分管农村、农业、林业、水利、粮食、供销、公安、消防、司法、信访、小吃等工作。 
 分管部门：农业局（畜牧兽医水产中心）、林业局、水利局（防汛办）、粮食局、供销社、公安局、司法局、信访局、小吃办、小吃集团、官昌水库管理处、自来水公司。 
 联系单位：法院、检察院，人武部、驻沙部队，消防大队、武警中队，老干局、综治办、农办、农科院、农校、烟草局、气象局、水文站、高砂水电有限公司、城关水电有限公司、官庄林场、水南林场 。 
 七、施剑峰副县长：协助分管安全生产、食品安全、环保、外事、侨务、外经贸、招商引资、城镇集体工业、商贸、物资等工作，联系对台工作。 
 分管部门：经贸局（内贸方面及支前办、食安办）、环保局、安监局 ( 县安办 ) 、外侨办、外经贸局、贸促会（国际商会）、农金办、城镇集体工业联社、商贸公司、物资公司。 
 联系单位：台办、总工会、 工商联（总商会、个私办）、 侨（台）联、工商局、质监局、人行、银监办、金融、保险、证券机构。 
 八、赵振华副县长（挂职）：协助分管科技、知识产权，主抓硅化工产业，协助招商引资等工作。 
 分管部门：科技局（地震办）。 
 联系单位：科协。 
 九、黄建烟副调研员：协助吕永青常务副县长工作，具体抓城市管理等工作。 
 十、廖善健副调研员：协助分管民政、老区、老龄、人力资源和社会保障、库区移民，主抓双溪水库项目建设，协助东门片区征迁等工作。 
 分管部门：民政局（老龄办）、老区办、人力资源和社会保障局、移民局。 
 联系单位：残联、老促会。 
 为了相互支持、相互配合、相互衔接，提高效率，县政府领导成员实行 AB 角工作制度，吕永青与乐生龙、邱华英与赵振华、陈剑生与施剑峰、乐荣光与廖善健互为 AB 角。
