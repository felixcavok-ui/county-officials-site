function setDateTime(id){

var vMon = d.getMonth() + 1;
var vDay = d.getDate();
var date = vMon+"/"+vDay+"/"+vYear; //此处也可以写成 17/07/2014 一样识别也可以写成 07-17-2014 但需要正则转

$("#"+id).html(thistext);
}

市十五届人大五次会议开幕李雅林主持大会殷昭举作政府工作报告陈少宏作市人大常委会工作报告 5月14日上午，潮州市第十五届人民代表大会第五次会议在市党政机关会堂开幕。来自全市各行各业、各条战线的人大代表肩负使命与重托，齐聚一堂、共商大计，共同描绘潮州高质量发展蓝图。　　开幕大会由大会主席团常务主席、大会执行主席李雅林主持。　　大会主席团常务主席、大会执行主席林壮森、姚继新、陈少宏、黄洪、黄潮标、林跃、陈史青、杨顺才、林镇光在主席台前排就座。　　市领导殷昭举、杨志明、李尧坤、徐和、王少勇、张传胜、赖建华、王文森、姚登峰,市中级人民法院代理院长任宗理、市人民检察院检察长陈伊拉，以及主席团其他成员在主席台就座。　　出席大会代表304人，符合法定人数。　　会上，市长殷昭举向大会作政府工作报告。报告指出，过去一年，市政府围绕省委“1+1+9”和市委“1+5+2”工作部署，按照“做好‘特、精、融’三篇文章，打造沿海经济带上的特色精品城市”发展定位，积极抢抓“双区”建设重大机遇，坚持稳中求进工作总基调，以供给侧结构性改革为主线，推动高质量发展，统筹做好“六稳”工作，经济社会呈现高质量发展态势。全市实现生产总值1080.9亿元，增长5%。　　报告指出，2020年新冠肺炎疫情发生以来，我市因应防控形势变化实施“一手强防控、一手强防治”等一系列防控策略，坚持统筹推进疫情防控和经济社会发展，疫情防控形势持续向好、经济社会运行加快复苏。　　报告提出，今年政府工作的总体要求是：以习近平新时代中国特色社会主义思想为指导，全面贯彻党的十九大和十九届二中、三中、四中全会以及中央经济工作会议精神，坚决贯彻党的基本理论、基本路线、基本方略，深入贯彻落实习近平总书记对广东重要讲话和重要指示批示精神，增强“四个意识”、坚定“四个自信”、做到“两个维护”，认真贯彻落实省委十二届七次、八次、九次全会和市委十四届八次、九次全会精神，紧紧围绕省委李希书记对潮州指示批示精神和“打造沿海经济带上的特色精品城市”发展定位，紧扣全面建成小康社会目标任务，坚持稳中求进工作总基调，坚持新发展理念，坚持以供给侧结构性改革为主线，坚持以改革开放为动力，在疫情防控常态化条件下抓实抓好经济社会发展各项工作，坚决打赢三大攻坚战，扎实做好“六稳”工作、全面落实“六保”任务，统筹推进稳增长、促改革、调结构、惠民生、防风险、保稳定，坚定不移推进“1+5+2”和“六大工程”工作部署，加快高质量发展，不断优化营商环境、法治环境、行政环境、城乡环境，确保全面建成小康社会和“十三五”规划圆满收官，取得人民群众认可、经得起历史检验的新业绩。　　报告指出，综合各方面因素，今年我市经济社会发展的主要预期目标是：生产总值增长5.5%左右，一般公共预算收入增长3%，固定资产投资增长6-6.5%，外贸进出口总额增长1%，社会消费品零售总额增长6.5%，居民消费价格指数涨幅控制在3%以内，居民收入增长和经济增长基本同步，城镇登记失业率控制在3.5%以内。　　报告指出，为实现上述目标，今年将重点做好六方面工作：一是坚持深化改革开放，积极对接融入“双区”建设；二是坚持推动高质量发展，推进总投资超1267亿元的“六大工程”，加快产业转型升级，狠抓重大项目建设，深化创新驱动发展，推动文旅融合发展，大力发展商贸服务业，建设现代化经济体系；三是坚持共建共治共享，提升城市治理、交通发展、基础保障、平安建设水平，推动治理体系和治理能力现代化；四是坚持新发展理念，突出抓重点、补短板、强弱项，决战决胜精准脱贫、污染防治、风险防控三大攻坚战；五是坚持强化保障支撑，用心用情用功办好民生实事；六是坚持加强党的建设，全力打造廉洁高效政府。　　市十五届人大常委会代理主任陈少宏向大会作市人大常委会工作报告。报告回顾总结一年来市人大常委会的主要工作及成效，指出做好新时代潮州人大工作，必须毫不动摇坚持党的领导，必须深刻认识人民代表大会制度的政治定位，必须深深扎根潮州改革发展热土。报告提出，新的一年，市人大常委会将持续深入学习贯彻习近平新时代中国特色社会主义思想和党的十九届四中全会精神；坚持党的全面领导，着力行使好决定权和任免权；完善立法体制机制，着力提高立法工作质量和效益；围绕全市发展大局，着力提高监督的针对性和实效性；更好发挥代表作用，着力深化县镇人大工作和建设；不断加强自身建设，着力提高依法履职能力和水平，以新担当新作为推动我市人大工作高质量发展，更好助力我市“打造沿海经济带上的特色精品城市”。　　市中级人民法院代理院长任宗理向大会作市中级人民法院工作报告。报告回顾总结2019年全市法院工作，提出2020年全市法院将始终把牢正确政治方向，落实市委“1+5+2”工作部署，服务保障潮州经济持续健康发展和社会大局稳定，深化司法体制综合配套改革和智慧法院建设，全面加强法院队伍建设，为把潮州打造成为沿海经济带上的特色精品城市提供更加有力的司法服务和保障。　　市人民检察院检察长陈伊拉向大会作市人民检察院工作报告。报告回顾总结2019年全市检察工作，提出2020年全市检察机关将旗帜鲜明地讲政治，充分发挥检察职能，更好为大局服务，着力推动“四大检察”全面协调充分发展，以“四化”要求锻造“四个铁一般”检察队伍，努力用法治力量为新时代潮州实现高质量发展助力护航。　　大会还审查了潮州市2019年国民经济和社会发展计划执行情况与2020年计划草案的报告及2020年国民经济和社会发展计划草案、潮州市2019年预算执行情况和2020年预算草案的报告及2020年预算草案；通过了大会选举办法。　　出席政协潮州市十二届四次会议的委员在湘桥区党政机关大院分会场以视频会议形式列席大会。
