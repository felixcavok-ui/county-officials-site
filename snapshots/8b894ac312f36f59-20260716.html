宝安区 是 中华人民共和国  广东省  深圳市 的一个 市辖区 、位于深圳西北部， 珠江 出海口的东岸，与 广州市  南沙区 对望，是深圳与广州唯一邻接的区域。宝安区成立于1992年11月11日，现管辖区域面积为553.82 平方公里 ，宝安区曾是深圳的工业强区，尤其以电子相关生产为主。 前海合作区 部分地块位于宝安区内。区内有 深圳宝安国际机场 ，区人民政府驻 新安街道 创业一路1号。
名称由来
[   编辑   ]
宝安，因旧县境北有宝山（今东莞市境内），寓“得宝而安”之意，故而得名。
历史
[   编辑   ]
宝安在上古时为 百越 的一部分。 东晋 年间置 宝安县 ，当时范围包括现时深圳和香港。 明朝 中叶，由于 倭寇 侵扰，经当地 乡绅 提议，转为“新安县”，取“革故鼎新，去危为安”之意。近代开始，新安县的管辖范围不断缩小，于鸦片战争至民国成立期间，新安县深圳河以南的辖区成为 英属香港 。1914年，因应民国成立，全国行政区域整编，新安县改回原名为“宝安县”。
1979年3月宝安县改制深圳市，1979年10月宝安县 深圳镇 和盐田等地改制成立 罗湖区 。1981年，中国政府决定恢复宝安县建制，辖深圳经济特区之外的部分。1982年12月国务院正式批准恢复宝安县建制，隶属深圳市。1986年宝安县沙头乡和上埗村一带地域改制成立上埗区（今 福田区 ），1990年1月4日宝安县南头墟、南山、蛇口、西丽等地改制成立 南山区 ，1992年11月11日宝安县再度整编，将宝安县东北一带的龙岗、大鹏、布吉、坂田和坪山等地分拆成立 龙岗区 ，在原宝安县西北的龙华、观澜、西乡、福永、松岗、光明一带设立宝安区。
2007年5月31日，深圳市人民政府宣布成立 光明新区 ，管辖原宝安区公明街道和光明街道。2010年7月1日，宝安区和 龙岗区 正式被划入为 深圳经济特区 的一部分，2011年12月30日，龙华新区成立，将管辖原宝安区龙华、大浪、民治、观澜4街道。2016年10月11日，国务院批复广东省政府，同意设立深圳市 龙华区 ，以龙华、大浪、民治、观湖、福城、观澜等6个街道的行政区域为龙华区行政区域   [ 3 ]   。2016年12月26日，宝安区管辖的街道由6个拆分为10个，其中西乡、福永、沙井、松岗4个街道分设为西乡、航城、福永、福海、沙井、新桥、松岗、燕罗8个街道办事处，石岩、新安街道办事处不变   [ 4 ]   。
地理
[   编辑   ]
宝安区地处 东经 113°52'， 北纬 22°35'，地势是东高西低，最高海拔为羊台山山顶587米   [ 5 ]   。海岸线集中在西部，长30.62 公里 。由于临 珠江 河口，西面海岸多为泥岸和平原，属于 珠江三角洲 一部分。东部的龙华、石岩等地以 丘陵 地貌和 盆地 为主、宝安区属 亚热带季风气候 ，平均气温 摄氏 22度，年雨量1926毫米。

人口
[   编辑   ]
2024年全区年末常住人口460.33万人，比上年末增加3.78万人，增长0.8%；常住户籍人口115.28万人，增长5.0%，常住非户籍人口345.05万人，下降0.5%。户籍人口出生率15.0‰，死亡率1.1‰，自然增长率13.9‰。   [ 7 ]
经济
[   编辑   ]
壹方城 是宝安区最大的商场
宝安区早期主要以农业、制造业为主，工厂主要集中在 沙井街道 、 石岩街道 等区域。生产领域大多涉及电子，现经济核心区为新安街道。   [ 8 ]
于2022年，第三产业占地区生产总值(2212.48亿)比重首次超过第二产业(2384.33亿)；但于2023年被第二产业反超，即第三产业占地区生产总值(2441.12亿)，第二产业(2528.65亿)。   [ 8 ]
2023年末，人均可支配收入为70008元   [ 8 ]   ，全区共有从事第二产业和第三产业活动的法人单位26.49万个，与2018年第四次全国经济普查相比，增长47.4%；个体经营户17.35万个，增长34.5%。   [ 9 ]
2025年全年，宝安区地区生产总值为5430.03亿元，按不变价格计算（下同），同比增长2.6%。其中，第一产业增加值为4.07亿元，同比下降32.7%；第二产业增加值为2720.00亿元，同比增长0.8%；第三产业增加值为2705.96亿元，同比增长4.8%。   [ 10 ]
商业
[   编辑   ]
宝安区的商场与大型写字楼主要集中于与 南山区 接壤的 新安街道 ，宝安中心CBD是深圳西部的主要CBD。作为传统商业重镇的 西乡街道 亦有不少商业大厦。位于新安街道的 壹方城 是深圳人流量最大的商场之一   [ 11 ]   ，临近的 欢乐港湾 （ 湾区之光 ）与 湾区之眼 是游客常去的商旅结合景点。由于临近深圳湾口岸，不少 港人 热衷于到宝安区消费。
工业
[   编辑   ]
在深圳建设 经济特区 之前，如今宝安区范围内已有农械厂、水泥厂、食品厂等小规模工厂。深圳经济特区起步时，宝安区是深圳市内重要的工业基地，吸收了大量港台投资。随着特区逐渐发展，宝安区开始承接原关内四区的工业产能。宝安区一直以 出口导向性 工业为主，主要生产电子通讯元器件、塑料制品、模具、 计算机 等。随着科技发展， 智能机器人 、新材料、 超高清视频 显示等高科技制造业成为宝安新的工业优势项目   [ 12 ]   。
农业
[   编辑   ]
宝安区农业规模不大，区内仅零星种植粮油作物，无天然林，畜牧业也规模极小， 蚝 业是主要产业， 沙井街道 的 沙井蚝 是深圳重要水产品。

交通
[   编辑   ]
铁路
[   编辑   ]
穗深城际铁路 贯穿宝安区， 沙井西站 、 福海西站 、 深圳机场北站 和 深圳机场站 均位于宝安区，被列为同城站。
机场
[   编辑   ]
深圳宝安国际机场 设于 航城街道 和 福永街道 交界处。
道路
[   编辑   ]
与东部的 龙岗区 相比，宝安区的道路网络较为发达，然而由于属关外地区，经济以制造业为主，大量重型车辆出入，使部分区域的道路例如宝石东路，多数破烂不堪。
区内高速公路包括 机荷高速公路 、 广深公路 ( 107国道 )、 梅观高速公路 、 龙大高速公路 、 南光高速公路 、 广深高速公路 、 广深沿江高速公路 等。
区内主干道有 宝安大道 、 洲石公路 、 松白路 等。

港口
[   编辑   ]
由2006年在 前海湾 填海的 大铲湾码头 ，是 深圳港 的一部分。
景点
[   编辑   ]
凤凰山
[   编辑   ]
凤凰山有着非常浓厚的人文气息。山下的凤凰古村是文天祥族人后裔的祖居和民居，始建于宋末年初大德年间。
曾氏大宗祠
[   编辑   ]
曾氏大宗祠是一处家族祠堂建筑，属于曾氏家族祭祀祖先和先贤的场所，是深圳建筑规模最大的广府祠堂而始建年代有待考证，现建筑是清嘉庆三年戊午（1798）大规模扩建而成的。
永兴桥
[   编辑   ]
永兴桥，始建于清康熙年间，后又在乾隆五十年重新修建，距今已经有两百多年的历史。作为深圳唯一的一座古代三孔石拱桥。1984年，永兴桥被列为市级重点文物保护单位。
北帝古庙
[   编辑   ]
西乡北帝古庙，位于西乡步行街旁，建于明朝万历年间（1537年），内奉北方真天精武玄天上帝。
海上田园
[   编辑   ]
深圳海上田园是一个集生态景观、会所、别墅为一体的观光、度假、休闲娱乐等多种功能旅游综合区。
欢乐港湾
[   编辑   ]
湾区之光摩天轮(亚洲最高海景摩天轮)、 湾区之声演艺中心( 深圳首座国际标准大剧场)坐落于此。
西湾红树林公园
[   编辑   ]
滨海栈道、红树林湿地坐落于此。
