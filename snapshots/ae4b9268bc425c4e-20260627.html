'''丁巍'''（{{bd|1957年|4月||catIdx=D丁}}），男，汉族，[[山西]][[晋城]]人，[[中华人民共和国]]政治人物。[[郑州大学]]历史专业毕业。[[第十三届全国人大代表]]。

== 生平 ==
1974年5月参加工作，1976年11月加入[[中国共产党]]。1978年10月至1982年8月在[[郑州大学]]历史专业学习。

1982年8月至1985年1月任[[商丘县]][[双八镇]]镇长。1985年1月至1988年11月任共青团河南省[[商丘]]地委书记。1988年11月至1992年6月任中共商丘县委副书记。1992年6月至1994年1月任[[永城县]]县长（1992年2月至1993年12月在[[天津大学]]研究生院管理系管理工程专业研究生学习）。1994年1月至1997年11月任[[中共夏邑县委]]书记（1996年9月至1997年7在[[中央党校]]中青年干部培训班学习）。

1997年11月，任[[中共商丘市委]]秘书长；2001年6月，任商丘市副市长。

2003年6月至2006年9月，任[[中共驻马店市纪委]]书记（2004年3月至2006年1月在中央党校研究生院[[法学]]理论专业学习）。2006年9月，任[[中共驻马店市委]]副书记。

2008年3月至2011年9，任[[鹤壁市人民政府]]市长；2011年9月至2013年4月，任[[中国共产党鹤壁市委员会|中共鹤壁市委]]书记。

2013年4月，任[[中共安阳市委]]书记<ref>{{cite web |url=http://www.aynews.net.cn/Article/2013/201304/231500.html |language= |title=安阳市委书记丁巍同志简历 |publisher=安阳日报 |date=2013-04-08 |accessdate= |archive-url=https://web.archive.org/web/20150325225505/http://www.aynews.net.cn/Article/2013/201304/231500.html |archive-date=2015-03-25 |dead-url=yes }}</ref><ref>{{cite web |url=http://www.chinadaily.com.cn/hqcj/zxqxb/2013-04-08/content_8697558.html |language= |title=丁巍任河南安阳市委书记 张笑东被免职(简历) |publisher=中国经济网 |date=2013-04-08 |accessdate= |archive-url=https://web.archive.org/web/20160605120805/http://www.chinadaily.com.cn/hqcj/zxqxb/2013-04-08/content_8697558.html |archive-date=2016-06-05 |dead-url=yes }}</ref>。

2016年5月，任[[中共河南省委]]副秘书长<ref>{{cite news|accessdate=2016-05-16|url=http://www.thepaper.cn/newsDetail_forward_1469033|title=河南省一天内集中任命平顶山信阳许昌安阳焦作5市市委书记|publisher=澎湃新闻|archive-date=2016-06-10|archive-url=https://web.archive.org/web/20160610133903/http://www.thepaper.cn/newsDetail_forward_1469033|dead-url=no}}</ref>。

2017年1月，当选为河南省十二届人大常委会秘书长<ref>{{cite web |url=http://district.ce.cn/newarea/sddy/201701/20/t20170120_19760697.shtml |language= |title=丁巍任河南省人大常委会秘书长 张启生不再担任 |publisher=中国经济网 |date=2017年1月20日 |accessdate= |archive-date=2019年5月12日 |archive-url=https://web.archive.org/web/20190512141304/http://district.ce.cn/newarea/sddy/201701/20/t20170120_19760697.shtml |dead-url=no }}</ref>。2018年2月24日，当选为[[第十三届全国人大代表]]<ref>{{Cite web|title=（受权发布）中华人民共和国第十三届全国人民代表大会代表名单-中新网|url=http://www.chinanews.com/gn/2018/02-25/8453959.shtml|accessdate=2021-02-13|work=中新网|archive-date=2018-02-27|archive-url=https://web.archive.org/web/20180227031724/http://www.chinanews.com/gn/2018/02-25/8453959.shtml}}</ref>。2020年6月，因年龄原因辞去[[河南省人大常委会]]秘书长<ref>{{cite web |url=http://district.ce.cn/newarea/sddy/202006/04/t20200604_35043299.shtml |language= |title=丁巍辞去河南省人大常委会秘书长职务 |publisher=中国经济网 |date=2020-06-04 |accessdate=2020-06-04 |archive-date=2020-06-04 |archive-url=https://web.archive.org/web/20200604045100/http://district.ce.cn/newarea/sddy/202006/04/t20200604_35043299.shtml |dead-url=no }}</ref>。
