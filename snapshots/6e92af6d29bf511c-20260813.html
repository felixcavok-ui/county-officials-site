 县委召开上半年工作会议

 吴海端讲话　蔡志主持

 来源:仙游今报

 时间：2026-08-07 08:31

 | 
 
 |

 | 
 
 |

 　　今报讯 （今报全媒体记者 陈溢）8月5日上午，县委召开上半年工作会议，深入学习贯彻习近平总书记对福建工作的重要讲话重要指示批示精神，贯彻落实中央政治局会议精神，按照省委、市委上半年工作会议部署，牢固树立和践行正确政绩观，深入开展“三争”行动，总结上半年工作，研究部署下半年工作，推动经济社会高质量发展，奋力实现“十五五”开好局起好步。县委书记吴海端出席并讲话。县委副书记、代县长蔡志主持会议，点评全县经济社会发展情况并作具体部署。县领导陈峻青、林宇家、郑碧娥、林金涛出席。 
 　　会上，县发改局和仙游经济开发区、鲤城街道、菜溪乡、郊尾镇相关负责人汇报上半年全县经济社会发展情况及有关情况及下一步思路举措；县农业农村局、工信局、住建局、商务局、财政局、统计局，仙游生态环境局及其他乡镇（街道）、管委会书面汇报本地区上半年经济社会发展情况及下一步思路举措;县委办书面通报深入开展“三争”行动有关情况。 
 　　吴海端指出，要洞察“时”与“势”，在坚定信心中吹响“敢为人先”冲锋号。今年以来，全县上下深入学习贯彻习近平总书记对福建工作的重要讲话重要指示批示精神，按照省委省政府、市委市政府工作要求，统筹发展和安全，牢固树立和践行正确政绩观，坚持向上对标、向实发力、向优奋进，全县上下比学赶超、争先进位的发展劲头持续巩固，交出了一份底色厚重、成色饱满、亮色鲜明的“半年报表”。 
 　　吴海端强调，要统筹“量”与“质”，在破题攻坚中打出“实干争先”组合拳。坚持创新驱动，让企业发展发财，在提升产业能级上持续用力，进一步积蓄传统产业存量势能，进一步培育新兴产业增量动能，进一步挖掘未来产业变量潜能。在扩大有效需求上精准发力，投资要抓实物、提效益；消费要抓挖潜、提质效，打造具有代表性、带动性的消费新场景；外贸要抓订单、稳份额，保持外贸良好发展势头，推动开放型经济健康发展。在积极争资争项上竭尽全力，力争更多项目纳入国家和省、市盘子，切实把政策含金量转化为发展实物量。坚持共建共享，让人民安居乐业，要算好民生一本账，绘好城乡一张图，下好治理“一盘棋”，全力解决人民群众最关心最直接最现实的利益问题，推动各项民生攻坚工作破题起势、见行见效。让城市有内涵更有品质，以城市品质提升十大行动、20项重点项目为抓手，加快建设创新、宜居、美丽、韧性、文明、智慧的现代化人民城市。让乡村有颜值更有气质，迭代升级跨村跨镇联建、片区组团发展模式，推动“一村一品”向“一片一产”升级，实现兴业、强县、富民一体发展。全面推进信访工作法治化，打造更高水平的平安仙游、法治仙游。坚持严管厚爱，让干部成长成才，慎始慎终抓学习教育，有力有效抓干部队伍，从严从实抓作风建设，持续巩固拓展学习教育成果。激发干部队伍内生动力和整体活力，让愿担当、敢担当、善担当蔚然成风。 
 　　吴海端要求，要扛牢“职”与“责”，在狠抓落实中跑出“一马当先”加速度。全县各级党委（党组）要想干事，解决观念问题，以思想的大解放、观念的大转变、思路的大拓展，促进经济社会的大发展。要敢干事，直面深层矛盾，敢于破旧立新、善于推陈出新，敢打硬仗、敢涉险滩，以钉钉子精神抓好改革落实。要会干事，锤炼过硬本领，切实以思想观念之变、思维方式之变推动路径之变、发展之变。 
 　　蔡志强调，全县各级各有关部门要铆足劲头、保持定力，努力补短板、锻长板、固底板、育新板，不断巩固拓展经济稳中向好的态势，确保顺利完成全年目标任务。要抓经济发展，推动一产稳基础、二产强筋骨、三产增活力，统筹抓好农业稳产、工业增效、消费扩容，不断夯实高质量发展根基。要抓发展后劲，全力攻坚项目、招商引资和向上争取资金，做大项目储备库、做实要素保障、做优营商环境，持续积蓄发展动能。要抓民生福祉，坚持就业优先导向，加快补齐教育、医疗、养老等公共服务短板，用心用情解决群众急难愁盼，不断增强群众获得感。要抓安定稳定，从严从实抓好安全生产、生态环保、矛盾纠纷排查化解等各项工作，强化源头治理、加强隐患排查、健全长效机制，坚决守住不发生系统性风险的底线，以实干实绩确保“十五五”开好局、起好步，为实现“和美仙游、共同富裕”新愿景贡献力量。 
 　　会议以视频形式召开，各乡镇街道（管委会）设分会场。
