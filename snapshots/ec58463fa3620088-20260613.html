雨花台区第十九届人大常委会第三次会议纪要&nbsp;&nbsp;雨花台区第十九届人大常委会第三次会议于2022年5月31日在区级机关九楼会议室举行。区人大常委会主任杨明，副主任艾长青、卞艳艳、贾乐实，委员王屹、王强、王纯阳、田海霞、戎锋、乔兰俊、朱运刚、任伯亭、刘军、杜家伟、杨春霞、李进进、张思军、张晓东、陈冬华、俞蓉、夏红忠、殷正标、高建平、陶文、崔益富、屠嘉顺、蒋宁卫、窦勇、魏平出席会议。区委常委、区政府副区长蓝波，区人大常委会领导顾晓春、陈苏宁，区法院院长黄德清，区检察院检察长肖水金，区纪委副书记、监委副主任金晖，区人大常委会《长江保护法》执法检查组成员单位、区人大各专委、区人大常委会各工作机构负责人和部分区人大代表列席本次会议。会议由区人大常委会副主任卞艳艳主持。一、会议传达学习了省委人大工作会议精神。二、会议听取和审议了区法院院长黄德清同志所作的关于审判辅助人员队伍建设情况的报告。三、会议听取和审议了区检察院检察长肖水金同志所作的关于虚假诉讼检察工作情况的报告。四、会议听取和审议了执法检查组所作的关于《中华人民共和国长江保护法》执法检查情况的报告。常委会组成人员充分肯定了相关单位在上述工作中取得的成绩，并提出了积极的意见和建议。会议决定，针对以上第二、三、四项议题提出的意见建议，将按照监督法的要求形成审议意见书，分别交由相关单位研究处理。五、会议组织了驻区市人大代表谢国庆向区人大常委会书面报告履职情况，并进行满意度测评。六、会议决定，任命李方毅同志为雨花台区人民政府副区长、代理区长职务，接受张连春同志辞去雨花台区人民政府区长职务。会议讨论通过了其他人事任免事项，举行了新任命人员的宪法宣誓仪式。会议结束前，区人大常委会主任杨明发表讲话，点评了会议各项议题，并就贯彻落实省委人大工作会议精神作了部署：一是提高政治站位，把思想和行动统一到会议精神上来。坚定不移贯彻落实坚持党的领导这一最高政治原则，积极协助区委筹备召开人大工作会议，总结全区人大工作和民主法治建设的基本经验。二是服务中心大局，更好助力经济社会发展。主动在防疫情、稳经济、保安全三大任务中履职尽责、担当作为。三是提高履职能力，扎实抓好年度重点工作。&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 南京市雨花台区人大常委会办公室整理&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 2022年6月2日
