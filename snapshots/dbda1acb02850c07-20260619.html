县委领导 县 委 书 记：牛方括 主持县委全面工作 县委副书记、县长：孙奇志 负责县政府全面工作 县委副书记：蒋青松 负责县经济开发区、招商引资工作，分管县委党校。 县委常委、副县长：房鲲鹏 负责县政府分工工作。 县委常委、宣传部长、统战部长：王亚晖 负责宣传思想文化、意识形态、统一战线、对台、民族宗教、城乡文明创建和文旅产业、民营经济工作，分管县委教育工作领导小组秘书组、县委网信办、县委讲师组、县文明办、县文联、县融媒体中心、县工商联、县侨联、县台办。 县委常委、政法委书记：牛 斌 负责政法、信访、维护稳定工作，负责县委依法治县办、县总工会工作，分管县委信访局，联系县法院、县检察院。 县委常委、组织部长：洪毅然 负责党的农村、组织、群团、目标考核工作，分管县直机关工委、县委编办、县委老干部局、团县委、县妇联、县科协、县委非公有制经济和社会组织工委、县档案馆，协助蒋青松同志分管县委党校，联系县人大、县政协。分管县总工会。 县委常委、纪委书记、监委主任：袁 东 负责纪检监察和县委巡察工作。 县委常委、人武部政委： 胡玉强 负责人民武装、国防动员和民兵预备役工作。 县委常委、县政府常务副县长： 李景练 负责县政府分工工作。 县委常委： 赵德兵 负责新桥国际产业园工作。 县委常委、寿春镇党委书记： 李锐 负责寿春镇党委、县国有资产投资运营（集团）有限公司党委全面工作。 县委常委（挂）、寿县蜀山现代产业园区党工委书记、管委会主任：彭兆耀 负责寿县蜀山现代产业园区工作。 县委办公室及其所属部门负责同志工作分工 李家明同志 负责办公室全面工作。 陈春华同志 负责县保密办（保密局）、目标办、效能办工作，分管办公室保密、督查等工作，联系协调发改、工业、商务、财税、金融、人社、卫生健康、医疗保障、自然资源和规划、审计、统计、科技、供电、通信、数据资源管理、公共资源交易监管等工作，分管目标考核科、督查室（效能办）。 潘 耐同志 协助做好办公室日常工作，负责档案局工作，分管办公室行政、机关党建、党风廉政建设、档案法规、招商引资等工作，联系协调农业农村、教育体育、招商引资、环境保护、城乡建设、城市管理、机关事务管理及寿西湖农场、正阳关农场等工作，分管行政科、档案法规科。 陈 晨同志 负责政研室、党建办、改革办、财经办工作，分管办公室宣传思想和意识形态、综合文字、调研、文秘等工作，联系协调人大办、政协办、纪检、组织、宣传、统战、群团等工作。分管综合科、调研科、秘书科。 赵 斌同志 负责县密码管理局工作，协助负责保密工作，分管办公室文明创建、信访稳定、老干部、工会等工作。 徐小虹同志 负责县纪委监委驻县委办纪检组工作。 王 磊同志 负责国安办工作，分管办公室信息、值班、结对共建等工作，联系协调政法、人武、民政、市场监管、交通运输、应急管理、园区发展、文化旅游、退役军人管理、房产、残联、砂石管理、八公山风景区管理等工作，分管信息综合室（国安协调管控科）、总值班室。 .init { background: url(); width: 297px; height: 297px; } var ll_6788768 = 4; 主办：安徽省寿县人民政府办公室 承办：安徽省寿县融媒体中心 版权所有:安徽省寿县融媒体中心 地址：安徽省淮南市寿县国投大厦 邮编：232200 E-mail：shouxian-wz@163.com 皖公网安备 34042202000005号 皖ICP备19025266号-1 网站标识码：3415210027 LA.init({id: "JhQ6zOJLPD1AyYn9",ck: "JhQ6zOJLPD1AyYn9"}) 本站已支持IPV6访问 互联网违法和不良信息举报电话及邮箱 电话：0554－4027701 传真：0554－4032565 E-mail：shouxian-wz@163.com 网上有害信息举报专区 var _hmt = _hmt || []; (function() { var hm = document.createElement("script"); hm.src = "https://hm.baidu.com/hm.js?ae2bc804114a80320eecc2cd63c97ec2"; var s = document.getElementsByTagName("script")[0]; s.parentNode.insertBefore(hm, s); })(); $(function(){ $('.yqlinks_top li').mouseover(function(){ var i=$(this).index(); $('.yqlinks_top li').removeClass('active').eq(
