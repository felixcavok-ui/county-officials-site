大会主席团常务主席、执行主席叶壮主持开幕大会
市长兰开驰代表市人民政府向大会作政府工作报告
2
月
25
日上午，在庄严的国歌声中，雅安市第三届人民代表大会第六次会议在市体育馆隆重开幕。
大会应到代表
285
人，实到
270
人，符合法定人数。
大会主席团常务主席、执行主席叶壮主持开幕大会。大会执行主席李伊林、张燕飞、青理东、刘锐、赖荣、宋开慧、李首成、朱玉贵、李荣、吴志君、李勇、罗强、衡彤、吴宏、赵昌林、高福强在主席台前排就座。
市政协主席杨承一在主席台就座。
上午
9
时许，叶壮宣布雅安市第三届人民代表大会第六次会议开幕。
市长兰开驰代表市人民政府向大会作政府工作报告。报告由三个部分组成：
2015
年和“十二五”工作回顾
;
“十三五”发展的基本思路
;2016
年工作安排。
兰开驰说，“十二五”时期，是雅安发展历史上极为特殊、极其艰难的五年。五年来，面对多种任务聚集、多重压力叠加、多条战线作战的复杂局面，我们坚持稳中求进总基调，积极有效应对各种困难挑战，统筹推进稳增长、促改革、调结构、惠民生、防风险各项工作，实现了在大灾后奋力崛起、在逆境中后发追赶，经济社会发展取得了令人鼓舞的巨大成就。这五年，我们战胜灾难、坚韧奋起，认真实施了重建新路的雅安实践
;
化危为机、主动作为，奋力开创了后发追赶的崭新局面
;
抢抓机遇、前瞻布局，着力奠定了长远发展的坚实基础
;
以人为本、发展为民，努力实现了民生福祉的持续改善。
兰开驰说，
2015
年是灾后恢复重建的攻坚之年，也是全面完成“十二五”规划的收官之年。在市委的坚强领导下，在市人大、市政协的监督支持下，市人民政府认真贯彻落实党中央、国务院，省委、省政府和市委的各项决策部署，决战重建脱贫“双攻坚”，大力实施后发追赶。这一年，我们凝心聚力实施重建攻坚，主动作为稳定经济增长，突出特色加快产业发展，抢抓机遇深化改革开放，建管并重提升城乡面貌，持续强化生态文明建设，尽心竭力改善人民生活，依法治理维护社会稳定，从严从实加强自身建设，全面完成了市三届人大五次会议确定的各项目标任务。纳入灾后恢复重建总体规划的
2160
个项目累计完工
1949
个、完工率
90.2%
，累计完成投资
646.3
亿元、投资完成率
90.6%
。实现地区生产总值
502.58

9%;
地方一般公共预算收入
30.31
亿元，增长
10.7%;
城镇居民人均可支配收入
25318

8.1%;
农村居民人均可支配收入
10195
元，增长
9.9%
。
兰开驰说，回顾五年来的工作，有七个方面的经验和体会特别值得总结，并在今后的工作中继续加以坚持：不断强化“不发展要落后、发展慢了也要落后”的忧患意识，是推进雅安后发追赶的强大内在动力
;
敢于担当、超常付出，是化危为机、崛起于危难的根本举措
;
坚持转化优势、特色发展，是适应经济发展新常态、顺应全国全省发展大势的科学抉择
;
坚持问题导向、目标引领、责任倒逼，是遵循发展规律、破解发展难题的有效做法
;
坚持发展为民、重建惠民、生态富民，是践行为民宗旨的具体体现
;
坚守工作底线、强化风险防控，是牢牢把握主动权、让发展经得起历史检验的重要基础
;
坚持依法行政、从严治政，在思想上、政治上、行动上与党中央、省委和市委保持高度一致，坚决贯彻落实市委决策部署，持之以恒地转作风、抓落实，是我们保持正确前进方向、加快各项事业发展的坚强保证。
报告对《雅安市国民经济和社会发展第十三个五年规划纲要
(
草案
)
》进行了说明。我市“十三五”期间的具体发展目标建议是：保持高于全国、全省的经济增长速度，质量和效益得到明显提升
;
人民生活水平和质量明显提高
;
公民素质和社会文明程度普遍提升
;
生态文明建设取得显著成效
;
重要领域和关键环节改革实现重大突破。按照规划，到“十三五”末，我市地区生产总值争取再上一个台阶，力争达到
1000
亿元
;
产业结构、动力结构实现优化升级，产业迈向中高端水平，经济迈入创新驱动、内生增长轨道
;
全面消除绝对贫困，贫困村全部摘帽，城乡居民收入保持较快增长，收入差距明显缩小，基本公共服务均等化水平稳步提高
;
市场在资源配置中的决定性作用充分发挥，开放型经济新机制基本形成，法治政府建设进一步加强，各项事业步入法治化轨道
;
“美丽雅安、生态强市”建设取得新成效，生态环境受到严格保护，生态优势得到有效转化，生态经济实现快速发展，生态红利持续富民强市，生态家园魅力充分彰显，生态文明能够全国示范，走出一条“让绿水青山变金山银山”的特色发展之路。
兰开驰表示，
2016
年是灾后重建“三年基本完成”的收官之年，也是“十三五”决胜全面小康的开局之年。今年政府工作的总体要求是：认真贯彻落实党中央、国务院，省委、省政府和市委的决策部署，牢固树立并贯彻“五大发展理念”，主动适应把握引领经济发展新常态，以建设“美丽雅安、生态强市”为总揽，决战重建脱贫“双攻坚”，大力实施“四大行动计划”，突出“四大工作抓手”，全面完成灾后恢复重建规划目标任务，努力保持经济平稳健康发展和社会大局和谐稳定，为“十三五”发展开好局、起好步。

对于
2016

;
决战脱贫攻坚，为同步实现全面小康打下坚实基础
;
强化项目投资拉动，着力保持经济稳定增长
;
大力实施工业强市行动计划，加快推进新型工业化进程
;
大力实施生态富民行动计划，切实转化生态资源优势
;
大力实施交通会战行动计划，加快推进重点基础设施建设
;
大力实施城乡提升行动计划，加快推进新型城镇化进程
;
坚持改革创新，着力培育经济发展新动能
;
坚持开放合作，努力提升开放型经济水平
;
坚持共建共享，努力增强人民群众的获得感。兰开驰说，今年我们将聚焦依法行政、转变职能、提高效能，进一步深化法治政府、服务政府和廉洁政府建设。

大会还表决通过了雅安市第三届人民代表大会第六次会议选举办法、财政经济委员会主任委员名单、关于专门委员会的设立和有关成员名单的表决办法，决定雅安市第三届人民代表大会设立内务司法委员会。
参加开幕式并在主席台就座的还有主席团成员、中共雅安市委、市人民政府、市政协的领导同志，市中级人民法院、市人民检察院、川藏兵站部、四川农业大学、雅安职业技术学院、市级各民主党派和工商联主要负责同志和市二届人大常委会的领导同志。
