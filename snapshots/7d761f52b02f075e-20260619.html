县委领导 县 委 书 记：牛方括 主持县委全面工作 县委副书记、县长：孙奇志 负责县政府全面工作 县委副书记：蒋青松 负责县经济开发区、招商引资工作，分管县委党校。 县委常委、宣传部长：李 琼 负责宣传思想文化、意识形态、城乡文明创建和文旅产业工作，分管县委教育工作领导小组秘书组、县委网信办、县委讲师组、县文明办、县文联、县融媒体中心。 县委常委、统战部长：王亚晖 负责统一战线、对台、民族宗教、民营经济工作，协助蒋青松同志抓好招商引资、新桥国际产业园工作，分管县工商联、县侨联、县台办。 县委常委、常务副县长：张 斌 负责县政府常务工作，负责县委军民融合办工作。 县委常委、政法委书记：牛 斌 负责政法、信访、维护稳定工作，负责县委依法治县办、县总工会工作，分管县委信访局，联系县法院、县检察院。 县委常委、组织部长：洪毅然 负责党的农村、组织、群团、目标考核工作，分管县直机关工委、县委编办、县委老干部局、团县委、县妇联、县科协、县委非公有制经济和社会组织工委、县档案馆，协助蒋青松同志分管县委党校，联系县人大、县政协。 县委常委、纪委书记、监委主任：袁 东 负责纪检监察和县委巡察工作。 县委常委、人武部政委： 胡玉强 负责人民武装、国防动员和民兵预备役工作。 县委常委、副县长： 李景练 负责县政府分工工作。 县委常委： 赵德兵 负责新桥国际产业园工作。 县委办公室及其所属部门负责同志工作分工 李家明同志 负责办公室全面工作。 陈春华同志 协助主任工作，负责目标办、效能办工作，分管督查、行政、工会等工作，联系协调群团、发改、工业、商务、财税、金融、人社、卫生健康、医疗保障、统计、科技、供电、通信、数据资源管理、公共资源交易监管等工作，分管目标考核科、督查室（效能办）、行政科。 潘 耐同志 协助主任工作，负责档案局工作，分管办公室机关党建、党风廉政建设、档案法规、招商引资等工作，联系协调纪委监委、组织、宣传、统战、农业农村、教育体育、招商引资、环境保护、应急管理、城乡建设、人大办、政协办及寿西湖农场、正阳关农场等工作，分管秘书科、档案法规科。 陶 杰同志 负责县保密办（保密局）工作，分管办公室值班、文明创建、计划生育、信访稳定、老干部等工作，联系协调房产、自然资源和规划、机关事务管理、残联、砂石管理、八公山风景区管理等工作，分管总值班室。 赵 斌同志 负责县委机要局（县密码管理局）工作, 协助负责保密工作。 庞惠利同志 负责县纪委监委驻县委办纪检监察组工作。 陈 晨同志 负责综合股、党建办、改革办、财经办工作，分管办公室综合文字、调研等工作，分管调研科。 王 磊同志 负责国安办工作，分管办公室信息、结对共建等工作，联系协调政法、人武、民政、市场监管、交通运输、园区发展、文化旅游、退役军人管理等工作，分管信息综合室（国安协调管控科）。 .init { background: url(); width: 297px; height: 297px; } 联系我们 | 网站地图 | RSS订阅 | 隐私保护 主办：安徽省寿县人民政府办公室 承办：安徽省寿县融媒体中心 版权所有 安徽省寿县融媒体中心 地址：安徽省淮南市寿县国投大厦 邮编：232200 网站标识码：3415210027 皖公网安备 34042202000005号 皖ICP备19025266号-1 document.write(unescape("%3Cspan id='cnzz_stat_icon_1280065775'%3E%3C/span%3E%3Cscript src='https://v1.cnzz.com/z_stat.php%3Fid%3D1280065775%26show%3Dpic1' type='text/javascript'%3E%3C/script%3E")); 本站已支持IPV6访问 互联网违法和不良信息举报电话及邮箱 电话：0554－4027701 传真：0554－4032565 E-mail： [email&#160;protected] /* */ 网上有害信息举报专区 智能问答 我要投稿 寿县发布 var ll_6787345 = 1; 政务微信 var ll_6787346 = 1; 分享 $(".slidebox .icon li").hover( function () { $(this).children('.web_area').fadeIn(); $(this).children('.web_link').addClass("active"); }, function () { $(this).children('.web_area').hide(); $(this).children('.web_link').removeClass(
