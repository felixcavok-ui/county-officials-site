钦州市六届人大一次会议举行第三次全体会议　王雄昌当选市人民政府市长　覃天卫当选市人大常委会主任
来源：钦州日报　　记者：潘定盼　　发布时间：2021-10-18 09:09
 
分享到：
 
10月16日下午，钦州市六届人大一次会议举行第三次全体会议，选举钦州市六届人大常委会主任、副主任、秘书长、委员，钦州市人民政府市长、副市长，钦州市监察委员会主任，钦州市中级人民法院院长，钦州市人民检察院检察长。王雄昌当选钦州市人民政府市长，覃天卫当选钦州市人大常委会主任。
大会主席团常务主席、执行主席许永锞、王雄昌、覃天卫、莫锦荣、沙君俊、黄剑峰、陆明、李磊岩、吴志新、陈仅、沈小军、黄光发在主席台执行主席席就座。
吕洪安、杨斌、龙卷、林海波、郑娟、李开创、古保华、姚永福等在主席台就座。
大会主席团常务主席、执行主席莫锦荣主持会议。
市六届人大一次会议应出席代表369人，出席本次会议的代表361人，符合法定人数。
根据大会选举办法，大会首先表决通过了总监票人、监票人名单，然后投票选举。
经大会无记名投票选举，覃天卫当选为钦州市六届人大常委会主任，陆明、李磊岩、吴志新、陈仅、沈小军、黄光发当选为钦州市六届人大常委会副主任，覃重当选为钦州市六届人大常委会秘书长；王雄昌当选为钦州市人民政府市长，林海波、李开创、张红丹、谢立品、莫一格、徐科峰、曾智当选为钦州市人民政府副市长；沙君俊当选为钦州市监察委员会主任；唐军成当选为钦州市中级人民法院院长；廖庆峰当选为钦州市人民检察院检察长；新当选的钦州市人民检察院检察长，依法须报经自治区人民检察院检察长提请自治区人大常委会批准；丁起文等32人当选为钦州市六届人大常委会委员；大会还表决通过了钦州市六届人大各专门委员会组成人员名单。
大会举行了宪法宣誓仪式。新当选的市六届人大常委会主任、副主任、秘书长，市人民政府市长、副市长进行宪法宣誓，覃天卫、王雄昌分别领誓。新当选的市监察委员会主任，市中级人民法院院长，市六届人大常委会委员、人大各专门委员会组成人员进行宪法宣誓。
出席市六届人大一次会议第三次全体会议的代表见证了宪法宣誓。
在主席台就座的还有：谢立品、莫一格、徐科峰、曾智、唐军成、廖庆峰、方建安、覃重、裴明。

function isuser(Str){
if(Str=="") return false;

}
function ispwd(str){
if(str=="") return false;
var re=/(?!^\d+$)(?!^[A-Za-z]+$)(?!^[^A-Za-z0-9]+$)(?!^.*[\u4E00-\u9FA5].*$)^\S{6,20}$/;
return re.test(str);
}

return true;

return false;
}
}
