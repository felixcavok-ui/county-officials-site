通化市第八届人民代表大会第四次会议在全体代表的共同努力下，圆满完成各项议程，2019年4月2日下午，在通化宾馆会议中心胜利闭幕。 下午2点，通化市第八届人民代表大会第四次会议举行第二次全体会，大会实有代表292人，出席代表243人，符合法律规定。 会议由大会执行主席赵忠国主持。 会议表决通过了总监票人、副总监票人、监票人名单。 根据《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》以及本次会议选举办法的规定，对通化市市长候选人进行了投票选举。根据计票结果：李平当选为通化市市长。 会议举行了宪法宣誓仪式，李平宣誓。 李平在发言中说：各位代表、同志们：刚才，大会选举我为通化市市长。代表们的每一张选票承载的都是信任、都是重托，每一份沉甸甸的信任和重托，都将成为我，为通化发展和人民幸福不懈奋斗的不竭动力！在市委带领下，全市上下勠力同心，砥砺奋进，开创了通化良好的发展局面。着力营造了良好的营商环境，推进“放管服”“只跑一次”改革，践行“政府围着企业转，企业有事马上办”，全力打造“吉林的台州”；着力实施“五转”，推动民营经济实现高质量发展；着力推进“一港两区”建设，不断提升开放水平；着力增强金融助力实体经济能力，破解企业发展难题；着力抓项目抓招商引人才，积蓄发展后劲；着力构建风清气正的政治生态、充满活力的经济生态、山清水秀的自然生态，所有这些都给这座城市注入了希望与未来。能与通化广大干部群众一起奋斗，感到无比荣幸。 谈到今后工作，李平表示，要做到始终保持政治坚定。政治坚定离不开理论坚定。始终把学懂弄通做实习近平新时代中国特色社会主义思想，特别是习近平总书记视察东北座谈会上的重要讲话和视察吉林时的重要指示精神，用理论武装头脑、指导实践、推动工作，树牢“四个意识”，坚定“四个自信”，践行“两个维护”，始终在思想上政治上行动上同以习近平同志为核心的党中央保持高度一致。自觉在市委的领导下，贯彻落实中央、省、市重大决策部署，不折不扣落到实处。 要全力推进振兴发展。市委七届六次全会摩画了通化未来的发展蓝图，八届三次人代会，“1 2 8”明确了今年的重点工作任务。作为市长，将带领市政府一班人，保持定力、锲而不舍，一张蓝图绘到底，一以贯之抓落实，坚持问题导向、责任导向、目标导向、效果导向，持续推动政府工作提效率、重落实、解难题、见成效，奋力推进通化高质量发展。 要做到时刻牢记改善民生。一枝一叶总关情，民之所望，政之所向。将全面践行以人民为中心的发展思想，沉下心来，扑下身子，多做群众最急最盼之事，多做利民惠民之事，坚持干则干成、干就干好，努力让通化人民群众的生活越过越好。 要努力维护精诚团结。通化的发展，离不开市委的坚强领导，离不开人大政协的监督支持，离不开全市上下的共同努力。将自觉在市委的坚强领导下，坚决落实市委的各项决策部署。我将加强政府班子建设，提振好精神、锤炼好作风。将主动接受人大、政协的监督，广泛听取各方面意见建议，切实汇聚起推动通化振兴发展的强大力量。 要做到固本培源清正廉洁。切实做到自身净、自身正、自身硬；切实将党风廉政建设责任扛在肩上、抓在手上、落实到行动上；坚守共产党人的初心使命，始终保持清正廉洁的政治本色。 李平最后说：各位代表，同志们！今天，我接过了市长的考卷，我一定尽心竭力作答；今天，我接过了人民的考卷，我一定夙兴夜寐作答。我坚信，有市委的坚强领导，有人大、政协的鼎力支持，有全市人民的共同努力，我们一定能够创造更多无愧于时代、无愧于人民的新业绩；我们一定能够续写好新时代通化绿色转型、全面振兴的新篇章。谢谢大家。 赵忠国在讲话中表示，2019年工作已全面展开，各项工作扎实，一季度实现了良好开局，让我们高举习近平新时代中国特色社会主义思想伟大旗帜，带着庄严的承诺，以砥砺奋进的豪迈姿态，在中共通化市位的坚强领导下，以更加昂扬拼搏的精神面貌，更加坚韧不拔的意志品质，更加奋发有为的工作状态，为决胜全面建成小康社会，奋力开创新时代通化绿色转型、全面振兴新局面而努力奋斗，以更加优异的工作成果，庆祝中华人民共和国成立七十周年！ 中国吉林网 吉刻APP记者 刘振国 .smy_topage { margin-top:15px; display:inline-block;} .smy_topage a { background: #fff; border: 1px solid #ccc; height: 30px; display: inline-block; color: #666666; padding: 0 10px; float: left; text-align: center; line-height: 32px; margin: 0 6px;} .smy_topage a:hover {background:#034da2; b
