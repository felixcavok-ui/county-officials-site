中央人事任免
中央任命3名西藏自治区常务副主席 >>
中共中央日前决定郝鹏任西藏自治区人民政府常务副主席吴英杰任西藏自治区人民政府常务副主席白玛赤林任西藏自治区人民政府常务副主席。
张杰出任上海交通大学校长 >>
上海交通大学27日召开全校教师干部大会宣布中共中央、国务院关于上海交通大学校长的任免决定由张杰任上海交通大学校长谢绳武因过任职年龄界限不再担任上海交通大学校长职务。
中央任命刘伟平为甘肃省委副书记 >>
中央决定刘伟平同志任中共甘肃省委委员、常委、副书记。
原青海西宁市委书记张裔炯出任西藏区委副书记 >>
近日中央决定张裔炯同志任西藏自治区党委委员、常委、副书记免去其青海省委常委、委员职务。
★地方人事任免
姜斯宪任海南副省长 曾任上海市委组织部长 >>
海南省第三届人民代表大会常务委员会第二十六次会议任命姜斯宪为海南省人民政府副省长。
北京市人民代表大会常务委员会任免名单 >>
任命吴在存为北京市第一中级人民法院副院长。免去马子荣的北京市第一中级人民法院副院长、审判委员会委员、审判员职务。
北京市人民检察院副检察长雍战胜因严重违纪被免职 >>
在3日召开的北京市第十二届人大常委会第32次会议上雍战胜因严重违纪被免去北京市人民检察院副检察长、检察委员会委员、检察员职务。
李汝求任广东惠州市代市长 >>
11月3日上午经广东惠州市九届人大常委会第29次会议审议表决决定接受黄业斌辞去惠州市市长职务?已任惠州市委书记?任命李汝求为惠州市副市长、代市长。此前李汝求任中共惠州市委副书记、纪委书记。
云南省人大常委会决定秦光荣任云南省代省长 >>
11月6日召开的云南省第十届人民代表大会常务委员会第二十五次会议决定秦光荣为云南省代理省长罗正富为云南省副省长。
张裔炯当选新一届中共青海省西宁市委书记 >>
中共青海省委常委张裔炯在中共西宁市第十二届一次会议上当选为新一届西宁市委书记骆玉林、张文林当选为市委副书记。会议审议通过了市纪委常委、书记、副书记选举结果的报告邹建胜当选为市纪委书记。
胡宪任南昌市代市长 李豆罗辞去南昌市长职务 >>
昨天8日下午南昌市十二届人大常委会第四十七次会议在市人大常委会常委会议室举行。会议决定胡宪为南昌市人民政府代市长同时通过了关于接受李豆罗辞去市长职务请求的决定。
厦门市市长张昌平被任命为福建省人民政府副省长 >>
厦门市市长张昌平九日被任命为福建省人民政府副省长。根据福建省省长黄小晶的提请福建省十届人大常委会第二十六次会议经审议下午高票通过了此项任命。
李鹏新当选为中共青海省海西州委书记 >>
在11月9日召开的中共青海省海西蒙古族藏族自治州委十届一次全体会议上李鹏新当选为中共海西州委书记诺卫星、高华、杜捷当选为副书记。
李源潮再次当选为中共江苏省委书记 >>
中共江苏省第十一届委员会第一次全体会议今天下午选举李源潮为省委书记梁保华、张连珍为省委副书记。
张春贤当选中共湖南省委书记 >>
中共湖南省第九届委员会第一次全体会议11月13日选举张春贤为省委书记周强、梅克保为省委副书记当选为省委常委的还有黄建国、肖捷、许云昭、李江、于来山、蒋建国、徐宪平、杨忠民、陈润儿、李微微。
栗智出任乌昌党委书记、乌鲁木齐市委书记 >>
11月12日18时乌鲁木齐市召开县级干部大会大会由自治区党委组织部宣读了自治区党委关于乌鲁木齐市委主要领导任免决定栗智担任乌昌党委书记、乌鲁木齐市委书记。

白恩培任云南省委书记 秦光荣李纪恒任省委副书记 >>
中共云南省第八届委员会第一次全体会议11月16日选举白恩培为省委书记秦光荣、李纪恒为省委副书记当选为省委常委的还有李汉柏白族、杨崇勇满族、罗正富彝族、李江女、杨应楠、王增钵、张田欣、黄毅景颇族、孟苏铁、曹建方。
刘奇葆当选广西区委书记 陆兵、郭声琨任副书记 >>
11月19日下午中国共产党广西壮族自治区第九届委员会在南宁举行第一次全体会议选举刘奇葆为中共广西壮族自治区委员会书记选举陆兵壮族、郭声琨为中共广西壮族自治区委员会副书记。
