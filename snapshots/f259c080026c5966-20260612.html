 协同创新 支持发展 | 南京市建邺区委书记李晖一行莅临集团调研指导 

 2022-09-28 

 

 

 

 

 

 

 

 &nbsp; 

 

 

 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;9月27日，建邺区委书记、河西新城区开发建设管委会主任、党组书记李晖一行莅临苏交科集团调研指导。建邺区委常委、区政府党组成员、建邺高新区党工委书记杨波，生态科技岛经开区管委会主任姚胜强及区委办、发改委、科技局、财政局、统计局、高新区、江东商贸区等相关领导陪同调研。苏交科集团董事长李大鹏，总裁朱晓宁，党委书记、副总裁何淼，副总裁(人力资源) 王欣等参与座谈交流。 

 

 

 

 

 

 

 

 

 

 

 

 ○&nbsp;苏交科集团总裁朱晓宁 

 

 

 

 &nbsp; 

 

 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 朱晓宁总裁对数字化改革、智库平台打造、2个国家级科研平台工作情况等苏交科亮点工作进行汇报。他表示，苏交科持续投入，打造以数字化、信息化为主的质量管理与协同作业的运营与赋能平台，形成了具有苏交科特色的质量管理体系，本年度获得&ldquo;江苏省省长质量奖&rdquo;，是全省交通领域第一家获得该荣誉的企业。同时，苏交科致力于提供智力服务，是交通部&ldquo;老交通智库&rdquo;的重要支撑单位，今年7月份，与江苏省民盟共建了民盟 &ldquo;交通运输现代化研究中心&rdquo;， 通过参与智库相关研究工作，围绕国家和交通运输行业热点议题献计献策。非常感谢建邺区领导对苏交科一直以来的关心与帮助，苏交科也将以国家重点实验室为基础，产学研联动，与建邺产业资本深度合作，助力建邺产业经济高质量发展。未来，苏交科将进一步加强与建邺区政府的沟通，为建邺区建设提供支撑服务。 

 

 

 

 

 

 

 

 

 ○&nbsp;苏交科集团董事长李大鹏 

 

 

 

 &nbsp; 

 

 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 李大鹏董事长对李晖书记一行来访表示热烈欢迎，并详细介绍了苏交科业务领域、未来发展规划以及苏交科在智慧城市和检测领域的业务成果与应用场景。他强调，苏交科在扎实发展传统咨询业务的基础上，大力推动苏交科特色数字化基础设施业务发展。未来，苏交科将积极对接建邺区政府，以数字化、信息化建设为契机，持续为建邺区高质量发展贡献力量。 

 

 &nbsp; 

 

 

 

 

 

 

 

 ○&nbsp;建邺区委书记 

 河西新城区开发建设管委会主任、党组书记李晖 

 

 

 

 &nbsp; 

 

 &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 李晖书记表示，通过本次调研工作，对苏交科有了更加全面深刻的了解。建邺区与苏交科渊源深厚，将在重大科技创新、产品升级、平台建设等方面给予苏交科重点支持。希望苏交科深化协同联动创新，推动数字创新链与产业链深度融合，助力提升建邺区基础设施建设水平；加快推动合作伙伴计划，形成信息直通机制，加强建邺区与苏交科的沟通，实现信息对称、资源共享；促进高新区企业间的交流，实现抱团融合、共同发展。
