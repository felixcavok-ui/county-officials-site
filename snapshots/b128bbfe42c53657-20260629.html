'''{{zy|蒿|hāo|}}慧杰'''（{{bd|1968年|10月||catIdx=Hao蒿}}），男，汉族，[[河南]][[中牟]]人，[[中国共产党]]、中华人民共和国政治人物，[[武汉大学]][[法学]]学士，[[郑州大学]]在职公共管理硕士。曾任中共河南省[[漯河]]、[[驻马店]]市委书记，[[陕西省人民政府]]副省长，[[中共陕西省委]]常委、宣传部部长、[[中共延安市委]]书记等职务。现任[[中共陕西省委]]常委、[[西安市委]]书记。

== 简历 ==
=== 早年及河南省 ===
曾任河南省财政厅副厅长、党组成员，省政府副秘书长、办公厅党组成员，省政府研究室主任、党组书记，中共漯河市委副书记（正市厅级）等职。

2016年9月，任漯河市人民政府代市长<ref>{{Cite web |title=蒿慧杰任漯河市代市长 曹存正辞去市长职务|url=http://district.ce.cn/newarea/sddy/201609/20/t20160920_16064780_1.shtml |website=中国经济网 |date=2016-09-20 |language=zh-cn |access-date=2026-01-16}}</ref>，翌年6月去代转正。在此期间，因被抽调至中央第二巡视组任副组长，曾连续70余天未在当地官媒露面，一度引发外界关注<ref>{{Cite web |title=河南这位代市长“消失”72天 去哪儿了？|url=https://www.rmzxw.com.cn/c/2017-06-15/1593823.shtml?n2m=1 |website=人民政协网 |access-date=2026-01-16 |date=2017-06-15}}</ref>。

2017年12月，升任中共漯河市委书记<ref>{{Cite web |title=蒿慧杰任中共漯河市委书记 |url=https://renshi.people.com.cn/n1/2017/1204/c139617-29683791.html |website=-人民网 |archive-url=https://web.archive.org/web/20210728235315/https://renshi.people.com.cn/n1/2017/1204/c139617-29683791.html |archive-date=2021-07-28 |access-date=2026-01-16 |dead-url=no }}</ref>。

2021年7月，转任中共驻马店市委书记<ref>{{Cite web |title=蒿慧杰任驻马店市委书记 |url=http://renshi.people.com.cn/n1/2021/0717/c139617-32160807.html |website=中国共产党新闻网 |archive-url=https://web.archive.org/web/20210812171127/http://renshi.people.com.cn/n1/2021/0717/c139617-32160807.html |archive-date=2021-08-12 |access-date=2026-01-16 |dead-url=no }}</ref>。

=== 陕西省 ===
2021年9月，跨省出任[[陕西省人民政府]]副省长<ref>{{Cite web|title=河南驻马店市委书记蒿慧杰已赴陕西任职|url=https://m.thepaper.cn/newsDetail_forward_14344986|access-date=2021-09-05|work=澎湃新闻|archive-date=2021-09-05|archive-url=https://web.archive.org/web/20210905132050/https://m.thepaper.cn/newsDetail_forward_14344986|dead-url=no}}</ref><ref>{{Cite web|title=蒿慧杰任陕西省人民政府副省长|url=https://china.huanqiu.com/article/44y2SNCs2vO|access-date=2021-09-29|work=china.huanqiu.com|archive-date=2022-03-06|archive-url=https://web.archive.org/web/20220306024526/https://china.huanqiu.com/article/44y2SNCs2vO|dead-url=no}}</ref>。

2022年5月，当选为[[中共陕西省委]]常委<ref>{{Cite web|title=刘国中当选陕西省委书记 蒿慧杰、李春临、王琳新任省委常委|url=http://district.ce.cn/newarea/sddy/202205/31/t20220531_37694173.shtml|access-date=2022-06-14|work=district.ce.cn|archive-date=2022-06-16|archive-url=https://web.archive.org/web/20220616143428/http://district.ce.cn/newarea/sddy/202205/31/t20220531_37694173.shtml}}</ref>，次月兼任省委宣传部部长<ref>{{Cite web|title=蒿慧杰已任陕西省委宣传部部长|url=http://district.ce.cn/newarea/sddy/202206/25/t20220625_37794526.shtml|access-date=2022-07-02|work=中国经济网|archive-date=2022-06-27|archive-url=https://web.archive.org/web/20220627061710/http://district.ce.cn/newarea/sddy/202206/25/t20220625_37794526.shtml}}</ref>；同年7月辞去陕西省人民政府副省长职务<ref>{{Cite web |title=蒿慧杰辞去陕西省副省长职务 已任省委常委、宣传部部长|url=https://district.ce.cn/newarea/sddy/202207/28/t20220728_37913975.shtml |website=中国经济网 |access-date=2026-01-16}}</ref>。

2023年1月，转任[[中共延安市委]]书记<ref>{{Cite web|title=蒿慧杰任延安市委书记 赵刚不再兼任|url=http://district.ce.cn/newarea/sddy/202301/20/t20230120_38358213.shtml|access-date=2023-01-20|website=district.ce.cn|archive-date=2023-03-26|archive-url=https://web.archive.org/web/20230326071748/http://district.ce.cn/newarea/sddy/202301/20/t20230120_38358213.shtml|dead-url=no}}</ref>。

2026年1月，调任[[中共西安市委]]书记<ref>{{Cite news |title=蒿慧杰任西安市委书记 |url=https://www.news.cn/politics/20260116/144d99dcf7be489494a9c10d18ad58b7/c.html |author=西部网 |work=新华网 |date=2026-01-16 |language=zh-cn |access-date=2026-01-17 |url-status=live}}</ref>。
