'''陈瑞峰'''（{{bd|1966年|5月|||catIdx=C陈}}），[[山东省|山东]][[胶南市|胶南]]人，[[中国共产党]]党员，[[中华人民共和国]]政治人物。现任[[中共中央统一战线工作部|中共中央统战部]]副部长、[[中华人民共和国国家民族事务委员会|国家民族事务委员会]]主任。曾任[[中国共产党青海省委员会|中共青海省委]]常委、[[西宁市]]委书记。[[中国共产党第二十届中央委员会候补委员列表|中共第二十届中央候补委员]]。

== 生平 ==
1983年9月，陈瑞峰考入[[青岛师范专科学校]]政治系政史专业学习。1985年9月，转入[[曲阜师范大学]]政治系政治专业学习。1987年9月，他考入[[北京大学]]政治学与行政管理系中共党史专业攻读硕士研究生。1989年4月加入[[中国共产党]]。1990年1月，毕业后分配到[[北京计算机二厂]]党委宣传部。

=== 中央宣传部 ===
1990年11月，调入[[中国共产党中央委员会宣传部|中共中央宣传部]]宣传局党员教育处。1992年3月，任宣传局党员教育处副主任科员。1994年6月，任[[中共中央宣传部宣传教育局|宣教局]]党员教育处主任科员，1996年8月任副处长，2000年8月任处长。2004年7月，调任[[中央文明办]]调研组副组长。2009年10月，升任[[中国志愿服务基金会]]秘书处秘书长，明确为正局长级。2014年7月，任中共中央宣传部宣教局局长<ref>{{cite web |title=湖北随州市委书记陈瑞峰转任青海省委常委、宣传部长 |url=http://www.xinhuanet.com/renshi/2020-07/19/c_1126257184.htm |website=新华网 |accessdate=2020-07-19 |date=2020-07-19 |archive-date=2020-07-19 |archive-url=https://web.archive.org/web/20200719032723/http://www.xinhuanet.com/renshi/2020-07/19/c_1126257184.htm |dead-url=no }}</ref>。

=== 湖北省 ===
2016年8月，陈瑞峰外放[[湖北]]，任[[中国共产党武汉市委员会|中共武汉市委]]副书记<ref>{{cite web |title=陈瑞峰任武汉市委副书记 |url=http://news.sina.com.cn/c/2016-09-13/doc-ifxvukuq4328127.shtml |website=新浪 |accessdate=2020-07-19 |date=2016-09-13 |archive-date=2020-07-19 |archive-url=https://web.archive.org/web/20200719031316/http://news.sina.com.cn/c/2016-09-13/doc-ifxvukuq4328127.shtml |dead-url=no }}</ref>。2017年1月，兼任市委政法委书记，同年5月改兼任[[武汉市人民政府]]常务副市长，同年7月当选为[[中国共产党湖北省委员会|中共湖北省委]]委员<ref>{{cite web |title=中国共产党湖北省第十一届委员会委员、候补委员名单 |url=http://www.hubei.gov.cn/zwgk/hbyw/hbywqb/201706/t20170630_1012260.shtml |website=湖北省人民政府 |accessdate=2020-07-19 |date=2017-06-30 |archive-date=2020-07-19 |archive-url=https://web.archive.org/web/20200719084408/http://www.hubei.gov.cn/zwgk/hbyw/hbywqb/201706/t20170630_1012260.shtml |dead-url=no }}</ref>。期间，还兼任[[第七届世界军人运动会]]执行委员会副主任、秘书长。2018年11月，出任中共[[随州市]]委书记。2019年1月至12月，兼任随州市人大常委会主任<ref>{{cite web |title=陈瑞峰任随州市委书记 |url=http://district.ce.cn/newarea/sddy/201811/16/t20181116_30798376.shtml |website=中国经济网 |accessdate=2020-07-19 |date=2018-11-16 |archive-date=2020-07-19 |archive-url=https://web.archive.org/web/20200719031316/http://district.ce.cn/newarea/sddy/201811/16/t20181116_30798376.shtml |dead-url=no }}</ref>。

=== 青海省 ===
2020年7月，任[[中国共产党青海省委员会|中共青海省委]]常委、宣传部部长<ref>{{cite web |title=陈瑞峰在调研西宁市城中区新时代文明实践中心时强调 推进新时代文明实践中心建设  接地气有活力可持续 |url=http://www.qhnews.com/newscenter/system/2020/07/19/013208188.shtml |website=青海新闻网 |accessdate=2020-07-19 |date=2020-07-19 |archive-date=2020-07-19 |archive-url=https://web.archive.org/web/20200719060243/http://www.qhnews.com/newscenter/system/2020/07/19/013208188.shtml |dead-url=no }}</ref>。2021年1月，转兼任中共[[西宁市]]委书记<ref>{{cite web |title=青海省委常委、宣传部长陈瑞峰任西宁市委书记 |url=https://new.qq.com/omn/20210109/20210109A0AOMY00.html |website=腾讯 |accessdate=2021-01-09 |date=2021-01-09 |archive-date=2022-12-05 |archive-url=https://web.archive.org/web/20221205202751/https://new.qq.com/rain/a/20210109A0AOMY00 |dead-url=yes }}</ref>。2022年10月，当选为[[中国共产党第二十届中央委员会候补委员列表|中共二十届中央候补委员]]。
