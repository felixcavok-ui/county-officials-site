'''胡衡华'''（{{bd|1963年|6月|catIdx=H胡}}），[[中华人民共和国]]政治人物，生于[[湖南省]][[衡南县]]。[[西安冶金建筑学院]]（现[[西安建筑科技大学]]）自动化专业毕业，[[湖南大学]]工商管理学院[[工商管理]]专业工商管理硕士。曾任[[中共湖南省委]]常委、[[长沙市委]]书记，[[中共陕西省委]]副书记，[[中共重庆市委]]副書記、[[重庆市人民政府]]市长等职务。2026年3月，因涉嫌严重违纪违法接受中央纪委国家监委纪律审查和监察调查。

== 生平 ==
=== 早年及湖南省 ===
1983年7月，毕业于[[西安冶金建筑学院]]工业自动化专业，获工学学士学位。毕业后任衡阳钢管厂100车间技术员、副工段长、工段长。

1985年6月加入[[中国共产党]]。

1990年12月，任衡阳钢管厂100车间副主任、76车间副主任。

1996年6月，任衡阳钢管厂108车间主任。

1996年12月，任衡阳钢管厂厂长助理、连轧车间主任。

1997年11月，任衡阳钢管厂副厂长。

1998年10月，任衡阳钢管（集团）有限公司副总经理。

1999年8月，任衡阳钢管（集团）有限公司执行董事（法人代表）、总经理（1998年7月至2001年12月在湖南大学工商管理学院工商管理专业同等学力学习，获工商管理硕士学位）。

2005年7月，任[[湖南省经济委员会]]主任、党组书记。

2008年3月，任中共[[益阳]]市委副书记、市人民政府代市长。

2009年1月，正式当选为益阳市人民政府市长。

2011年1月，任[[湖南省发展和改革委员会]]主任、党组书记。

2013年12月，任[[中共长沙市委]]副书记，[[长沙市人民政府]]副市长、代理市长。

2014年1月，正式当选为长沙市人民政府市长<ref>{{cite news|title=胡衡华当选长沙市人民政府市长|url=http://renshi.people.com.cn/n/2014/0111/c139617-24089970.html|accessdate=2014-01-12|newspaper=人民网|archive-date=2020-04-04|archive-url=https://web.archive.org/web/20200404032258/http://renshi.people.com.cn/n/2014/0111/c139617-24089970.html|dead-url=no}}</ref>。

2015年11月，兼任湖南[[湘江新区]]党工委书记<ref>{{cite news|title=虢正贵任湖南长沙市委副书记，提名湘江新区管委会主任|url=http://www.thepaper.cn/newsDetail_forward_1403582|accessdate=2016-05-27|newspaper=澎湃新闻|archive-date=2020-04-04|archive-url=https://web.archive.org/web/20200404032306/http://www.thepaper.cn/newsDetail_forward_1403582|dead-url=no}}</ref>。

2016年11月，任[[中国共产党湖南省委员会|中共湖南省委]]常委<ref>{{cite news|title = 第十一届湖南省委领导班子亮相，杜家毫当选省委书记|url = http://www.thepaper.cn/newsDetail_forward_1564377|accessdate = 2016-11-19|publisher = 澎湃新闻|archive-date = 2016-11-20|archive-url = https://web.archive.org/web/20161120005211/http://www.thepaper.cn/newsDetail_forward_1564377|dead-url = no}}</ref>、[[湖南省人民政府国有资产监督管理委员会]]党委书记<ref>{{cite web|accessdate=2016-11-23|url=http://www.thepaper.cn/newsDetail_forward_1566859|title=蔡振红兼任湖南省委宣传部部长，胡衡华兼任省国资委党委书记|publisher=澎湃新闻|archive-date=2016-11-23|archive-url=https://web.archive.org/web/20161123202918/http://www.thepaper.cn/newsDetail_forward_1566859|dead-url=no}}</ref>。

2017年7月，任[[中国共产党长沙市委员会|中共长沙市委]]书记。

===陕西省===
2020年10月，胡衡华跨省履新，任[[中国共产党陕西省委员会|中共陕西省委]]副书记<ref>{{Cite web|title=湖南省委常委、长沙市委书记胡衡华调任陕西省委副书记(简历)_中国经济网——国家经济门户|url=http://district.ce.cn/newarea/sddy/202010/17/t20201017_35900716.shtml|access-date=2021-05-26|work=district.ce.cn|archive-date=2020-10-21|archive-url=https://web.archive.org/web/20201021072436/http://district.ce.cn/newarea/sddy/202010/17/t20201017_35900716.shtml|dead-url=no}}</ref>。

===重庆市===
2021年12月，调任[[中共重庆市委]]副书记。同月任[[重庆市人民政府]]副市长、代理市长<ref>{{cite news |author1=祝加贝 |title=胡衡华任重庆市代市长 |url=https://news.sina.com.cn/c/2021-12-30/doc-ikyamrmz2159918.shtml |accessdate=2021-12-30 |work=新浪 |date=2021-12-30 |archive-date=2021-12-30 |archive-url=https://web.archive.org/web/20211230085121/https://news.sina.com.cn/c/2021-12-30/doc-ikyamrmz2159918.shtml |dead-url=no }}</ref>。

2022年1月，正式当选为重庆市人民政府市长<ref>{{cite web |title=胡衡华当选重庆市市长 |url=http://www.news.cn/politics/2022-01/21/c_1128286498.htm |website=新华网 |accessdate=2022-01-21 |archive-date=2022-01-21 |archive-url=https://web.archive.org/web/20220121075516/http://www.news.cn/politics/2022-01/21/c_1128286498.htm |dead-url=no }}</ref>。

== 政务处分及落马 ==
2014年11月，[[国家安监总局]]通报，在造成54人死亡、6人受伤（其中4人因伤势过重医治无效死亡）的7·19沪昆高速客货车相撞事故中，长沙市市长胡衡华负有重要领导责任，被建议给予行政记过处分<ref>{{cite web|title=国务院事故调查组公布“7·19”、“8·9”事故调查报告|url=https://www.mem.gov.cn/gk/sgcc/tbzdsgdcbg/2014/201411/t20141130_245222.shtml|website=应急管理部|accessdate=2026-03-20}}</ref>。

2023年5月，就[[2022年长沙自建房倒塌事故|湖南长沙“4·29”特别重大居民自建房倒塌事故]]，中央纪委以胡衡华在担任长沙市委副书记、代市长、市长和市委书记期间，对中央部署的违法建筑整治、房屋安全和风险隐患排查治理等工作组织领导不力，对事故发生负有领导责任，决定给予其党内警告处分<ref name="新华网_让新闻离你更近 2023">{{cite web|date=2023-05-21|title=4名中管干部因湖南长沙“4·29”特别重大居民自建房倒塌事故被问责-新华网|url=http://www.news.cn/2023-05/21/c_1129634189.htm|access-date=2023-05-21|website=新华网_让新闻离你更近|language=zh|archive-date=2023-05-22|archive-url=https://web.archive.org/web/20230522041215/http://www.news.cn/2023-05/21/c_1129634189.htm|dead-url=no}}</ref>。

2026年3月20日，中央纪委国家监委网站发布消息：胡衡华因涉嫌严重违纪违法，接受中央纪委国家监委纪律审查和监察调查<ref>{{Cite web |title=重庆市委副书记、市长胡衡华接受中央纪委国家监委纪律审查和监察调查 |url=https://www.ccdi.gov.cn/toutiaon/202603/t20260320_480512.html|date=2026-03-20|access-date=2026-03-21|website=中央纪委国家监委网站}}</ref>。此前胡衡华缺席多场公开活动，引发猜测。<ref>{{Cite news |title=胡衡华未现身重庆领导班子植树活动 |url=https://www.zaobao.com/news/china/story20260319-8760066 |work=联合早报 |date=2026-03-21 |access-date=2026-03-19}}</ref>

2026年5月27日，辞去重庆市人民政府市长职务<ref>{{Cite web |title=胡衡华辞去重庆市市长职务_中国经济网——国家经济门户 |url=http://district.ce.cn/newarea/sddy/202605/t20260528_2995405.shtml |website=district.ce.cn |access-date=2026-05-28}}</ref>。
