 区长节前带队走访重点企业

 来源:区委报道组

 时间：2026-02-18 15:49

 | 
 
 |

 | 
 
 |

  

 走访慰问送温暖，殷殷关怀显真情。在春节来临之际，2月16日，区委副书记、区长朱建阳带队深入辖区重点企业华峰华锦有限公司走访调研，看望慰问坚守岗位的一线职工，向他们致以诚挚问候和新春祝福。区领导吴兰梅、郑燕平参加调研。 
 朱建阳一行详细了解企业当前的生产经营状况、节日期间用工安排以及安全生产措施落实情况，关切询问发展过程中遇到的难点与诉求。朱建阳代表区委、区政府，对华峰华锦有限公司过去一年为秀屿经济发展作出的突出贡献表示感谢，并鼓励企业在新的一年里开足马力扩大生产、释放产能，奋力实现“开门红”。 
 期间，朱建阳一行特意来到企业职工中间，参加企业的年夜饭活动。他与留岗职工们围坐在一起，共迎新春佳节，感谢大家节日期间的辛勤付出与默默坚守。他希望大家以秀为家，把这里当作第二故乡，在忙碌之余也能感受到家的温暖和年的味道。
