　　省委组织部副部长胡文容宣读省委决定。


                


              


                


                  


					　　本报枣庄12月15日讯(记者　白雪岩)　15日上午,全市领导干部会议在市政大厦召开。省委组织部副部长胡文容在会上宣布了省委关于枣庄市委、市政府主要负责同志职务调整的决定。省委决定:刘玉祥不再担任枣庄市委书记、常委、委员、市委党校校长职务；陈伟任枣庄市委书记、市委党校校长职务,不再担任市长职务；张术平任枣庄市委委员、常委、副书记,提名为市长候选人。
　　胡文容在讲话中说,近年来,枣庄市委、市政府坚持以党的十七大和十七届全会精神为指导,深入贯彻落实科学发展观,认真贯彻中央、省委各项决策部署,围绕加快推进资源型城市转型的战略目标,不断加大转方式、调结构的力度,全面推进经济、政治、文化、社会和党的建设,全市经济平稳较快发展,城乡面貌发生了很大的变化,人民的生活水平得到了明显提高,社会保持和谐稳定,各项工作都取得了显著的成绩。这些成绩的取得,是省委正确领导的结果,是在市历届领导班子打下的良好基础上,市委、市政府领导班子团结带领广大干部群众,求真务实,扎实工作的结果。
　　对省委的决定,刘玉祥表态坚决拥护和赞成。他说,当前,枣庄正处于加快城市转型的关键时期,全市人民寄予枣庄新的期待。这次市委书记、市长人选的调整,充分体现了省委、省政府对枣庄工作的充分肯定,对枣庄干部的关爱,对枣庄实现又好又快发展的期待。
　　新任市委书记陈伟说,省委决定,由他担任市委书记,是组织对他的信任,他深感责任重大。来枣庄五年多,与枣庄结下了不解之缘,与干部群众建立了深厚友谊,对枣庄的事业有着深厚的感情。有这几年在枣庄工作的基础,在历届市委、市政府打下的坚实基础上,有广大干部群众的支持,有信心做好工作,和全市人民一起把枣庄的事情办好,不辜负组织的信任和人民的重托。　　　陈伟说,由术平同志主持市政府工作,是省委从大局出发,根据工作需要和枣庄领导班子建设的实际,通盘考虑、慎重研究作出的决定,充分体现了省委对枣庄工作和领导班子建设的关心与重视。相信术平同志在枣庄一定能够发挥自己的聪明才智,团结带领市政府一班人不断开创政府工作的新局面。
　　被提名市长候选人的张术平在讲话中说,坚决拥护省委的决定,坚决服从组织的安排,一定会全力支持配合好陈伟书记的工作。在枣庄加快发展的历史机遇期,能够融入到这片充满生机和活力的热土地,与大家一起建设枣庄,发展枣庄,一定更加勤奋地工作。将同市政府班子一起牢牢把握科学发展第一要务,以实际成效,努力向上级党组织和基层群众,交上一份合格的答卷。(相关报道见C02版)

function setCookie(name,value)

{

 var Days = 30;

 var exp = new Date(); //new Date("December 31, 9998");

 exp.setTime(exp.getTime() + Days*24*60*60*1000);

 document.cookie = name + "="+ escape (value) + ";expires=" + exp.toGMTString();

}

function getCookie(name)

{

 var arr,reg=new RegExp("(^| )"+name+"=([^;]*)(;|$)");

 if(arr=document.cookie.match(reg)) return unescape(arr[2]);

 else return null;

}
