新疆党委表决通过8名地州书记1名厅局党委书记 2011年07月18日 03:08 来源：天山网 参与互动( 0 ) 【字体： ↑大 ↓小 】 7月17日下午，自治区党委举行七届十三次全委会议，无记名投票表决通过8名地州党委书记、1名厅局党委书记。 自治区党委书记张春贤主持会议。 自治区党委副书记、组织部部长韩勇介绍了自治区党委常委会议决定提名的9名领导职务拟任人选情况。与会的自治区七届党委委员、候补委员分组审议了拟任人选名单。 根据《党政领导干部选拔任用工作条例》、《党的地方委员会全体会议对下一级党委、政府领导班子正职拟任人选和推荐人选表决办法》和《中共新疆维吾尔自治区委员会关于地(州、市)和自治区部分单位领导职务拟任人选和推荐人选表决实施办法(试行)》等有关规定，经过无记名投票表决通过，李学军任伊犁哈萨克自治州党委书记，张博任塔城地委书记，赵青任博尔塔拉蒙古自治州党委书记，李建国任昌吉回族自治州党委书记，彭家瑞任巴音郭楞蒙古自治州党委书记，曾存任克孜勒苏柯尔克孜自治州党委书记，程振山任喀什地委书记，闫汾新任和田地委书记，史少林任自治区司法厅党委书记。 张春贤在投票表决后希望走上新的领导岗位的干部，要以对党负责、对事业负责、对人民负责的态度，踏踏实实做事，堂堂正正做人，清清白白为官，不辜负自治区党委和各族人民的重托。 他对大家提出要求。一要注重学习，不断加强党性修养、提高素质能力。深入学习中国特色社会主义理论体系，切实把科学理论转化为谋划发展的正确思路、促进发展的政策措施、领导发展的实际能力，做到真学、真懂、真信、真用。全面学习做好领导工作必需的各种知识，增加知识涵养，增强人格魅力，提高工作水平。 二要努力工作，切实把经济发展搞上去、把长治久安工作搞扎实。坚持科学执政、民主执政，努力提升“新疆能力”，实践“新疆效率”，弘扬“新疆精神”，实现社会价值和人生价值的统一。 三要做好表率，不断增强领导班子的凝聚力和战斗力。党委书记要负起带班子、带队伍、带作风的主要责任，切实发挥表率作用，把一个地方的领导班子和干部队伍带好、把社会风气搞好。 四要联系群众，真心实意为各族人民谋利造福。把保障和改善民生放在优先位置，切实实现好、维护好、发展好最广大人民的根本利益。 五要廉洁自律，树立共产党人的良好形象。大力弘扬艰苦奋斗的优良传统和作风，心系基层、心系群众，吃苦在前、享受在后，克己奉公、甘于奉献，始终与各族群众同甘共苦。要严于律己、廉洁奉公，带头执行廉洁自律各项规定，管好配偶、子女和身边工作人员，严防腐败、严格管理、严肃纪律，做到为民、务实、清廉，树立共产党人清廉高洁的良好形象。 努尔・白克力、艾力更・依明巴海、艾斯海提・克里木拜、车俊、符强、黄卫、肖开提・依明、努尔兰・阿不都满金、宋爱荣、朱海仑、白志杰、库热西・买合苏提、胡伟、华士飞等出席会议。 自治区七届党委委员、候补委员参加会议。(新疆日报记者成立新报道) 分享按钮 参与互动( 0 ) 【编辑:巫峰】 ----- 国内新闻精选 ----- ・ 陕西：省内会议活动对领导称呼不加“尊敬的” ・
