政 府 工 作 报 告


（2025年2月15日在黔西南州第九届人民代表大会第五次会议上）
州长  黄兴文


各位代表：
现在，我代表州人民政府向大会报告工作，请予审议，并请州政协委员和其他列席人员提出意见。
一、2024年工作回顾
2024年是新中国成立75周年，是实现“十四五”规划目标任务的关键一年。全州上下坚持以习近平新时代中国特色社会主义思想为指导，认真贯彻党的二十大和二十届二中、三中全会精神，全面落实习近平总书记关于贵州工作重要讲话重要指示精神，按照党中央、国务院、省委省政府和州委部署要求，以高质量发展统揽全局，深入实施“产业强州”“文教兴州”“和谐稳州”战略，加快建设“康养胜地、人文兴义”，推动工作重心转移、思想观念转变、经济发展转型，高质量发展和现代化建设取得新成效。
一年来，我们深入实施产业强州战略，经济运行回升向好。全年地区生产总值增长4.2%，较2023年提升1.1个百分点。一、二、三产分别增长3.6%、6.7%、3.1%。规模以上工业增加值增长10%、排全省第二；固定资产投资增长8.5%、排全省第四，其中工业投资增长38.9%、排全省第二，占比提升10.3个百分点；一般公共预算收入增长3.8%；城镇和农村居民人均可支配收入分别增长4.1%、6.8%。全州经济承压增长，工业支撑作用更加凸显，发展质效不断提升。
一年来，我们深入实施文教兴州战略，文教事业持续向好。出台“文教兴州”战略实施意见，建立“加油文化”创新发展体制机制，推动文化繁荣、教育提质。兴义入选中国文化百强县。新增学前和义务教育学位18881个，本科上线率连续7年超过50%。以文化人、以教育人的氛围更加浓厚。
一年来，我们深入实施和谐稳州战略，安全形势稳中向好。用好“六防六化”工作方法，深入开展隐患矛盾问题大起底大排查，刑事、治安警情分别下降45.2%、32.9%；生产安全事故起数、死亡人数分别下降5.1%、4.9%，连续两年实现“双下降”，全州未发生重特大安全事故，安全发展基础更加牢固。
一年来，我们加快建设“康养胜地、人文兴义”，城市形象提升向好。成功召开国际山地旅游暨户外运动大会、中国世界地质公园年会、省旅游产业发展大会，万峰林景区成功创建国家5A级景区，黔西南州荣获“世界康养示范城市”称号，兴义地质公园获批“世界地质公园”，万峰林马拉松获中国田协A1类赛事认证。“康养胜地、人文兴义”城市形象更加光彩靓丽。
（一）千方百计稳定工业增长，经济支撑更加有力。稳住煤电。建成兴富、朝阳等4处煤矿，新增产能180万吨/年，调度原煤产量1494万吨。500千伏仁义输变电工程建成投运。元豪电厂3号机组、4个光伏项目建成发电，电力总装机达1700.73万千瓦。累计发电量441.15亿千瓦时、增长10.9%，全社会累计用电量177.76亿千瓦时，其中工业用电量126.2亿千瓦时。突破黄金。建成普安泥堡金矿露采、兴仁新恒基太平洞金矿项目，盘活黔昆金业冶炼厂。黄金生产及加工18027公斤、增长62.6%。拓展铝及铝加工。发挥登高、元豪等企业带动作用，不断延伸铝加工产业链。生产电解铝60.86万吨，铝及铝加工产业完成产值210.43亿元、增长34.1%。收窄新材料降幅。建成东岛4万吨、鑫茂1.5万吨负极材料生产线，开工建设兴义清水河磷酸铁锂等重点项目，晖阳新材料向储能电池负极材料转型，产业集群初步形成。释放其他行业产能。承接纺织服装产业转移，安龙云纺纺织、浙泰轻纺等重点项目加快建设。建成贵州薏粮醇酒厂。铁合金产业有序发展。
（二）多措并举扩投资促消费，有效需求不断扩大。强化争资争项。争取上级到位资金346.99亿元。争取中央和省预算、专项债、国债等资金49.73亿元，支持248个项目建设。狠抓招商引资。产业到位资金253.86亿元，其中工业到位资金193.72亿元，分别完成目标任务的126.9%、161.4%。扩大民间投资。引入民间资本198亿元，推动166个项目纳入国家、省重点项目，民间投资增长3.3%。加快重大项目建设。完成投资217.12亿元。金州大桥和纳晴、六安高速建成通车，盘兴铁路兴义段完成铺轨。开工建设黄百铁路、高卡水库。实施水网建设三年攻坚行动，建成兴仁打鱼凼、晴隆西泌河等10个骨干水源工程。全力稳住房地产投资。完成投资41亿元，建筑业总产值增长7.2%。“白名单”房地产项目授信贷款9.5亿元，信贷投放率近98%、投放进度排全省第三。促进消费提振恢复。消费品以旧换新、酱酒联动促销成效明显，带动消费22.08亿元，其中拉动汽车消费16.4亿元、排全省第三。
（三）深入推进旅游融合发展，比较优势愈加凸显。丰富旅游业态。积极协助编制世界第一高桥花江峡谷大桥桥旅融合景区规划。大佛坊完成业态升级并投入运营。举办路跑赛事活动255场，参与人次达18.65万。新增金山级民宿8家、银山级民宿10家。栖梦泽温泉建成投用，云屯沐云温泉入选“IMTA国际山地温泉康养旅游先行示范点”。打造黔剧《知府添灯油》，开展“加油之旅”研学活动。强化宣传营销。多措并举拓展旅游市场，赴港澳、武汉、深圳等地开展宣传推介10余次。接待游客人次、旅游总花费分别增长9.6%、11.7%。提升服务品质。开通“支支串飞”6条，积极推行“小车小团”，新增城区至景区公交线路3条，开通兴义至兴仁、安龙城际公交。从严整治“黑社”“黑车”等违法行为。盘活闲置低效旅游项目9个。
（四）毫不放松巩固脱贫成果，乡村振兴扎实推进。守住不发生规模性返贫致贫底线。累计识别监测对象8.2万人，落实分类帮扶措施，强化“3+1”保障，抓好易地搬迁后续扶持。深化东西部协作和中央单位定点帮扶，获东西部协作财政援助资金3.57亿元、中央单位定点帮扶资金0.96亿元。狠抓耕地保护和粮食安全。推进历年自然资源督察反馈问题整改，侵占耕地整改工作取得阶段性成效。新建、改造高标准农田11.57万亩。完成粮食播种311万亩、产量88.22万吨，平均单产283.67公斤、增长6.1%。因地制宜发展乡村产业。推进十大农业特色产业提质增效，贞丰火龙果、望谟油茶等9个农产品入选“全国名特优新农产品”，普安红茶、兴仁薏仁米入选中国农业品牌目录农产品区域公用品牌。盘活处置农村闲置低效项目409个、盘活处置率99%。扎实有序推进乡村建设。开展“两改两治理”，新（改）建户厕1.27万户、改圈0.15万户，农村生活污水治理（管控）率47%，30户以上自然村寨生活垃圾收运处置体系覆盖率保持90%以上。深入推进“四在农家·和美乡村”建设，乡村面貌加快改善，乡风文明持续提升。
（五）全面深化改革扩大开放，内生动力逐步增强。稳慎推进重点领域改革。原义龙新区体制机制改革稳步推进。组建州农投、能投集团。深化“三医”联动改革。推进公积金制度改革创新。政务服务“四单”工作模式获“贵州省综合改革示范奖”。册亨入选全省深化集体林权制度改革试点。持续扩大开放水平。实际利用外资1561万美元、增长128%，外贸工作获省激励通报。黔西南高新区入选全省外贸提升区名单，兴仁经开区入选国家级经开区培育对象，普安、晴隆经开区获省政府批复。强化科技人才支撑。50个项目获国家、省级科技计划立项，3个项目获省科学技术进步三等奖。有效高新技术企业达44家，全社会研发支出6.36亿元。引进高层次急需紧缺型人才416名，选派422名专技人才赴惠州挂职。不断优化营商环境。推进新一轮营商环境大改善三年行动、招商承诺不兑现专项整治，落实减税降费政策，清理妨碍统一市场和公平竞争的政策措施，办理“高效办成一件事”82.15万件。新设立经营主体4.57万户，总量达32.24万户。质量工作扭转多年靠后局面。万峰林“景区、商户营销服务产品”成功登记数据知识产权，成为全省文旅领域首例。
（六）扎实推进污染防治攻坚，生态环境持续改善。深入推进污染防治。环境空气质量优良率99.2%。16个国省控断面、县级及以上集中式饮用水源地水质优良率100%。启动无废城市创建，新增城市污水收集日处理能力1.2万吨。扎实推进生态环境保护督察反馈和披露问题整改。连续18年保持较大以上突发环境事件“零发生”。加强生态保护修复。全面落实河（湖）长制、林长制。联合六盘水、安顺申报国家历史遗留废弃矿山生态修复示范工程。完成营造林20万亩、石漠化治理107平方公里、水土流失综合治理365.14平方公里。大力推进绿色发展。遏制“两高”项目盲目发展，持续推进绿色低碳转型，新能源电力装机占比30.7%，新增和更新新能源出租车占比100%。册亨获全州第一张省级林业碳票，实现首单交易。
（七）全力防范化解重大风险，社会大局和谐稳定。防范化解债务金融风险。用好置换债券政策，加快化解存量隐性债务。推进融资平台债务展期、降息、置换，持续优化债务结构。加快融资平台实体化转型。积极解决拖欠企业账款问题。扎实做好中小金融机构风险防范化解，加快推进农村中小法人金融机构改革化险，牢牢守住不发生区域性系统性金融风险底线。筑牢安全屏障。深入开展安全生产治本攻坚三年行动，常态化开展安全生产会商研判和“打非治违”，纵深推进各行业领域重大风险防范化解，本质安全水平不断提升。维护社会稳定。坚持定期研究信访维稳工作，切实解决行业领域突出问题。常态化开展扫黑除恶斗争，依法打击各类违法犯罪活动。扎实推进保交楼、保交房，维护购房人合法权益。全面巩固和深化全国民族团结进步示范州创建成果，1个集体、2名个人获全国民族团结进步模范表彰。
（八）切实解决群众急难愁盼，民生福祉稳步增进。“十件民生实事”全面完成。促进群众就业增收。农村劳动力跨省务工53.75万人，城镇新增就业4.2万人，脱贫人口外出务工37.92万人，易地搬迁人口实现就业17.73万人。离校未就业高校毕业生帮扶就业率92.6%。开展技能培训2.12万人次。发放创业贷款2.24亿元。努力办好人民满意的教育。投入5.58亿元实施基础教育项目429个。新建、改扩建加油书院等学校11所，培育义务教育公办强校35所，民办义务教育学校在校生占比控制在8%以内。高考综合改革“首考”平稳落地。黔西南职院“双高”创建扎实推进。全力守护人民健康。建成国家级临床专科2个、省级临床重点专科20个、县域医疗次中心4个，县域内就诊率稳定在90%以上。县级公立中医医疗机构实现全覆盖。共享互认医学检验检查结果10.88万例次。强化社会保障。城乡低保平均标准分别提高至769元/月、6816元/年。发放困难群众救助补助资金12.13亿元。养老保险覆盖范围持续扩大，参保人数224.31万人。基本医保参保率稳定在95%以上，取消城乡医保普通门诊日报销限额，二级及以下定点医疗机构普通门诊报销比例提高10至30个百分点，大病保险年度报销限额从30万元提高到50万元。
一年来，我们持续强化理论武装，巩固主题教育成果，深入开展党纪学习教育，更加自觉衷心拥护“两个确立”、忠诚践行“两个维护”。加强法治政府建设，进一步规范行政机关权力运行，强化重点领域监管和公共法律服务保障，“两降一升”工作获省激励通报。自觉接受各方面监督，办理人大代表建议159件、政协委员提案165件。严格执行中央八项规定及其实施细则精神，严格落实过“紧日子”要求，切实整治形式主义为基层减负，抓好巡视整改、以案促改、15件群众身边具体实事集中整治整改，持续推进党风廉政建设和反腐败斗争。
各位代表！过去一年所有成绩的取得，根本在于以习近平同志为核心的党中央坚强领导，在于习近平新时代中国特色社会主义思想科学指引，是省委、省政府和州委坚强领导的结果，是州人大、州政协和社会各界有效监督、鼎力支持的结果，是全州广大干部群众守正笃行、久久为功的结果。在此，我代表州人民政府，向全州各族人民，向全州人大代表、政协委员，向各民主党派、工商联、无党派人士、各人民团体，向驻州人民解放军、武警部队官兵、公安干警和消防救援人员，向中央定点帮扶单位、东西部协作城市以及所有关心和支持黔西南发展的各界人士，表示衷心的感谢！
各位代表！我们也清醒地认识到，我州经济社会发展还面临不少困难和问题，主要是：有效需求偏弱，消费不振，投资稳定增长支撑不足；部分行业“增产不增效”，部分企业生产经营困难；财政收支矛盾较大、债务化解困难；民生事业仍有不少短板，群众就业增收面临一些困难；房地产市场还处于艰难调整期；安全生产、耕地保护、生态环境保护等领域还存在风险隐患。同时，一些干部作风不实，形式主义、官僚主义问题仍然存在。这些困难和问题，我们将采取有力措施，认真加以解决。
二、2025年工作目标和主要任务
今年是“十四五”规划收官之年，政府工作的总体要求是:以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大和二十届二中、三中全会及中央经济工作会议精神，深入贯彻习近平总书记关于贵州工作重要讲话重要指示精神，坚持以铸牢中华民族共同体意识为主线，按照省委十三届五次、六次全会暨省委经济工作会议和州委八届八次、九次全会暨州委经济工作会议部署，坚持稳中求进工作总基调，完整准确全面贯彻新发展理念，服务融入新发展格局，坚持以高质量发展统揽全局，守好发展和生态两条底线，坚持围绕“四新”主攻“四化”主战略和“四区一高地”主定位，深入推进“产业强州”“文教兴州”“和谐稳州”，加快建设“康养胜地、人文兴义”，大力提振消费，提高投资效益，突出大抓产业、大抓项目、大抓招商、大抓作风，推动科技创新和产业创新融合发展，加快构建黔西南特色现代化产业体系，进一步全面深化改革、扩大对外开放，更好激发活力、稳定预期、防范风险，不断提高人民生活水平，顺利完成“十四五”规划目标任务，为实现“十五五”良好开局打牢坚实基础。
主要预期目标是：全州地区生产总值增长6%左右，其中一、二、三产分别增长4%左右、8.5%左右、5.5%左右；规上工业增加值增长10%左右；固定资产投资增长11%左右；社会消费品零售总额增长5%左右；一般公共预算收入增长2%左右；城镇和农村常住居民人均可支配收入分别增长5.5%左右、7.5%左右；居民消费价格涨幅2%左右；城镇新增就业4万人左右；常住人口城镇化率达51%左右。
实现上述目标，必须坚持发挥能矿资源优势强工业、发挥区位优势强城市、发挥名优特产优势强农业、发挥生态气候资源和民族文化优势强旅游，奋力建设贵州面向南亚东南亚开放节点城市、黔滇桂结合部区域中心、贵州能源资源综合利用基地、国际山地运动康养度假旅游目的地。重点抓好以下工作。
（一）坚持大抓产业、协同共进，全力夯实发展基础
一是推动工业扩量提速。抢抓省“六大产业基地”建设机遇，锚定“3513”目标，以“富矿精开”为抓手，实施扩大工业投资攻坚行动，奋力推进新型工业化，完成工业投资128亿元左右，力争工业投资占比38%以上，新增规上工业企业30户左右。提振煤电。加快推进普兴矿区总体规划修编，帮助顺发、全力等煤矿恢复生产，推动大丫口、安福等煤矿恢复建设，实现新鸿发、承龙等煤矿稳产达产。建成投产煤矿3处以上，新增产能180万吨/年，调度原煤产量1850万吨以上。加快建设兴仁煤炭储备中心、兴义清水河煤炭储配基地项目。推动元豪电厂4号机组建成发电、中电普安风光火储一体化项目建成投用，新增电力装机100万千瓦以上，发电量450亿千瓦时。建强铝链。聚焦“煤电网”+铝及铝精深加工，全力争取省外电解铝产能指标转移，重点引进铝合金型材、铝合金零部件等项目，培育铝精深加工企业，推动铝产业集群发展。力争完成产值300亿元左右。巩固黄金。加大黄金勘探开采冶炼力度，推进贞丰紫金矿业、普安亚太矿业、黔西南高新区贵金属精炼、安龙黄金尾矿资源综合利用等项目建设。力争黄金生产及加工完成产值125亿元左右。稳住新能源电池及材料。按照全省新能源电池及材料“一核两区”规划布局，加快建设以三元正极材料和原辅料为代表的电池材料及原辅料产业集聚区，引导企业提质增效，增强市场竞争力。做优特色轻工。建设安龙印染纺织产业示范区，加快云纺纺织等项目建设。深入实施中医药产业高质量发展攻坚行动，加大民族药基础研究，打造民族药品牌。加快推进鹏昇（三期）项目建设，力争实现投产达产。建设茶叶、薏仁米、山茶油加工集中区。全力释放白酒等行业产能。强化数字赋能。大力发展数字经济，完善算力基础设施，推动黔西南高新区大数据产业园由存力向算力提档升级。加快新兴业态和数据产业孵化培育，开展公共数据授权运营试点，在交通、文旅、气象等领域打造数据产业应用场景。软件和信息技术服务业收入增长15%以上。推动50家企业数字化转型改造。促进铁合金、化工等传统产业转型升级。深入落实低空经济高质量发展三年行动，力争在特色场景应用上取得突破。
二是推动旅游业提质增效。围绕“两大提升”，聚焦“三大要素”，实施“四大行动”，奋力推进旅游产业化，接待游客人次、旅游总花费均增长8%以上。深化资源开发。依托“一带一核”，将沿线世界第一高桥、三岔河、招堤、云屯、万峰林等景区“串珠成链”，发挥世界地质公园、醉美诗酒田园、和谐布依家园、户外运动乐园优势，打造体验式、沉浸式、度假式场景业态。推动万峰林景区打造世界级旅游景区、兴义市建设一流旅游城市，加快云屯旅游度假区申报创建国家级旅游度假区，培育贞丰古城创建国家4A级旅游景区和国家级旅游休闲街区。加快花江峡谷大桥桥旅融合项目建设，着力打造“桥梁观光+桥梁运动体验+旅游服务”贵州桥旅融合示范样板。弘扬“加油文化”，深入开展“加油之声”“加油之旅”等系列活动。拓展客源市场。坚持市场化原则，精心筹备办好国际山地旅游暨户外运动大会、万峰林峰会，持续办好万峰林马拉松、青少年足球、万峰湖野钓、笃山攀岩等赛事。落实“引客入黔”奖补政策，发挥“云贵五城”区域文化旅游联盟作用，巩固扩大省内外客源市场。用好240小时过境免签政策，积极开发东南亚、日韩、欧美等境外客源市场。借助中央定点帮扶单位、惠州、州驻外机构等力量，积极引导州外机构到我州开展团建会展、疗养度假。组织旅行社、房企、酒店等外出开展推介，以“旅游+买房”“旅游+优质客房”等多种产品组合方式，开展营销宣传。提升服务质量。大力开展餐饮业、住宿业服务品质提升行动，聚焦万峰林蛋炒饭、金州“三碗粉”、贞丰糯米饭等特色美食，奋力打造具有本土元素的网红美食；引进高端品牌酒店入驻，完成10家以上等级民宿评定。完善旅游指示标识，扩大城市和景区停车位供给，优化游客租车服务。开发特色文旅商品，优化购物场所布局。优化升级《知府添灯油》等剧目，推进万峰林等智慧景区建设，加快“AI游黔西南”项目落地。坚决整治旅游市场乱象。
三是推动农业特色产业发展壮大。奋力推进农业现代化，大力发展菜心产业，逐步建立产销一体化产业链，稳定蔬菜种植面积170万亩、产量292万吨左右。推动兴仁薏仁米国家产业园区建设，中药材、食用菌产量分别增长5%左右、3.5%左右。推进茶叶标准化生产和茶产品开发，做强“普安红茶”区域公用品牌。打造芒果、香蕉、柑橘等具有较强竞争力的单品，稳定果园面积100万亩、产量65万吨左右。生猪存栏120万头、出栏170万头、猪肉产量16万吨左右，肉牛存栏46.7万头、出栏18.1万头、牛肉产量2.6万吨左右，家禽存栏、出栏分别增长2%以上、3%以上，禽蛋产量增长5%以上，渔业产量增长6%左右。大力发展林下经济，推动林业扩量增长。
四是加快发展生产性服务业。落实降低全社会物流成本专项行动，发展多式联运，推动大宗货物运输“公转铁”“公转水”，降低交通物流成本。持续做好金融“五篇大文章”，深入推进基金和保险资金入州。常态化开展政金企融资对接活动，发挥小微企业融资协调工作机制，用好“贵州金服平台”，落实无还本续贷政策。大力发展检测检验、咨询服务、节能环保、人力资源等生产性服务业。
（二）坚持大抓项目、强化保障，全力扩大有效需求
一是扩大有效投资。围绕资源谋项目。充分挖掘能矿资源、气候生态、文化教育、地方电网等优势，围绕“两重”“两新”等国家政策和省加力政策，紧盯国家“十五五”规划支持方向、政策导向、资金投向，全力争取省级前期工作专项资金，做实做深项目前期工作，最大程度谋划储备一批大项目、好项目。抢抓机遇争项目。项目化争取中央和省预算内投资、超长期特别国债、专项债，以及省“四化”产业基金、产业发展资金、房地产方面资金等政策支持，力争完成争资增长6%以上。聚焦重点抓项目。全力推动兴仁四海煤矿露采、贞丰簸箕田2金矿、安龙兴隆风电场等产业项目开工建设。深入推进产业配套基础设施建设三年行动计划，开工建设贞丰金城产业园区配套基础设施、安龙产业园供排水工程（一期）等项目。建成盘兴铁路，加快建设黄百铁路、新开行互联互通农村交通公路等重大项目，开工建设蔗香至红水河高速公路、G320普安新寨河至高铁站公路等项目。持续推进兴义至百色高铁、兴义经西林至文山天保高速公路、望谟港、八渡水电站等项目前期工作，配合推进红水河龙滩水电站1000吨级通航建筑物工程、南北盘江-红水河航道提等升级工程。完成交通投资30亿元左右。大力推进水网建设三年攻坚行动，建成安龙平桥水库、普安五嘎冲水库等15个骨干水源工程，加快建设兴义高卡水库、晴隆普岔河水库等重大水利项目，推进安龙美女山等水库前期工作，完成水务投资23亿元左右。深入实施城镇燃气和天然气基础设施建设攻坚行动，加快推进天然气支线管网二期兴仁至贞丰段项目，新改建城镇燃气管网50公里。落实机制推项目。用好“5+3”抓项目机制，聚焦“四化”和基础设施建设5个领域在建项目，工业、农业、服务业3个领域拟招项目，遴选一批省州重大项目，专班化、责任化、清单化推动建设。坚持“投资必问效、无效必问责”，推进分类加强政府投资项目管理机制改革，严控低效无效投资。
二是推动房地产市场平稳健康发展。坚决落实“四取消、四降低、两增加”政策措施，持续优化公积金政策，促进房地产转型升级、止跌回稳，完成房地产开发投资48亿元左右、销售商品房120万平方米左右。围绕“好环境+好房子”“好配套+好房子”，引导房企积极开发避暑康养旅居改善性产品。深入推进保交房工作，发挥城市房地产融资协调机制作用，推动在建商品住房按时保质交付。积极争取城中村和城市危旧房改造项目。深入实施“四房联动”专项行动、存量安置房三年清零攻坚行动，有序盘活存量闲置土地，支持居民“以小换大”“以旧换新”置换新房，联动推进存量安置房清零和商品房去库存。
三是实施提振消费专项行动。提升居民消费能力。落实好新一轮促进城乡居民增收行动，严格兑现惠民惠农补贴，加大以工代赈力度，千方百计增加居民收入，加快缩小城乡居民收入差距。提振重点领域消费。抢抓加力扩围实施消费品以旧换新政策机遇，用足用好国家补贴，叠加用好省优质酱酒等特色补贴、商家补贴，开展汽车、家电、家居和酒车、酒菜、酒商等促消费活动。逐步发展壮大健康、养老、托幼、家政等服务行业，鼓励经营主体和社会力量提供多元化服务。引导和鼓励企业积极开展成品油促销活动，深化成品油市场整治。培育新型消费业态。大力促进数字消费、绿色消费、健康消费等新型消费，积极发展首发经济、银发经济、避暑经济、演艺经济。依托赛会活动，发展流量经济，进一步释放消费潜力。深入实施电商“十百千万”工程，力争培育省级电商示范直播基地或示范企业10家以上。营造良好消费环境。改造升级商圈、商业步行街、夜间消费集聚区，在重点旅游景区及周边布局建设特色美食街区。开展“守护消费”执法铁拳行动，加强消费者权益保护。
（三）坚持大抓招商、优化环境，全力做大经济增量
一是突出主导产业招商。用好“一图三清单”，加大招商引资力度，新增签约项目合同投资300亿元以上，其中工业项目合同投资180亿元。围绕工业主导产业，招引一批“链主”企业、配套企业、转移企业，不断提高工业产业聚集度。围绕“康养胜地、人文兴义”城市定位，抓好旅游、康养和生产性服务业等产业招商。围绕产业配套设施、棚改拆迁闲置土地，开展商业综合体、康养地产、园区配套、现代物流等领域招引。围绕茶、中药材、蔬菜（菜心）、薏仁米、盘江小黄牛等农业特色优势产业，大力引进农特产品精深加工企业。
二是优化创新招商方式。积极探索“基金+产业”招商，加强与优强投资机构、金融机构对接联动，建立“以投带引”“招投联动”机制，引导、培育和孵化一批重点招商项目。积极探索“场景+产业”招商，围绕数字化、智能化、绿色化应用场景和设备，建立应用场景清单，招引推动一批先进制造业、文化旅游业项目落地。积极探索“矿产+产业”招商，按照“产业链-产业集群-产业生态圈”的路径，聚焦矿产资源精深加工环节，招引附加值高、产业支撑性强的企业。用好西部地区鼓励类产业企业所得税减按15%征收等优惠政策，深入开展央企、国企、民企、外企招商，统筹推进以商招商、开发区联动招商、盘活存量招商。
三是持续优化营商环境。深入实施营商环境大改善三年行动，持续整治营商环境突出问题，严格规范涉企行政检查，坚决遏制乱检查，减轻企业负担。严格规范招商引资行为，加强新招引项目合法性、公平竞争审查，提高招商引资质效。加强重大签约项目跟踪服务，做好用地、用能、资金等要素保障，强化并联审批和分工协作，推动项目加快建设。深化“高效办成一件事”改革，拓展“企业之家”服务内涵，推广“四单”工作模式，为企业提供一站式、便捷高效的政务服务。
（四）坚持城乡融合、共同繁荣，全力推进乡村振兴
一是抓实耕地保护。持续开展违法占用耕地问题整治，坚决整治“大棚房”等违法违规行为，坚决遏制耕地“非农化”“非粮化”。认真落实园地和林地上山、耕地下山部署，进一步优化耕地空间布局。扎实推进高标准农田建设，新建和改造提升10万亩以上。实施粮油作物大面积单产提升行动，确保粮食播种面积稳定在311万亩以上、产量不低于85万吨，完成大豆种植面积12万亩、油料80万亩。

    function IsMobile() {
        var isMobile = {
            Android: function () {
                return navigator.userAgent.match(/Android/i) ? true : false;
            },
            BlackBerry: function () {
                return navigator.userAgent.match(/BlackBerry/i) ? true : false;
            },
            iOS: function () {
                return navigator.userAgent.match(/iPhone|iPad|iPod/i) ? true : false;
            },
            Windows: function () {
                return navigator.userAgent.match(/IEMobile/i) ? true : false;
            },
            any: function () {
                return (isMobile.Android() || isMobile.BlackBerry() || isMobile.iOS() || isMobile.Windows());
            }
        };

        return isMobile.any(); //是移动设备
    }
