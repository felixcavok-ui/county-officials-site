张学平同志简历

张学平同志简历 张学平，男，汉族，1955年7月生，安徽寿县人，1973年4月参加工作，1974年8月加入中国共产党，大学学历，农学学士学位。 1973年4月寿县埝口公社知青、大队党支部书记； 1976年3月任寿县革委会知青办副主任； 1978年1月至1982年1月在安徽农学院农学系农学专业学习，任校学生会主席、省学联副主席，毕业后分配到安徽农学院学生部工作； 1983年11月起历任团省委学少部副部长、部长； 1990年5月任团省委副书记、省青联副主席，九届全国青联常委(其间:1991年7月至1993年7月挂职任桐城县委副书记)； 1995年3月任团省委副书记、党组副书记(主持工作)； 1995年11月任宣城地委副书记； 1998年3月任宣城地委书记(1997年9月至1999年7月参加安徽农业大学农经学院经管专业研究生课程进修班学习)； 2000年12月任宣城市委书记； 2001年1月任宣城市委书记、市人大常委会主任(其间:2001年3月至2002年1月参加中央党校培训部一年制中青班学习)； 2003年5月任省委常委、省委秘书长、省直属机关工委第一书记； 2006年10月至2007年11月任省委秘书长、省直属机关工委第一书记(2007年9月至2008年1月参加中央党校省部级干部进修班学习)； 2008年1月至今任安徽省政协副主席、党组成员。 中共十六大代表。中共九届省委委员。 更多地方人事报道请见 （责任编辑：尹彦宏） 编辑推荐 "女神"明星当年稚嫩照 盘点演艺圈中混血尤物 众女星销魂“湿身”照 女星超嫩美照排行 <!-- .pic_run_container {width:624px; height:132px; overflow:hidden; padding:0px; text-align:left;} .pic_run_container ul, .pic_run_container li{list-style:none;margin:0;padding:0; } .pic_run_container .pic_run_one { width:608px; height:132px; overflow:hidden; } .pic_run_title { position:absolute; display:block; left:0px; bottom:0px; width:100%; line-height:20px; border:1px solid #3F0; } .pic_run_num{
