'''黄钫'''({{bd|1972年|9月|}})，中華人民共和國政治人物，[[河南]][[开封]]人。1994年12月加入中国共产党，1995年7月参加工作，曾任[[漯河市]]市长<ref>{{Cite web |title=市长黄钫主持召开市政府党组（扩大）会议 |url=http://www.luohe.gov.cn/sitesources/lhsrmzf/page_pc/zfxxgkpt/fdzdgknr/zfgz/zfhy/article36ac3c8347d345b7ad61ab7c06bc6cda.html |website=漯河市政府 |date=2024年8月15日}}</ref>，现任中共漯河市委书记。

== 生平 ==
曾就讀于[[中央财经大学]]及[[四川大学]]，並擁有经济学博士学位。

2011年12月，任[[郑州市]][[惠济区]]人民政府区长；2015年11月，任中共惠济区委书记；2018年9月，任[[南阳市]]人民政府副市长；2021年9月，任中共[[信阳市]]委常委，市政府常务副市长；

2023年3月，任中共[[漯河市]]委副书记、市政府市长<ref>{{Cite web |title=黄钫当选漯河市市长(简历)_中国经济网——国家经济门户 |url=http://district.ce.cn/newarea/sddy/202303/25/t20230325_38462205.shtml |website=district.ce.cn |access-date=2025-01-22 |archive-date=2023-07-25 |archive-url=https://web.archive.org/web/20230725023547/http://district.ce.cn/newarea/sddy/202303/25/t20230325_38462205.shtml |url-status=live }}</ref>。

2026年5月，升任中共漯河市委书记<ref>{{Cite web |title=省委决定：漯河市市长黄钫，任市委书记 |url=https://www.shobserver.com/staticsg/wap/newsDetail?id=1111345 |website=上观新闻 |access-date=2026-05-13}}</ref>。
