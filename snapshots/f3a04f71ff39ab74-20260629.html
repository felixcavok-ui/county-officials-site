 冀文林 海口市人民政府 市长 任期 2011年2月16日－2013年3月 
 个人资料 性别 男 出生 1966年7月 中华人民共和国 内蒙古自治区 凉城县 国籍 中华人民共和国 政党 中国共产党 （2014年7月2日被开除） 专业 地球物理学 学历 
 中国地质大学 硕士研究生 
 
 
 冀文林 （1966年7月—），男， 内蒙古自治区 凉城县 人， 中华人民共和国 政治人物。曾在 中国地质大学 就读，获 地球物理 专业硕士学位。1989年7月正式参加工作，1994年8月加入 中国共产党 。冀文林曾长期担任 周永康 的 秘书 ，被认为是周永康的心腹 [ 1 ] 。
 
 
 生平 [ 编辑 ] 
 冀文林于1966年7月出生于凉城县 永兴镇 西驼厂村的一个贫寒农家，
 
 地质矿产部时期 [ 编辑 ] 
 1989年7月，进入 中华人民共和国地质矿产部 ，正式 参加工作 ；历任地矿部 办公厅 科员 、副主任科员、主任科员。
 1994年8月，加入 中国共产党 。
 1996年12月起，任地质矿产部部长办公室副主任。
 
 国土资源部部长周永康的秘书 [ 编辑 ] 
 1998年8月起，历任 国土资源部 办公厅值班室助理调研员、 调研员 、部长（周永康） 秘书 。 [ 2 ] 
 
 四川省委书记周永康的秘书 [ 编辑 ] 
 1999年12月起，历任 中共四川省委 常委办公室副主任、 省委办公厅 副厅级秘书；2001年9月至2003年7月， 四川省工商管理学院 MBA 在职研究生 学历教育班学习。
 
 国务委员兼公安部部长周永康的秘书 [ 编辑 ] 
 2003年3月 第十届全国人大第一次会议 上，周永康被任命为 国务委员 ，继续兼任 公安部 部长。
 2003年4月起，冀文林任公安部 办公厅 副主任、 国务院办公厅 副局级秘书。
 2005年9月，冀文林被授予 二级警监 警衔 。2005年9月起，任 中共中央办公厅 正局级秘书。
 
 中央政治局常委兼中央政法委书记周永康的秘书 [ 编辑 ] 
 2007年10月 中共十七届一中全会 上，周永康晋升 中共中央政治局常委 、 中央政法委 书记、 中央综治委 主任，接替罗干全面负责中共政法工作。
 2008年7月，冀文林兼任 中央维护稳定工作领导小组办公室 副主任。
 
 国土资源部办公厅主任 [ 编辑 ] 
 2008年12月起，任 国土资源部 办公厅主任（服务时任部长 徐绍史 ）；2009年1月起，为中共国土资源部党组成员 [ 3 ] 。
 
 海南时期 [ 编辑 ] 
 2011年2月16日起，任 海口市人民政府 市长 [ 3 ] 。
 2013年1月起，任 海南省人民政府 副省长。
 
 被查 [ 编辑 ] 
 参见： 周永康案 
 2014年2月18日， 中纪委 披露，冀文林因涉嫌严重违纪违法，被 纪检 监察 机关立案调查 [ 4 ] [ 5 ] [ 6 ] 。同年7月2日被双开并移送司法机关处理，经查冀文林利用职务上的便利为他人谋取利益，收受、索取巨额贿赂共计折合人民币2046万余元；以及与他人通奸。 [ 7 ] 
 2016年3月30日， 天津市第一中级人民法院 一审宣判，冀文林犯受贿罪，判处有期徒刑12年，并处罚金人民币100万元 [ 8 ] 。
 
 家庭 [ 编辑 ] 
 有两姐姐、一个哥哥和一个弟弟，在家中排老四。
 妻子是在武汉地质学院地质系就读时认识的学妹， 吉林市 人，两人育有一女。 [ 9 ]
