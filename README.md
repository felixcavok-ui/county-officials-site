# CCLD 网站（试点版）

中国县级主政官员数据库（CCLD）静态站点。站点展示仓库正式三层数据目录的确定性生成结果，原虚构演示样例已全部移除；实际覆盖范围与发布日期以页面内 `DB.meta` 和覆盖图为准。

**打开方式**：双击 `index.html` 即可（纯静态、无依赖、无需服务器）。

**数据来源与更新方式**
- `js/data.js` 由 `scripts/build_demo_data.py` 从仓库 `data/` 目录（county-collect 工作流的 merge 产物）生成，**禁止手工编辑**；
- 新批次入库后重跑 `python scripts/build_demo_data.py --as-of YYYY-MM-DD` 即可上新；
- 任职记录与已挂接的人物字段展示来源链接（摘要最多展示 3 个去重 source_url，含信源 A–D 级标注），可回溯 `data/<省全称>/<地级市>/<单位>/evidence.csv` 的逐字引文与 `archive/` 页面快照；无证据字段不得据此推定已核验。
- 跨单位复制的履历按 `career_spell_id` 确定性归并；互斥非空字段的冲突组整组不进入网页人物履历，排除数量写入 `DB.meta.quality.career`，原始 CSV 不改写。

**站点内容**
- 首页：项目定位、已采集单位×年**月度覆盖率**热力图（由 spell 起止月真实计算）、方法制度、引用方式
- 数据浏览：省 → 县 → 历任书记/市长时间轴（按离任去向着色：晋升/平调/退二线/落马/在任/免职辞职/待查，代理期与缺口显式标注）→ 任职记录表（来源链接 + 多源/单源/分歧核验标记 + 一键报错）
- 人物页：完整简历（career spells 保留机构/职务原文）与"薄记录"两种形态、落马官员的纪律审查模块
- 数据下载：证据/结论/生成三层表结构，展示正式目录口径的真实行数与大小；单文件提供 MD5，分散表展示文件数
- 研究注册：post-analysis registration 流程与登记表（当前两条为示例条目）

文件结构：`index.html` + `css/style.css` + `js/data.js`（生成的数据）+ `js/app.js`（渲染逻辑）。
正式版将由数据库 release 自动生成静态页面（同一设计系统）。
